The 2026-07-18 current-tree smoke found one additional reset integration defect.
The Module 07 scoped lifecycle reset `artifact-store-01`, which correctly
removed participant model outputs but also removed the immutable teacher
object. It did not reset `model-host-01`, the SDL-declared bootstrap owner that
reuploads and verifies that object. Artifact access therefore failed closed

closure, restoring the object through that owner, and rerunning only the
affected theft and award phases produced a passing transfer and final join.
The final 15-service health check passed and the range remains retained.
