From the OT engineering desktop or the connector container with corporate session.

Requires W17.1 and W17.2. Identify the instrument binding for FIT-CRR-204B: its IEC variable, OPC UA NodeId, historian series, and unit. Submit the exact engineering reference entry.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

# The instrument binding is published in the engineering reference document on the OT desktop.
# FIT-CRR-204B is the flow instrument for outlet B.
body = json.dumps({
    "card": "W17.3",
    "instrument": "FIT-CRR-204B",
    "variable": "FlowBM3s",
    "node_id": "nsu=urn:arwc:crr:tags;s=CRR.FlowBM3s",
    "historian_series": "flow_b_m3s",
    "unit": "m3/s",
}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/live-observations/current",
                            data=body, headers=h, method="POST"),
    context=ctx).read())
print("satisfied:", d["satisfied"])
print("flag:", d["flag"])   # FLAG{29af64987ad77321}
```

The service validates the submitted binding against both the engineering reference contract and the live historian catalog. All five fields must match exactly.

Flag: `FLAG{29af64987ad77321}` in the top-level `flag` field.
