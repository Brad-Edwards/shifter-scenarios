Use limited_session from W05.3 as X-ARWC-Planning-Access.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
limited = pathlib.Path("receipts/limited-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc",
     "X-ARWC-Planning-Access": limited}

d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://corporate-identity.arwc.test/api/sessions/current/audit", headers=h),
    context=ctx).read())
rec = d["record"]
print("record_id:", rec["record_id"])              # RENDER-CRR-882
print("oauth_transaction:", rec["oauth_transaction"])  # OAUTH-PLN-882
print("oauth_state:", rec["oauth_state"][:20], "...")
print("drawing:", rec["drawing"])                  # DRW-OG2-R8
print("review:", rec["review"])                    # REV-CRR-4417
print("flag:", d["flag"])                          # FLAG{415d4e9b4cc2c1ba}
```

Flag: `FLAG{415d4e9b4cc2c1ba}` in the top-level `flag` field.
