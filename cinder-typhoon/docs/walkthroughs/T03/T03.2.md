Read the failed build log to get the publisher token:

```bash
curl -s http://developer.training:8080/ | grep -o 'http://developer.training:8082[^`]*'
# -> http://developer.training:8082/jobs/BLD-204/log
curl -s http://developer.training:8082/jobs/BLD-204/log | grep publisher_
# -> publisher_CINDER_7K4M9Q2V6R8D
```

```bash
curl -s -H "Authorization: Bearer publisher_CINDER_7K4M9Q2V6R8D" http://developer.training:8083/api/channels/rehearsal/manifest
```
