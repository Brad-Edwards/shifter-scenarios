## Restore backup to get a recovery namespace

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Authorization: Bearer <recovery_session>" \
  -H "Content-Type: application/json" --data-binary '{}' \
  https://data.keplerops.test/api/backups/BAK-2026-021/restores
```

Output: `{"backup_id":"BAK-2026-021","namespace_id":"NS-REC-4ACDF4940B"}`

Value used next: `namespace_id=NS-REC-4ACDF4940B`
