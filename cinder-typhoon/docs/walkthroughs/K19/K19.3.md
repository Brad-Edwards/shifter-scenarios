## Request Kerberos delegation via mTLS cert (K19.3 acceptance check)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  --cert /tmp/journey-evan.crt --key /tmp/journey-evan.key \
  -H "Content-Type: application/json" \
  --data-binary '{"spn":"HTTP/staff.keplerops.test@KEPLEROPS.TEST"}' \
  https://staff.keplerops.test/api/archive/delegation/probe
```
