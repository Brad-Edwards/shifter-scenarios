## Submit the reviewer who was never listed

Bind the recovered reviewer, the helper digest, and the archive context from
W22.3. A different reviewer is rejected with 409.

```bash
PROCESS=$(cat receipts/process-session)
BODY=$(python3 - <<'PY'
import json
d = json.load(open("/tmp/w22-open.json"))
ctx = d["archive_context"]
print(json.dumps({
    "helper_sha256": d["review_helper_sha256"],
    "reviewer": open("/tmp/w22-reviewer.txt").read().strip(),
    "session": ctx["session"],
    "comparison": ctx["comparison"],
    "project": d["record"]["project"],
}))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST \
  https://maintenance-review.arwc.test/api/unlisted-reviewers/current
```

```json
{"audit_id":"...","flag":"FLAG{e7cf68818ecbefd1}","record":{"historical":true,"current_identity":false,"control_authority":false,...}}
```

On success `record.historical` is `true` while `current_identity` and
`control_authority` are `false`. The flag is in the top-level `flag` field.
