## Prerequisite

After W22.1. Reuses `/tmp/w22.json` and `/tmp/w22vm.py`.

## Run every ordinary case through the VM

Each ordinary case carries its own program. For each one, run the VM and report
the registers, the SHA-256 of memory `0x40..0x80`, and the step count. A short
set (missing the last case) is rejected with 409.

```bash
PROCESS=$(cat receipts/process-session)
BODY=$(python3 - <<'PY'
import json, base64, sys
sys.path.insert(0, "/tmp"); from w22vm import public
d = json.load(open("/tmp/w22.json"))
cases = d["record"]["ordinary_cases"]
results = [public(base64.b64decode(case["program_b64"])) for case in cases]
print(json.dumps({"cases": results}))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST \
  https://process-view.arwc.test/api/sealed-viewers/current/execute
```

```json
{"audit_id":"...","flag":"FLAG{2aff355751accd95}","record":{"cases":[...]}}
```

The response `record.cases` has one entry per ordinary case. The flag is in the
top-level `flag` field.
