## Derive the sealed-project key and open the project

The key is `SHA-256(project_id + "\0" + memory[0x40:0x80] + registers)`, where the
registers are packed as little-endian 16-bit values and the memory comes from the
VM run of the delivery program. A wrong key is rejected with 409.

```bash
PROCESS=$(cat receipts/process-session)
BODY=$(python3 - <<'PY'
import json, base64, hashlib, struct, sys
sys.path.insert(0, "/tmp"); from w22vm import run_vm
d = json.load(open("/tmp/w22.json"))
project_id = d["record"]["project_id"]
reg, mem, _ = run_vm(base64.b64decode(d["program_b64"]))
material = project_id.encode() + b"\0" + mem[0x40:0x80] + b"".join(struct.pack("<H", r) for r in reg)
print(json.dumps({"project_id": project_id, "key_hex": hashlib.sha256(material).hexdigest()}))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST \
  https://process-view.arwc.test/api/sealed-projects/current -o /tmp/w22-open.json
python3 -c "import json;d=json.load(open('/tmp/w22-open.json'));print('flag:',d['flag']);print('project:',d['record']['project']);print('archive_context:',d['archive_context'])"
```

Expected: `flag: FLAG{e4faeac4a9f89ddb}`. The response carries
`review_helper_b64` (a ReadyToRun DLL beginning `MZ`), `review_helper_sha256`,
`record.project`, and `archive_context`.

## Recover the unlisted reviewer from the helper DLL

The DLL shows one decoy reviewer ending `-review` as a UTF-16LE string. The real
reviewer is assembled from native `mov rax, imm64; ret` immediate chunks. Recover
it (it ends with the same suffix but differs from the decoy).

```bash
python3 - <<'PY'
import json, base64, re, sys
d = json.load(open("/tmp/w22-open.json"))
helper = base64.b64decode(d["review_helper_b64"], validate=True)
visible = [t.decode("utf-16le") for t in re.findall(rb"(?:[\x20-\x7e]\x00){6,}", helper)
           if t.decode("utf-16le").endswith("-review")]
assert len(visible) == 1, visible
visible_reviewer = visible[0]
native = []
for m in re.finditer(rb"\x48\xb8(.{8})\xc3", helper, re.DOTALL):
    try: v = m.group(1).decode("utf-16le")
    except UnicodeDecodeError: continue
    if len(v) == 4 and all(0x20 <= ord(c) < 0x7f for c in v):
        native.append(v)
allc = {helper[o:o + 8].decode("utf-16le") for o in range(len(helper) - 7)
        if all(helper[o + i] == 0 for i in (1, 3, 5, 7)) and all(0x20 <= helper[o + i] < 0x7f for i in (0, 2, 4, 6))}
suffix = visible_reviewer.rsplit("-", 1)[-1]
cands = set()
for i in range(len(native) - 2):
    prefix = "".join(native[i:i + 3])
    for chunk in allc:
        for final in range(0x20, 0x7f):
            c = prefix + chunk + chr(final)
            if (len(c) == len(visible_reviewer) and c.endswith("-" + suffix)
                    and c != visible_reviewer and re.fullmatch(r"[a-z][a-z.]+-[a-z]+", c)):
                cands.add(c)
assert len(cands) == 1, cands
open("/tmp/w22-reviewer.txt", "w").write(cands.pop())
print("visible decoy:", visible_reviewer)
print("recovered reviewer:", open("/tmp/w22-reviewer.txt").read())
PY
```

Expected recovered reviewer `elias.vorn-review`. Keep `/tmp/w22-open.json` and
`/tmp/w22-reviewer.txt`. The flag is in the top-level `flag` field.
