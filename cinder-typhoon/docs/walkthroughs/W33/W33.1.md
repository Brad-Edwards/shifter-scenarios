## Step 2 — Find the W30 request in the dispatcher journal

From the OT engineering workstation, connect to the OT historian:

```
sudo docker exec --user fieldlink cinder-arwc-ot-engineering \
  psql -h 172.29.63.22 -U reader -d historian -c \
  "SELECT id, time, status FROM public.dispatch_history
   WHERE status = 'completed'
   ORDER BY time DESC LIMIT 5;"
```

Record the request UUID (`id`) of the most recent completed W30 dispatch.

## Step 3 — Find the PLC acceptance time

```
sudo docker exec --user fieldlink cinder-arwc-ot-engineering \
  psql -h 172.29.63.22 -U reader -d historian -c \
  "SELECT source_time FROM public.command_history
   WHERE asset = 'AST-CRR-017' AND channel = 'dispatcher'
   ORDER BY source_time DESC LIMIT 1;"
```

Record the PLC acceptance time (`plc_accepted_at`).

## Step 4 — Read settled TotalFlowM3s samples after acceptance

```
sudo docker exec --user fieldlink cinder-arwc-ot-engineering \
  psql -h 172.29.63.22 -U reader -d historian -c \
  "SELECT ph.source_time, ph.value, ph.process_quality
   FROM public.process_history ph
   JOIN public.historian_tag_catalog c ON c.series = ph.tag
   WHERE ph.asset = 'AST-CRR-017' AND c.variable = 'TotalFlowM3s'
     AND ph.source_time >= '<plc_accepted_at>'
     AND ph.source_time <= '<plc_accepted_at>'::timestamptz + interval '3 minutes'
   ORDER BY ph.source_time;"
```

Replace `<plc_accepted_at>` with the time from Step 3.

Identify the first Good sample within 0.02 m³/s of 0.30 m³/s — this is `settled_start`.
Collect at least five consecutive Good in-tolerance samples. Record `settled_end` as the last sample time.

## Step 5 — Calculate calibration values

```python
plc_accepted_at = "<ISO 8601 from Step 3>"
settled_start   = "<ISO 8601 of first in-tolerance Good sample>"
settled_end     = "<ISO 8601 of last settled Good sample>"
good_samples    = [<list of TotalFlowM3s values from settled window>]

requested_flow  = 0.3
mean_flow       = sum(good_samples) / len(good_samples)
response_delay  = (settled_start - plc_accepted_at).total_seconds()
flow_gain       = mean_flow / requested_flow
```

## Step 6 — Submit the calibration

From the IT connector shell (Step 0):

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
proc = pathlib.Path("receipts/process-session").read_text().strip()
h = {"Authorization": "Bearer " + proc, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

body = {
    "asset": "AST-CRR-017",
    "request_id": "<W30 request UUID from Step 2>",
    "plc_accepted_at": "<ISO 8601 from Step 3>",
    "settled_start": "<ISO 8601 from Step 4>",
    "settled_end": "<ISO 8601 from Step 4>",
    "requested_total_flow_m3s": 0.3,
    "mean_total_flow_m3s": <mean from Step 5>,
    "response_delay_seconds": <delay from Step 5>,
    "flow_gain": <gain from Step 5>,
    "good_sample_count": <count of settled Good samples>,
}
d = json.loads(urllib.request.urlopen(
    urllib.request.Request(
        "https://process-view.arwc.test/api/commissioning-calibrations/current",
        data=json.dumps(body).encode(), headers=h, method="POST"), context=ctx).read())
print("flag:", d["flag"])   # FLAG{a972558765950459}
```

The service verifies response delay, mean flow, and gain against the OT historian. The flag appears in the top-level `flag` field.
