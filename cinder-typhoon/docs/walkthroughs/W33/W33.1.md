# W33.1 Walkthrough: CRR commissioning calibration

## Prerequisite

W30 (gate release observed, `w30_result` in service state). Access from engineering workstation with ROLE=engineering.

## Steps

Access the OT historian (`172.29.63.22`, PostgreSQL, `dbname=historian`, `user=reader`). Read the last command for asset `AST-CRR-017` channel `dispatcher` within 24 hours, then read `TotalFlowM3s` values in the 3-minute window after the PLC acceptance. Compute `mean_total_flow_m3s`, `response_delay_seconds`, and `flow_gain = mean / 0.3`.

```
TOKEN=$(cat handover/corporate-session)
curl -sS --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary "{
    \"request_id\": \"$(uuidgen)\",
    \"requested_total_flow_m3s\": 0.3,
    \"mean_total_flow_m3s\": <computed>,
    \"response_delay_seconds\": <computed>,
    \"flow_gain\": <computed>,
    \"good_sample_count\": <computed>
  }" \
  https://process-view.arwc.test/api/commissioning-calibrations/current
```

Expected output:

```json
{"audit_id":"...","flag":"FLAG{a972558765950459}","record":{"record_id":"CAL-CRR-W33-R1","revision":1,"instruction":"CRR-OP-W33-R1","asset":"AST-CRR-017","requested_total_flow_m3s":0.3,"mean_total_flow_m3s":<computed>,"response_delay_seconds":<computed>,"flow_gain":<computed>,"good_sample_count":<n>}}
```

Gate: requires `w30_result` state; calibration values must match OT historian records within tolerance 0.01.
