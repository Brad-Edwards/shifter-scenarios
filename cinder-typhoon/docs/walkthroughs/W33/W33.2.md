# W33.2 Walkthrough: CRR operating schedule

## Prerequisite

W33.1 complete (`w33_calibrated` state). Access from engineering workstation with ROLE=engineering.

## Steps

Compute a 12-interval operating schedule (interval_seconds=300) for asset AST-CRR-017 under instruction CRR-OP-W33-R1. The schedule must keep the buffer (starting 180 m3) between 120 and 240 m3 at every step and end between 160 and 200 m3. Projected volume must be between 0.78 and 0.84 ML.

```
TOKEN=$(cat handover/corporate-session)
curl -sS --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{
    "forecast": {"schema": "arwc.demand-forecast/v1", "demand_m3s": [0.45,0.50,0.55,0.60,0.65,0.70,0.70,0.65,0.60,0.55,0.50,0.45]},
    "schedule": {
      "schema": "arwc.operating-schedule/v1",
      "instruction": "CRR-OP-W33-R1",
      "asset": "AST-CRR-017",
      "interval_seconds": 300,
      "reservoir_release_m3s": [<12 values>],
      "alternate_supply_m3s": [<12 values>]
    }
  }' \
  https://process-view.arwc.test/api/operating-schedules/current
```

Expected output:

```json
{"audit_id":"...","flag":"FLAG{7fc27069641f0cc2}","record":{"record_id":"SCHED-CRR-W33-R1","revision":1,"instruction":"CRR-OP-W33-R1","asset":"AST-CRR-017","interval_count":12,"interval_seconds":300,"projected_reservoir_volume_ml":<0.78-0.84>,"final_buffer_m3":<160-200>,"feasible":true}}
```

Gate: buffer must stay in envelope at every step; uses `w33_flow_gain` from W33.1 calibration.
