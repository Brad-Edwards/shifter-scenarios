From the IT connector shell:

import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")

Note the tariff rate (USD/ML) and committed volume (ML).

## Step 3 — Construct a feasible twelve-interval schedule

Use the calibrated `flow_gain` from W33.1. Apply these constraints:

- Initial buffer: 180 m³
- Buffer update: `next = current + 300 × (flow_gain × reservoir_release + alternate_supply − demand)`
- Buffer bounds after every interval: 120–240 m³
- Final buffer: 160–200 m³
- Reservoir release: 0.00–0.80 m³/s; step limit 0.10 m³/s
- Alternate supply: 0.00–0.50 m³/s; step limit 0.10 m³/s
- Projected reservoir volume: `sum(300 × flow_gain × release) / 1000` must be 0.78–0.84 ML

Demand vector: `[0.45, 0.50, 0.55, 0.60, 0.65, 0.70, 0.70, 0.65, 0.60, 0.55, 0.50, 0.45]` m³/s

Write your values into the schedule template on the OT engineering workstation:

```
sudo docker exec --user fieldlink cinder-arwc-ot-engineering bash -c \
  "cat > /home/fieldlink/CairnReach/Briefs/W33/my-schedule.json << 'EOF'
{
  \"schema\": \"arwc.operating-schedule/v1\",
  \"instruction\": \"CRR-OP-W33-R1\",
  \"asset\": \"AST-CRR-017\",
  \"interval_seconds\": 300,
  \"reservoir_release_m3s\": [<twelve values>],
  \"alternate_supply_m3s\": [<twelve values>]
}
EOF"
```

Verify the schedule is feasible before submitting.

## Step 4 — Submit the schedule

From the IT connector shell, submit the forecast (W33.1 calibration) and the schedule together:

```python
forecast = {
    "asset": "AST-CRR-017",
    "request_id": "<W30 request UUID from W33.1>",
    "plc_accepted_at": "<from W33.1>",
    "settled_start": "<from W33.1>",
    "settled_end": "<from W33.1>",
    "requested_total_flow_m3s": 0.3,
    "mean_total_flow_m3s": <from W33.1>,
    "response_delay_seconds": <from W33.1>,
    "flow_gain": <from W33.1>,
    "good_sample_count": <from W33.1>,
}
schedule = {
    "schema": "arwc.operating-schedule/v1",
    "instruction": "CRR-OP-W33-R1",
    "asset": "AST-CRR-017",
    "interval_seconds": 300,
    "reservoir_release_m3s": [<your twelve values>],
    "alternate_supply_m3s": [<your twelve values>],
}
body = {"forecast": forecast, "schedule": schedule}
d = json.loads(urllib.request.urlopen(
    urllib.request.Request(
        "https://process-view.arwc.test/api/operating-schedules/current",
        data=json.dumps(body).encode(), headers=h, method="POST"), context=ctx).read())
print("projected_volume:", d["record"]["projected_reservoir_volume_ml"])
print("flag:", d["flag"])   # FLAG{7fc27069641f0cc2}
```

The service validates buffer bounds, ramp limits, and projected volume using your calibrated gain. The flag appears in the top-level `flag` field.

Flag: `FLAG{7fc27069641f0cc2}`
