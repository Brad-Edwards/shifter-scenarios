# W33.3 Walkthrough: CRR commissioning run

## Prerequisite

W33.2 complete (`w33_schedule` state). Access from engineering workstation with ROLE=engineering.

## Steps

The commissioning run POSTs 12 request IDs for the operating schedule intervals. Timing must be sequential. Submit the run with the same schedule and forecast from W33.2.

```
TOKEN=$(cat handover/corporate-session)
curl -sS --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{
    "asset": "AST-CRR-017",
    "forecast": <forecast from W33.2>,
    "schedule": <schedule from W33.2>,
    "request_ids": ["<uuid-1>","<uuid-2>","<uuid-3>","<uuid-4>","<uuid-5>","<uuid-6>","<uuid-7>","<uuid-8>","<uuid-9>","<uuid-10>","<uuid-11>","<uuid-12>"],
    "started_at": "<ISO8601>",
    "completed_at": "<ISO8601 after started_at>",
    "mean_step_flows_m3s": [<12 float values observed from OT historian>]
  }' \
  https://process-view.arwc.test/api/commissioning-runs/current
```

Expected output:

```json
{"audit_id":"...","flag":"FLAG{271d8984b1b19a04}","record":{"record_id":"COMM-CRR-W33-R1","revision":1,"instruction":"CRR-OP-W33-R1","asset":"AST-CRR-017",...}}
```

Gate: requires W33.2; exactly 12 request IDs; timestamps ordered; mean flows from OT historian.
