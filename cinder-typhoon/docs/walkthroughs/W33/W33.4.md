## Step 1 — Read settled mean flow for each interval

For each of the twelve W33.3 request UUIDs, find the settled TotalFlowM3s mean in the 4 seconds before the dispatch `completed` timestamp.

From the OT engineering workstation:

```sql
-- For each request_id, get the completed time and settled mean:
SELECT dh.id, dh.time AS completed_at,
       (SELECT AVG(ph.value) FROM public.process_history ph
        JOIN public.historian_tag_catalog c ON c.series = ph.tag
        WHERE ph.asset = 'AST-CRR-017' AND c.variable = 'TotalFlowM3s'
          AND ph.source_time >= dh.time - interval '4 seconds'
          AND ph.source_time <= dh.time
          AND ph.process_quality = 'Good') AS mean_flow
FROM public.dispatch_history dh
WHERE dh.id::text IN (<comma-separated list of 12 request UUIDs>)
  AND dh.status = 'completed'
ORDER BY dh.time;
```

Record the twelve mean flow values in interval order.

## Step 2 — Read the starting usable volume

Read the `UsableVolumeML` value just before the first commissioning step started:

```sql
SELECT ph.source_time, ph.value
FROM public.process_history ph
JOIN public.historian_tag_catalog c ON c.series = ph.tag
WHERE ph.asset = 'AST-CRR-017' AND c.variable = 'UsableVolumeML'
  AND ph.source_time <= '<first_request_started_at>'::timestamptz - interval '5 seconds'
ORDER BY ph.source_time DESC LIMIT 1;
```

## Step 4 — Calculate the projection

```python
interval_seconds  = 300
means             = [<twelve values from Step 1>]
starting_volume   = <UsableVolumeML from Step 2>
committed_volume  = <from Step 3>   # 12.0 ML
tariff_rate       = <from Step 3>   # 2400.0 USD/ML

projected_volume  = sum(interval_seconds * m for m in means) / 1000.0
remaining_volume  = starting_volume - projected_volume
shortfall         = max(0.0, committed_volume - remaining_volume)
liability         = shortfall * tariff_rate
```
