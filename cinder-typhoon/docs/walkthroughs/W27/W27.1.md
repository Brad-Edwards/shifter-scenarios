Requires process_session and deployed_revision_observed (W22).

Step 1 - GET materials:
POST /api/signature-programs/current/reproductions:
```json
{"operation":"materials","record_id":"VER-ROT128-R3"}
```
Returns verifier binary (ELF64) and 6 DPG1 test programs.

Step 2 - Run verifier on each program:
Execute the ROT128 verifier binary locally on each program:
```bash
./rot128-verifier <program.dpg>
```
Collect: case_id, digest (hex), decision (pass/fail).

Step 3 - POST results:
```json
{"operation":"results","record_id":"VER-ROT128-R3","program_set":"DPG1-CASES-R3",
 "results":[{"case_id":"...","digest":"...","decision":"..."},...]}
```

```json
{"flag":"FLAG{783b582e0ba2a939}","record":{"record_id":"VER-ROT128-RESULT-R3",...}}
```
