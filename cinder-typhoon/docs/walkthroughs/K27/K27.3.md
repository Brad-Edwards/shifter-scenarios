Precondition: K27.2 package uploaded. The job_id is the one created in K27.1 (`$JOB`).

**Note: this card requires a paired ARWC range.** The deliver endpoint pushes
the diagnostic job to the ARWC-side fieldlink service. Without a paired ARWC VM
the endpoint returns `customer_connector_unavailable`.

```
COOKIE=$(sqlite3 ~/.config/chromium/Default/Cookies "select value from cookies where name='fieldkest_support'")  # rowan's support session cookie
# Connect to your KeplerOps range host (use your range's access method), then:
sudo docker exec --user rowan cinder-keplerops-k-dev bash
```

```
# JOB is the job_id obtained in K27.1 (e.g. DIAG-ARWC-XXXXXXXX)
curl -sk -H "Cookie: fieldkest_support=$COOKIE" -H "Content-Type: application/json" \
  -d '{}' \
  "https://support.keplerops.test/api/diagnostics/$JOB/deliver"
```
