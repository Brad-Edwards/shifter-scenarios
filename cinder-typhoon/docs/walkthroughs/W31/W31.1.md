## Step 1: Discover the vault record

```bash
TOKEN=$(cat handover/corporate-session)
curl -s --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-ARWC-Tenant: arwc" \
  https://process-view.arwc.test/api/vault-records/current
```
