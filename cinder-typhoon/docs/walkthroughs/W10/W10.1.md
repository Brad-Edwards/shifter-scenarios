Requires W06.3 (Metabase session). Get the `business.report-sources` route from the planning-data client doc. Run the SEL-CRR-DP3-7 Metabase question to recover the source-selection record.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"}
planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

# Get the report-sources route.
doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client", headers=h),
    context=ctx).read())
sources_url = next(r["template"] for r in doc["routes"] if r["key"] == "business.report-sources")
# sources_url = https://reports.arwc.test/api/card/<card_id>
card_id = sources_url.rstrip("/").split("/")[-1]

result = json.loads(urllib.request.urlopen(
    urllib.request.Request(f"https://reports.arwc.test/api/card/{card_id}/query",
                            data=b"{}", headers=mb_h, method="POST"),
    context=ctx, timeout=30).read())

cols = [c["name"] for c in result["data"]["cols"]]
rows = result["data"]["rows"]
rec = dict(zip(cols, rows[0]))
print("record_id:", rec["record_id"])        # SEL-CRR-DP3-7
print("district:", rec["district"])          # Cairn Reach
print("allocation_source:", rec["allocation_source"])  # ALLOC-2026-DP3-R9
print("flag:", rec["flag"])                  # FLAG{0657c9326fcc1aed}
```

Flag: `FLAG{0657c9326fcc1aed}` in the `flag` column of the SEL-CRR-DP3-7 query result.
