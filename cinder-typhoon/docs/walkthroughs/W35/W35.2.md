# W35.2 Walkthrough: A quote outside your district

## Prerequisite

W35.1 complete. Corporate access session.

## Steps

The quote lookup checks corporate role but not district membership. Submit the procurement reference from W35.1 with catalog revision 5 and role corporate-reader:

```
TOKEN=$(cat handover/corporate-session)
curl -sS --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{
    "procurement_reference": "PRC-REGIONAL-17",
    "catalog_revision": 5,
    "role": "corporate-reader"
  }' \
  https://business-workplace.arwc.test/api/procurement-quotes/external
```

Expected output:

```json
{"audit_id":"...","flag":"FLAG{8aba65d6162bf904}","record":{"record_id":"QUOTE-MER-884","revision":4,"supplier":"Merewick Bulk Water Cooperative","quantity_ml":0.75,"price_per_ml_usd":2280.0,"planning_window":"ALLOC-2026-DP3","owner_district":"Merewick",...}}
```

Gate: W35.1 (procurement catalog read) required; `role=corporate-reader`; `procurement_reference=PRC-REGIONAL-17`; `catalog_revision=5`.
