## Prerequisite

W35.2 complete. Corporate access session.

## Steps

The order route checks quote ownership and supplier but trusts the caller-supplied charge district. Submit the Merewick quote against the Cairn Reach budget:

```
TOKEN=$(cat handover/corporate-session)
curl -sS --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{
    "quote_id": "QUOTE-MER-884",
    "expected_revision": 4,
    "supplier": "Merewick Bulk Water Cooperative",
    "quantity_ml": 0.75,
    "planning_window": "ALLOC-2026-DP3",
    "charge_district": "Cairn Reach",
    "budget": "BUD-CRR-DP3"
  }' \
  https://business-workplace.arwc.test/api/invoices/current
```
