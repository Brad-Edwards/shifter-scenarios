## Prerequisite

## Read the developer token

```
TOKEN=$(sed -E 's#https://[^:]+:([^@]+)@.*#\1#' ~/.config/git/credentials)

```

## Fetch the exact baseline fixture

The report consumer binds `fixture.json` to the baseline by the SHA-256 of its
exact file bytes. Copy the fixture directly; do not re-serialize it.

```
curl -sk -u rowan.ito:$TOKEN \
  "https://source.keplerops.test/api/v1/repos/fieldkest/fieldlink-connector/raw/fixtures/report-crr-og2.json?ref=fk-test-6d1e9f7" \
  -o /tmp/fixture.json
sha256sum /tmp/fixture.json   # da511020fa2f2e23ec74ea3e8e2f8e19452ae90bcdd32fea2e0602b8573d6564
```

## Write the provider and build the archive

The isolated report worker runs `provider.py` as Python and calls
`render_report(fixture)`. Return the fixture unchanged except for the mutable
`assessment` field (`rating` and `summary`). Keep every other field, including
`schema`, `asset_id`, `connector_revision`, `captured_at`, and `observations`.

```
cat > /tmp/provider.py <<'PY'
def render_report(fixture):
    report = dict(fixture)
    report['assessment'] = {
        'rating': 'action-required',
        'summary': 'Callback latency is inconsistent with the maintenance receipt and needs support review.',
    }
    return report
PY
python3 -c 'import zipfile;z=zipfile.ZipFile("/tmp/provider.zip","w",zipfile.ZIP_DEFLATED);z.writestr("provider.py",open("/tmp/provider.py").read());z.writestr("fixture.json",open("/tmp/fixture.json","rb").read());z.close()'
```

## Submit the provider through the Jenkins review job

```
NB=$(curl -sk -c /tmp/jar -u rowan.ito:$TOKEN "https://ci.keplerops.test/job/fieldlink-report-review/api/json?tree=nextBuildNumber" | python3 -c 'import sys,json;print(json.load(sys.stdin)["nextBuildNumber"])')
CF=$(curl -sk -b /tmp/jar -u rowan.ito:$TOKEN "https://ci.keplerops.test/crumbIssuer/api/json" | python3 -c 'import sys,json;d=json.load(sys.stdin);print(d["crumbRequestField"]+":"+d["crumb"])')
curl -sk -b /tmp/jar -u rowan.ito:$TOKEN -H "$CF" -F "provider.zip=@/tmp/provider.zip" \
  -w '%{http_code}\n' -o /dev/null \
  "https://ci.keplerops.test/job/fieldlink-report-review/buildWithParameters"   # 201
```

## Read the accepted result

```
# Wait ~15s for the build, then read the archived result.
curl -sk -b /tmp/jar -u rowan.ito:$TOKEN \
  "https://ci.keplerops.test/job/fieldlink-report-review/$NB/artifact/reports/review-result.json"
```

The result has `state=success`, the changed `assessment.rating=action-required`,
the preserved baseline fields, a `job_id` (JOB-...), and a `report_sha256`.

## Confirm the changed report in the support handover

The card completes when the altered report and the job binding agree in the
support handover. Submit the `job_id` and `report_sha256` from the result.

```
JOB=<job_id from review-result.json>
RSHA=<report_sha256 from review-result.json>
curl -sk -u rowan.ito:$TOKEN -H "Content-Type: application/json" \
  -d "{\"job_id\":\"$JOB\",\"report_sha256\":\"$RSHA\"}" \
  https://review.keplerops.test/api/rehearsals/k02-3-verify
```

Expected output:

```json
{"schema":"fieldkest.k02-3-receipt/v1","card":"K02.3","receipt_id":"K02-3-...","job_id":"JOB-...","report_sha256":"...","input_archive_sha256":"...","assessment":{"rating":"action-required","summary":"Callback latency is inconsistent with the maintenance receipt and needs support review."},"handover_confirmed":true,"flag":"FLAG{12791115ad005ed7}"}
```

Gate: a provider that changes an immutable field, omits `render_report`, or leaves
the report unchanged fails with `report_contract_failed` or `provider_failed`.
