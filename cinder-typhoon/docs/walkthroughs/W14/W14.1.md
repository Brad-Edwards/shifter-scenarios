Use contractor_session from W13.4.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
contractor = pathlib.Path("receipts/contractor-session").read_text().strip()
h = {"Authorization": "Bearer " + contractor, "X-ARWC-Tenant": "arwc"}

d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://contractor-portal.arwc.test/api/field-kits/current", headers=h),
    context=ctx).read())
bag = d["record"]
print("protocol:", bag["retained_client"]["protocol"])  # fieldbag/v1
print("inspection:", bag["inspection"])                 # INSP-CRR-2026-09-18
print("flag:", d["flag"])                               # FLAG{8095bac46a61f18f}
```

Flag: `FLAG{8095bac46a61f18f}` in the top-level `flag` field.
