Use contractor_session from W13.4. Access the field gateway service to discover the current process-read protocol.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
contractor = pathlib.Path("receipts/contractor-session").read_text().strip()
h = {"Authorization": "Bearer " + contractor, "X-ARWC-Tenant": "arwc"}

d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://field-gateway.arwc.test/api/instruments/current", headers=h),
    context=ctx).read())
rec = d["record"]
services = rec["services"]
current = next(s for s in services if s["status"] == "active")
print("protocol:", current["protocol"])   # process-read/v2
print("encoding:", current["encoding"])   # application/cbor
print("flag:", d["flag"])                 # FLAG{dda40f67ae90302c}
```

Flag: `FLAG{dda40f67ae90302c}` in the top-level `flag` field.
