## Find the release review task

```
pid=$(rpc '{"jsonrpc":"2.0","id":1,"method":"getProjectByIdentifier","params":{"identifier":"FIELDLINK"}}' \
  | python3 -c 'import sys,json;print(json.load(sys.stdin)["result"]["id"])')
tid=$(rpc "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"getAllTasks\",\"params\":{\"project_id\":$pid,\"status_id\":1}}" \
  | python3 -c 'import sys,json;[print(t["id"]) for t in json.load(sys.stdin)["result"] if t.get("reference")=="REL-FLK-7.4.2-09"]')
echo "task $tid, reference REL-FLK-7.4.2-09"
```

## Read the review attachment (K01.3 acceptance check)

