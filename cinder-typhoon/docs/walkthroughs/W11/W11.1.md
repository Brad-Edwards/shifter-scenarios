Requires W09.4 (integration session, process_session). Use the planner session (Metabase session) to query the relation schema.

The `planning.relation-schema` route points to a native Metabase question that shows the relation contracts/schemas.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
# The planner_session IS the Metabase session ID (from W06.3)
planner = pathlib.Path("receipts/planner-session").read_text().strip()

# Call the relation-schema Metabase question
# Discover the planning.relation-schema route template from the client document
# Then call it with the Metabase session header
resp = urllib.request.urlopen(
    urllib.request.Request(
        "https://reports.arwc.test/api/card/<relation-schema-card-id>/query",
        data=b"{}",
        headers={"Content-Type": "application/json", "X-Metabase-Session": planner},
        method="POST"),
    context=ctx, timeout=30)
result = json.loads(resp.read())
cols = [c["name"] for c in result["data"]["cols"]]
rows = result["data"]["rows"]
print("schema:", dict(zip(cols, rows[0])))
# Flag: FLAG{362994ae7c0d0a41} in the flag column
```

Flag: `FLAG{362994ae7c0d0a41}` in the `flag` column of the relation schema query result. NOTE: Flag placement via Metabase SQL column in the seed script.
