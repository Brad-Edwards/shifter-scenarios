data_hex is 1024+ hex chars. Chars 160-1023 contain the runtime descriptor (JSON with worker_session, exception_record, completion_route). Decode with:

```python
import json
data_bytes = bytes.fromhex(data_hex[160:1024])
descriptor = json.loads(data_bytes.rstrip(b'\x00'))
worker_session = descriptor["worker_session"]
```

Save this `data_hex`. The extended read writes its own payload into the arena and
overwrites the descriptor region (bytes 72-511). The service seeds the descriptor
only once, at the first K04.1 mutation, so a later read returns zeros. K04.2 needs
this first `data_hex` to restore the descriptor and recover `worker_session`.

Gate: datalen<512 → no descriptor exposure. K04.1 must precede.
