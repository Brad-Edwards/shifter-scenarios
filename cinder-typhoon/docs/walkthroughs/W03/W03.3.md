Query the PostgREST integration API at read-data.arwc.test.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")

# Check the OpenAPI schema
schema = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://read-data.arwc.test/"), context=ctx).read())
print("/reserve_report in schema:", "/reserve_report" in schema["paths"])
print("/allocation_ledger in schema:", "/allocation_ledger" in schema["paths"])

# Query the reserve_report
rows = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://read-data.arwc.test/reserve_report?record_id=eq.RPT-CRR-DP3-R7"),
    context=ctx).read())
print("asset:", rows[0]["asset"])   # AST-CRR-017
print("flag:", rows[0]["flag"])     # FLAG{4c92291fb1143aea}
```

Flag: `FLAG{4c92291fb1143aea}` in the `flag` column of the reserve_report query result.
