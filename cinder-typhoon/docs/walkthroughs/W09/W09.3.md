Requires W09.1 and W09.2. Use the planner session (Metabase session ID from W06.3) to query the reserve reconciliation view.

The `planning.allocation-discrepancy` route points to the native Metabase card RECON-DP3-CURRENT (card 42 at reports.arwc.test).

```python
import json, ssl, urllib.request, pathlib
from http.cookiejar import CookieJar
from urllib.request import HTTPCookieProcessor, HTTPSHandler, build_opener, Request

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
# The planner_session IS the Metabase session ID (from W06.3)
planner = pathlib.Path("receipts/planner-session").read_text().strip()

opener = build_opener(HTTPCookieProcessor(CookieJar()), HTTPSHandler(context=ctx))
# Execute the reconciliation Metabase card
resp = opener.open(Request(
    "https://reports.arwc.test/api/card/42/query",
    data=b"{}",
    headers={"Content-Type": "application/json",
             "X-Metabase-Session": planner},
    method="POST"), timeout=30)
result = json.loads(resp.read())
cols = [c["name"] for c in result["data"]["cols"]]
rows = result["data"]["rows"]
row = dict(zip(cols, rows[0]))
print("overstatement_ml:", row.get("overstatement_ml"))  # 1.0
print("flag:", row.get("flag"))                           # FLAG{b938b4afcc7e8a90}
```

Flag: `FLAG{b938b4afcc7e8a90}` in the `flag` column of the reconciliation query result.
