Activate with the activation code from W05.2. Request PLAN-RELIEF-7 (the starter's assignment, not the approved PLAN-RELIEF-3).

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

body = json.dumps({
    "employee_number": "TMP-4821",
    "activation_code": "731944",
    "requested_assignment": "PLAN-RELIEF-7",
}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://corporate-identity.arwc.test/api/temporary-credentials/current",
                            data=body, headers=h, method="POST"),
    context=ctx).read())
rec = d["record"]
print("assignment:", rec["assignment"])        # PLAN-RELIEF-7 (not the approved PLAN-RELIEF-3)
print("administrative:", rec["administrative"])  # False
print("flag:", d["flag"])                      # FLAG{4c78bd2e2f7c25bd}

pathlib.Path("receipts").mkdir(exist_ok=True)
pathlib.Path("receipts/limited-session").write_text(d["limited_session"])
```

Flag: `FLAG{4c78bd2e2f7c25bd}` in the top-level `flag` field of the temporary credential response.
