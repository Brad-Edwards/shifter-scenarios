# W32.4 Walkthrough: Submit the witness

Run replay32 in `witness` mode and send the disputed-trace witness to the execute
endpoint. The service records the optional model evidence for the disputed trace.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user fieldlink --workdir /var/lib/fieldlink-connector cinder-arwc-connector bash -l
```

Prerequisite: W32.3 (`receipts/process-session`, runnable `/var/lib/fieldlink-connector/r32`).

## Step 1: submit the witness (W32.4 acceptance check)

```python
import json, ssl, urllib.request, pathlib, subprocess
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}
witness = json.loads(subprocess.run(["/var/lib/fieldlink-connector/r32", "witness"],
                                     capture_output=True, text=True).stdout)
body = json.dumps({"replay": "REPLAY-CRR-R19", "trace": "TRACE-R19-DISPUTED", "witness": witness}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/replay-sessions/current/execute",
                           data=body, headers=H, method="POST"), context=ctx).read())
print("flag:", d.get("flag"))
print("record:", d["record"]["evidence_role"])
```

Output `flag: FLAG{f4403d8aabe6a550}` with `evidence_role: optional-model-evidence`.

Note: the flag is minted only when fresh plant data is present (the historian path
for W25 and later). The submission is accepted and returns the correct record in all
cases; when the historian data is stale the response omits the flag.
