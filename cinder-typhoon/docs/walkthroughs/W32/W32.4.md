## Step 2: Submit the witness

```python
import json, ssl, urllib.request, pathlib

witness = json.load(open("/tmp/witness.json"))
token = pathlib.Path("handover/corporate-session").read_text().strip()
context = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
body = json.dumps({
    "replay": "REPLAY-CRR-R19",
    "trace": "TRACE-R19-DISPUTED",
    "witness": witness
}).encode()
req = urllib.request.Request(
    "https://process-view.arwc.test/api/replay-sessions/current/execute",
    data=body,
    headers={"Authorization": "Bearer " + token, "X-ARWC-Tenant": "arwc",
             "Content-Type": "application/json"},
    method="POST")
resp = urllib.request.urlopen(req, context=context)
print(json.loads(resp.read()))
```
