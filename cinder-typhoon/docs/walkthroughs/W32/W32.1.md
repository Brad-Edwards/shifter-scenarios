# W32.1 Walkthrough: The disputed replay

Read the replay session record and keep the replay32 binary. The read returns the
flag, the ECS entity model, the distinguishing cases, and the binary for W32.2-W32.4.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user fieldlink --workdir /var/lib/fieldlink-connector cinder-arwc-connector bash -l
```

Prerequisite: `receipts/process-session` from the W09.4 chain.

## Step 1: read the replay session (W32.1 acceptance check)

```python
import json, ssl, urllib.request, pathlib, base64
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc"}
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/replay-sessions/current", headers=H),
    context=ctx).read())
print("flag:", d["flag"])
open("/var/lib/fieldlink-connector/r32", "wb").write(base64.b64decode(d["replay_b64"]))
```

Output `flag: FLAG{1d16a3a336e29908}`. Make the binary runnable in a directory that
allows execution (`/tmp` is noexec):

```
chmod +x /var/lib/fieldlink-connector/r32
```

replay32 is an x86-64 ECS replay tool with three modes: `transitions`, `condition`,
`witness`. W32.2-W32.4 run these modes and send the output.
