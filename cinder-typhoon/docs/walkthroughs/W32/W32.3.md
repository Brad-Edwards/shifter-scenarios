## Step 1: submit the condition (W32.3 acceptance check)

```python
import json, ssl, urllib.request, pathlib, subprocess
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}
condition = json.loads(subprocess.run(["/var/lib/fieldlink-connector/r32", "condition"],
                                       capture_output=True, text=True).stdout)
body = json.dumps({"replay": "REPLAY-CRR-R19", "trace": "TRACE-R19-DISPUTED", "condition": condition}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/estimator-results/current",
                           data=body, headers=H, method="POST"), context=ctx).read())
print("flag:", d["flag"])
```

Output `flag: FLAG{7329a078d7db6108}`. The record shows
`post-ReserveUpdate independently observed Reserve`.
