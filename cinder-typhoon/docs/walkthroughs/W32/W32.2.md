# W32.2 Walkthrough: Reproduce the transitions

Run replay32 in `transitions` mode and send the ECS state transitions to the
estimator. The service reproduces the distinguishing cases.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user fieldlink --workdir /var/lib/fieldlink-connector cinder-arwc-connector bash -l
```

Prerequisite: W32.1 (`receipts/process-session`, runnable `/var/lib/fieldlink-connector/r32`).

## Step 1: submit the transitions (W32.2 acceptance check)

```python
import json, ssl, urllib.request, pathlib, subprocess
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca-bundle.pem")
ps = pathlib.Path("receipts/process-session").read_text().strip()
H = {"Authorization": "Bearer " + ps, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}
transitions = json.loads(subprocess.run(["/var/lib/fieldlink-connector/r32", "transitions"],
                                         capture_output=True, text=True).stdout)
body = json.dumps({"record_id": "REPLAY-CRR-R19", "revision": 19, "transitions": transitions}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/estimator-tasks/current/inputs",
                           data=body, headers=H, method="POST"), context=ctx).read())
print("flag:", d["flag"])
```

Output `flag: FLAG{551d772cb90103fd}` with `cases_reproduced: 4`.
