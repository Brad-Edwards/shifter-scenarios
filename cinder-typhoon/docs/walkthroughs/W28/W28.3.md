After W28.2 (utility_flow_controlled=True).

Build an issuer frame that calls the control-broker's issue-client via the utility binary.
Then use the issued client token to demonstrate readback authority.

POST /api/control-authority with operation="issue":
```json
{"operation":"issue","session_id":"...","length":<len>,"frame_b64":"<issuer frame>"}
```
Returns control_client token.

POST /api/control-authority with operation="readback":
```json
{"operation":"readback","control_client":"<token>","outlet_group":"OG-CRR-02","project":"CRR-CTRL-R21","action":"readback"}
```
