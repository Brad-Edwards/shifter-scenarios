## Prerequisite

K11.1 produced `/tmp/program_model.json`. K11.2 returned
`corpus_result_sha256`. The repository `/tmp/journey-pc` holds the corpus. Set
the same variables:

```
TOKEN=$(sed -E 's#https://[^:]+:([^@]+)@.*#\1#' ~/.config/git/credentials)
CA=~/.local/share/keplerops/ca.crt
EVAL=https://source-tools.keplerops.test:8443/api/policy-compilers/fieldkest-policyc/evaluations
NONCES=https://source-tools.keplerops.test:8443/api/policy-compilers/fieldkest-policyc/nonces
```

## Read an accepted input and the corpus digest

```
CRS=$(grep -oE '[0-9a-f]{64}' /tmp/journey-pc/README.md | head -1)
python3 -c 'import json;c=json.load(open("/tmp/journey-pc/corpus/policy-corpus-2026-09-r4.json"));print([x["input"] for x in c["cases"] if x["accepted"]][0])'
```

## Get a one-use nonce

```
NONCE=$(curl -sS --cacert $CA -u rowan.ito:$TOKEN -X POST -H "Content-Type: application/json" \
  --data-binary '{}' $NONCES | python3 -c 'import sys,json;print(json.load(sys.stdin)["nonce"])')
```

## Submit the accept operation

```
python3 -c 'import json,sys;p=json.load(open("/tmp/program_model.json"));json.dump({"operation":"accept","program_model":p,"policy_input":{"tenant_state":"active","connector_api":"3.0.0","signer_lineage":"fieldkest-release-2026","compatibility_exception":True,"channel":"stable","tenant_class":"standard","nonce":sys.argv[1],"corpus_result_sha256":sys.argv[2]}},open("/tmp/accept_body.json","w"))' "$NONCE" "$CRS"
curl -sS --cacert $CA -u rowan.ito:$TOKEN -X POST -H "Content-Type: application/json" \
  --data-binary @/tmp/accept_body.json $EVAL
```
