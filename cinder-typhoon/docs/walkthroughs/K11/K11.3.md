## Prerequisite

## Derive the condition set

The corpus shows which field values the compiler accepts: `tenant_state` must be
`active`, `connector_api` must be `>= 3.0.0`, `signer_lineage` must be
`fieldkest-release-2026`, and `compatibility_exception` must be `true`. Channel
and tenant class are not policy conditions. Build the condition set in that order.

```
python3 - <<'PY'
import json
condition_set = {"schema": "fieldkest.policy-condition-set/v1", "all": [
    {"field": "tenant_state", "operator": "in", "values": ["active"]},
    {"field": "connector_api", "operator": "semver_gte", "value": "3.0.0"},
    {"field": "signer_lineage", "operator": "in", "values": ["fieldkest-release-2026"]},
    {"field": "compatibility_exception", "operator": "eq", "value": True},
]}
p = json.load(open('/tmp/program_model.json'))
json.dump({"operation": "condition-check", "program_model": p,
    "policy_input": {"corpus_id": "POLICY-CORPUS-2026-09-R4", "condition_set": condition_set}},
    open('/tmp/condition_body.json', 'w'))
PY
```

## Submit the condition check

```
curl -sS --cacert $CA -u rowan.ito:$TOKEN -X POST -H "Content-Type: application/json" \
  --data-binary @/tmp/condition_body.json $EVAL
```
