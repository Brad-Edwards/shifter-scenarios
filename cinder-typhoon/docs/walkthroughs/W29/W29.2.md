# W29.2 Walkthrough: What reserve remains uncommitted

## Step 0 — Access

OT engineering desktop (for historian query):
```
sudo docker exec -it --user fieldlink cinder-arwc-ot-engineering bash
```

Corporate foothold (for API submission):
```
sudo docker exec -it --user fieldlink cinder-arwc-connector bash
```

## Step 1 — Query the OT historian for current UsableVolumeML

On the OT engineering desktop:

```
psql -h postgres -U reader -d historian -c "
SELECT ph.source_time, ph.value, ph.unit, ph.process_quality
FROM public.process_history ph
JOIN public.historian_tag_catalog c ON c.series = ph.tag
WHERE ph.asset = 'AST-CRR-017'
  AND c.variable = 'UsableVolumeML'
  AND ph.source_time >= current_timestamp - interval '5 minutes'
ORDER BY ph.source_time DESC
LIMIT 1"
```

Note `source_time`, `value` (ML), and `process_quality` (must be `Good`).

## Step 2 — Calculate the uncommitted margin

```
uncommitted_margin = measured_usable_volume_ml - 12.0
```

If margin > 0.005: `margin_state = "positive"`
If margin < -0.005: `margin_state = "negative"`
Otherwise: `margin_state = "zero"`
