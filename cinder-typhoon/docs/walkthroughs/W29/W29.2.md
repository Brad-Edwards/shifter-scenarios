Requires W09.4 (process_session) and W29.1 (tariff and allocation observed). Reconcile the planned reserve against the live OT process reserve and submit it to the engineering workbench.

The workbench reads `UsableVolumeML` from the OT historian itself and checks your values within tolerance 0.005, so your submitted `measured_usable_volume_ml` must match a recent Good sample. The committed reserve is fixed at 12.0 ML. Read `UsableVolumeML` from the OT historian with `psql` on the OT engineering container (`cinder-arwc-ot-engineering`); the connector has no route to the historian. Use the source_time of a recent Good sample as `observed_at` (it must be within 5 s of the sample the service picks).

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
proc = pathlib.Path("receipts/process-session").read_text().strip()
h = {"Authorization": "Bearer " + proc, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

# From the OT engineering container:
#   psql -h 172.29.63.22 -U reader -d historian
#   SELECT source_time, value FROM process_history ph
#     JOIN historian_tag_catalog c ON c.series = ph.tag
#    WHERE ph.asset='AST-CRR-017' AND c.variable='UsableVolumeML'
#      AND ph.process_quality='Good'
#    ORDER BY source_time DESC LIMIT 1;
observed_at = "<source_time of that Good sample, ISO 8601 with offset>"
measured = <value of that sample>            # e.g. 12.4
committed = 12.0
margin = measured - committed
margin_state = "positive" if margin > 0.005 else "negative" if margin < -0.005 else "zero"

d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/reserve-reconciliations/current",
        data=json.dumps({
            "planning_window": "ALLOC-2026-DP3", "asset": "AST-CRR-017", "observed_at": observed_at,
            "process_quality": "Good", "measured_usable_volume_ml": measured, "committed_ml": committed,
            "uncommitted_margin_ml": margin, "margin_state": margin_state,
        }).encode(), headers=h, method="POST"), context=ctx).read())
print("flag:", d["flag"])   # FLAG{ea5a5c4c83724109}
```

The workbench records the reconciliation (REC-CRR-DP3-17) and notifies planning-data, which marks the reserve reconciled. This also sets the process-interpretation prerequisite used by the W34 reporting cards.

Flag: `FLAG{ea5a5c4c83724109}` in the top-level `flag` field.
