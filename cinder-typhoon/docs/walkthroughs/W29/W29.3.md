# W29.3 Walkthrough: Paper truth

## Step 0 — Access

Same as W29.2: OT desktop for historian, corporate foothold for submission.

## Step 1 — Identify report RPT-CRR-DP3-R7

From the allocation-ledger.csv (or the corporate planning DB):
- Report `RPT-CRR-DP3-R7`: `reported_ml = 13.4`, `as_of = 2026-11-09T00:00:00Z`

## Step 2 — Get a later historian observation

On the OT engineering desktop (same psql query as W29.2):

```
psql -h postgres -U reader -d historian -c "
SELECT ph.source_time, ph.value, ph.unit, ph.process_quality
FROM public.process_history ph
JOIN public.historian_tag_catalog c ON c.series = ph.tag
WHERE ph.asset = 'AST-CRR-017'
  AND c.variable = 'UsableVolumeML'
  AND ph.source_time >= current_timestamp - interval '5 minutes'
ORDER BY ph.source_time DESC
LIMIT 1"
```

The `source_time` must be AFTER `2026-11-09T00:00:00Z`.

## Step 3 — Calculate signed paper variance

```
signed_paper_variance_ml = 13.4 - measured_usable_volume_ml
```

If variance > 0.005: `direction = "report_above_later_process_value"`
If variance < -0.005: `direction = "report_below_later_process_value"`
Otherwise: `direction = "aligned_within_tolerance"`
