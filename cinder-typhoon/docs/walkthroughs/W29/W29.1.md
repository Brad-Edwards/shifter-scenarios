# W29.1 Walkthrough: The price of this planning window

## Step 0 — Access

```
sudo docker exec -it --user fieldlink cinder-arwc-connector bash
```

Working directory: `/var/lib/fieldlink-connector`

## Step 1 — Read the allocation export

On the OT engineering desktop:

```
sudo docker exec -it --user fieldlink cinder-arwc-ot-engineering bash
cat ~/CairnReach/Briefs/W29/allocation-ledger.csv
```

Note TAR-CRR-DP3-R4 (tariff) and ALLOC-2026-DP3-R9 (allocation) for AST-CRR-017 in ALLOC-2026-DP3.

## Step 2 — Get the planner session

From the corporate foothold, read the planner session:

```
PLANNER=$(cat /var/lib/fieldlink-connector/receipts/planner-session | tr -d '\n')
CORP=$(cat /var/lib/fieldlink-connector/handover/corporate-session | tr -d '\n')
```

## Step 3 — Call GET /api/settlement-tariffs/current

```
curl -s -k -H "Authorization: Bearer $CORP" \
     -H "X-ARWC-Tenant: arwc" \
     -H "X-ARWC-Planner-Session: $PLANNER" \
     https://planning-data.arwc.test/api/settlement-tariffs/current
```

Returns TAR-CRR-DP3-R4 at 2400 USD/ML, effective 2026-11-01 to 2026-12-01.

## Step 4 — Call GET /api/allocation-ledgers/current (flag step)

```
curl -s -k -H "Authorization: Bearer $CORP" \
     -H "X-ARWC-Tenant: arwc" \
     -H "X-ARWC-Planner-Session: $PLANNER" \
     https://planning-data.arwc.test/api/allocation-ledgers/current
```

The response contains `"planning_flag": "FLAG{e3d444e18d2f9106}"` because the tariff endpoint was already called in this session.
