Using practice tank PT-01, transfer_quantity=200 from T04.1. Field guide publishes hold and transfer endpoints:

```bash
curl -s http://state.training:8080/field-guide.md | grep -E 'POST|GET'
# hold: POST /api/practice/hold   transfer: POST /api/practice/transfer
# state: GET /api/practice/state  observations: GET /api/practice/observations

# Clear hold first
curl -s -X POST -H "Content-Type: application/json" \
  -d '{"request_id":"qa4-hold-clear","active":false}' \
  http://state.training:8080/api/practice/hold

# Request transfer of 200L
curl -s -X POST -H "Content-Type: application/json" \
  -d '{"request_id":"qa4-transfer-200","quantity_l":200}' \
  http://state.training:8080/api/practice/transfer
```

```json
{"accepted_at":"...","request_id":"qa4-transfer-200","result":"accepted"}
```

Wait for transfer to complete, then check observations:

```bash
sleep 25
curl -s http://state.training:8080/api/practice/observations | python3 -c "
import sys,json
obs=json.load(sys.stdin)['observations']
term=[o for o in obs if o.get('terminal')]
print(term[-1])
"
```
