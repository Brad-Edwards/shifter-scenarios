# W34.1 Walkthrough: Which view the planner trusts

## Prerequisite

PROCESS_INTERPRETATION capability earned (W23.3 or W27.3). Corporate access session.
Planner session from `receipts/planner-session` (issued at W09.4).

## Steps

POST the planning consumer input binding to the reporting-submissions endpoint:

```
TOKEN=$(cat handover/corporate-session)
PLANNER=$(cat receipts/planner-session)
curl -sS --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-ARWC-Planner-Session: $PLANNER" \
  -H "Content-Type: application/json" \
  --data-binary '{
    "checkpoint": "REH-REPORT-34",
    "consumer": "PLAN-CONSUMER-R8",
    "consumer_revision": 8,
    "source": "DPG-CRR-CINDER",
    "estimate": {"Cairn Reach": 13.4, "North": 8.1, "Merewick": 7.65},
    "refresh_interval_seconds": 300,
    "raw_observations": ["MTR-CRR-DP3-R12", "FIT-CRR-204A", "FIT-CRR-204B"]
  }' \
  https://planning-data.arwc.test/api/reporting-submissions/current/result
```

Expected output:

```json
{"audit_id":"...","flag":"FLAG{509426611d275191}","record":{"record_id":"VIEW-CRR-34","revision":1,"checkpoint":"REH-REPORT-34","consumer":"PLAN-CONSUMER-R8","consumer_revision":8,"source":"DPG-CRR-CINDER","estimate":{"Cairn Reach":13.4,"North":8.1,"Merewick":7.65},"unit":"ML","quality":"valid","refresh_interval_seconds":300,...}}
```

Gate: requires process_interpretation_prerequisite; estimate `{"Cairn Reach": 13.4, "North": 8.1, "Merewick": 7.65}` must come from the W23/W27 estimator path and pass consumer validation.
