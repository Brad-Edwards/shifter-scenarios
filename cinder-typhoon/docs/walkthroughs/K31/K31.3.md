# K31.3 Walkthrough: The maintenance label

Precondition: the K31.1 runtime credential (`$RUNTIME`) and the K31.2 attestation.

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Step 1: get the runtime credential and the attestation

```
CA=~/.local/share/keplerops/ca.crt
DEV=$(sed -E 's#https://([^@]+)@.*#\1#' ~/.config/git/credentials)
WORKLOAD=$(curl -sS --cacert $CA -u "$DEV" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/workspaces/current/token-exchange \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
ROLE=$(curl -sS --cacert $CA -H "Authorization: Bearer $WORKLOAD" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/token-exchange/support-export-editor \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
RUNTIME=$(curl -sS --cacert $CA -H "Authorization: Bearer $ROLE" \
  https://cloud-api.keplerops.test/api/maintenance \
  | grep -o '"runtime_credential":"[^"]*"' | cut -d'"' -f4)
WORKER=$(curl -sS --cacert $CA -H "Authorization: Bearer $ROLE" \
  https://cloud-api.keplerops.test/api/maintenance \
  | grep -o '"worker_credential":"[^"]*"' | cut -d'"' -f4)
curl -sS --cacert $CA -X PATCH -H "Authorization: Bearer $WORKER" \
  -H 'Content-Type: application/json' \
  --data-binary '{"command":["maintenance-summary","--archive","FIELD-CRR-2026-09"],"labels":{"workload.class":"maintenance"}}' \
  https://workloads.keplerops.test/api/workloads/MAINT-FLK-01 >/dev/null
ATTEST=$(curl -sS --cacert $CA -H "Authorization: Bearer $WORKER" \
  https://workloads.keplerops.test/api/workloads/MAINT-FLK-01/whoami \
  | grep -o '"attestation":"[^"]*"' | cut -d'"' -f4)
```

## Step 2: read the field archive with the workload-class and attestation headers (K31.3 acceptance check)

```
curl -sS --cacert $CA -H "Authorization: Bearer $RUNTIME" \
  -H "X-Workload-Class: maintenance" \
  -H "X-Scheduler-Attestation: $ATTEST" \
  https://data.keplerops.test/api/field-archive/FIELD-CRR-2026-09
```

Output:

```json
{"archive_id":"FIELD-CRR-2026-09","asset":"CRR-OG2","calibration_revision":"CRR-OG2-CAL-2026-09-18","flag":"FLAG{fde258527cfc25b1}","runtime_identity":"svc-fieldlink-maintenance"}
```
