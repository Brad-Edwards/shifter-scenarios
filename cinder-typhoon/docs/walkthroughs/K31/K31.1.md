# K31.1 Walkthrough: Whose maintenance job

Precondition: the K14.2 export role token (`$ROLE`).

## Step 0: open a participant shell

```
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Step 1: get the export role token

```
CA=~/.local/share/keplerops/ca.crt
DEV=$(sed -E 's#https://([^@]+)@.*#\1#' ~/.config/git/credentials)
WORKLOAD=$(curl -sS --cacert $CA -u "$DEV" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/workspaces/current/token-exchange \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
ROLE=$(curl -sS --cacert $CA -H "Authorization: Bearer $WORKLOAD" \
  -H 'Content-Type: application/json' -d '{}' \
  https://cloud-api.keplerops.test/api/token-exchange/support-export-editor \
  | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)
```

## Step 2: read the maintenance index and capture the credentials

The worker and runtime credentials are specific to each range. Capture them.

```
curl -sS --cacert $CA -H "Authorization: Bearer $ROLE" \
  https://cloud-api.keplerops.test/api/maintenance
WORKER=$(curl -sS --cacert $CA -H "Authorization: Bearer $ROLE" \
  https://cloud-api.keplerops.test/api/maintenance \
  | grep -o '"worker_credential":"[^"]*"' | cut -d'"' -f4)
RUNTIME=$(curl -sS --cacert $CA -H "Authorization: Bearer $ROLE" \
  https://cloud-api.keplerops.test/api/maintenance \
  | grep -o '"runtime_credential":"[^"]*"' | cut -d'"' -f4)
```

The index gives `policy_id=fieldlink-maintenance`, `workload_id=MAINT-FLK-01`,
`field_archive=FIELD-CRR-2026-09`, `$WORKER`, and `$RUNTIME`.

## Step 3: read the maintenance policy (K31.1 acceptance check)

The policy needs the worker credential; the plain developer token is denied.

```
curl -sS --cacert $CA -H "Authorization: Bearer $WORKER" \
  https://cloud-api.keplerops.test/api/policies/fieldlink-maintenance
```

Output:

```json
{"archive_request":{"headers":{"scheduler_attestation":"X-Scheduler-Attestation","workload_class":"X-Workload-Class"}},"command":["maintenance-summary","--archive","FIELD-CRR-2026-09"],"flag":"FLAG{c3f9834223486bbe}","management_caller":"svc-fieldkest-runner","policy_id":"fieldlink-maintenance","required_label":{"workload.class":"maintenance"},"runtime_identity":"svc-fieldlink-maintenance","scheduler":"fieldkest-scheduler","whoami":"svc-fieldkest-runner"}
```
