## Prerequisites

- K06.1 gives the registry publisher credential `fieldlink-importer-publisher:fk_registry_publisher_...`.
- K29.1 gives the release-reader token, the dossier `deleted_commit`, and `rollover_record.passphrase_half`.
- K29.2 gives `signer-history.json` (`key_id`, `lineage`, `passphrase_half`) and the encrypted signer seed.

Each step below stores a value in a shell variable and the next step uses it. Run the steps in order in one shell.

## Build the compatible release package

The package must support connector v2 and v3. Build it deterministically.

```
python3 - "$NAME" "$VER" "$IFACE" <<'PY'
import base64,gzip,io,json,sys,tarfile,hashlib
name,ver,iface=sys.argv[1],sys.argv[2],sys.argv[3]
metadata={"name":name,"version":ver,"fieldkest":{"interface":iface,"compatible_interfaces":["fieldkest.connector/v2",iface]}}
src=b"const run = input => ({schema:'fieldkest.rehearsal-result/v1',tenant_id:input.tenant_id,asset_id:input.asset_id,assessment:input.schema === 'fieldkest.connector/v2' ? 'reference-compatible' : 'calibration-review'}); exports.consume = run; exports.diagnostic_summary = run;\n"
raw=io.BytesIO()
with tarfile.open(fileobj=raw,mode="w",format=tarfile.USTAR_FORMAT) as ar:
    for n,p in (("package/index.js",src),("package/package.json",json.dumps(metadata,sort_keys=True,separators=(",",":")).encode())):
        i=tarfile.TarInfo(n);i.size=len(p);i.mtime=0;i.mode=0o644;i.uid=i.gid=0;ar.addfile(i,io.BytesIO(p))
out=io.BytesIO()
with gzip.GzipFile(fileobj=out,mode="wb",mtime=0,filename="") as z: z.write(raw.getvalue())
data=out.getvalue()
open("/tmp/journey-pkg.tgz","wb").write(data)
open("/tmp/journey-pkg.sha256","w").write(hashlib.sha256(data).hexdigest())
print("sha256",hashlib.sha256(data).hexdigest())
PY
DIGEST=$(cat /tmp/journey-pkg.sha256)
B64=$(base64 -w0 /tmp/journey-pkg.tgz)
echo "digest=$DIGEST"
```

Output: `sha256 432ce8eb436da27239ddb0680c50de1ef9184c1406ef2cfdb51f26ab4f89ae84`

## Sign the release message with the recovered signer

Password is `rollover_record.passphrase_half` + `signer-history.passphrase_half`.

```
SIG=$(python3 - "$NAME" "$VER" "$IFACE" "$DIGEST" "$HALF_A" "$HALF_B" <<'PY'
import base64,hashlib,json,sys
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
name,ver,iface,digest,half_a,half_b=sys.argv[1:7]
w=json.loads(open("/tmp/signer.enc.json").read())
key=hashlib.scrypt((half_a+half_b).encode(),salt=base64.b64decode(w["kdf"]["salt_base64"]),n=w["kdf"]["n"],r=w["kdf"]["r"],p=w["kdf"]["p"],dklen=32)
seed=AESGCM(key).decrypt(base64.b64decode(w["cipher"]["nonce_base64"]),base64.b64decode(w["cipher"]["ciphertext_base64"])+base64.b64decode(w["cipher"]["tag_base64"]),w["cipher"]["aad"].encode())
msg=json.dumps({"interfaces":["fieldkest.connector/v2",iface],"name":name,"sha256":digest,"version":ver},sort_keys=True,separators=(",",":")).encode()
print(base64.b64encode(Ed25519PrivateKey.from_private_bytes(seed).sign(msg)).decode())
PY
)
echo "$SIG"
```

## Approve the signed release (K29.3 acceptance check)

```
curl -sk -X POST -H "Authorization: Bearer $PUBTOK" -H "Content-Type: application/json" \
  --data-binary "{\"version\":\"$VER\",\"interfaces\":[\"fieldkest.connector/v2\",\"$IFACE\"],\"lineage\":\"$LINEAGE\",\"key_id\":\"$KEYID\",\"signature_base64\":\"$SIG\"}" \
  https://delivery.keplerops.test:8443/api/releases/REL-FLK-$VER/approval
echo
```

Output: `{"approved":true,"signed":true,"flag":"FLAG{bd3422ac88bd90d8}","channel_credentials":{"grants":{"poll":{...},"activate":{...},"rollback":{...},"receipt":{...}}},...}` (HTTP 201)

```

  --data-binary "{\"version\":\"$VER\",\"consumer\":\"arwc-release-v3\",\"input\":{\"schema\":\"$IFACE\",\"tenant_id\":\"TEN-ARWC-047\",\"asset_id\":\"CRR-OG2\",\"operation\":\"diagnostic_summary\"}}" \
  https://review.keplerops.test/api/rehearsals/connector
echo
```

Output: `{"state":"success","consumer":"arwc-release-v3","version":"7.4.3-cinder.rset1","output":{"assessment":"calibration-review",...},...}` (HTTP 202)

K29.3 flag: `FLAG{bd3422ac88bd90d8}` in the approval response.

Gate: publisher token without a signature → `release_signature_required` (403). Wrong signature → `release_signature_denied` (422). Interfaces not `[v2, v3]` → `interface_contract_denied` (422).
