## Compute the K29.2 lineage proof signature

Sign the canonical proof message `{"key_id":<old>,"lineage":<lineage>}` with the recovered old signer.

```
PROOF=$(python3 - "$KEYID" "$LINEAGE" "$HALF_A" "$HALF_B" <<'PY'
import base64,hashlib,json,sys
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
key_id,lineage,half_a,half_b=sys.argv[1:5]
w=json.loads(open("/tmp/signer.enc.json").read())
k=hashlib.scrypt((half_a+half_b).encode(),salt=base64.b64decode(w["kdf"]["salt_base64"]),n=w["kdf"]["n"],r=w["kdf"]["r"],p=w["kdf"]["p"],dklen=32)
seed=AESGCM(k).decrypt(base64.b64decode(w["cipher"]["nonce_base64"]),base64.b64decode(w["cipher"]["ciphertext_base64"])+base64.b64decode(w["cipher"]["tag_base64"]),w["cipher"]["aad"].encode())
msg=json.dumps({"key_id":key_id,"lineage":lineage},sort_keys=True,separators=(",",":")).encode()
print(base64.b64encode(Ed25519PrivateKey.from_private_bytes(seed).sign(msg)).decode())
PY
)
echo "$PROOF"
```


K29.4 flag: `FLAG{fb7f87b5a1ca1ce8}` in the verify response.

Gate: missing `k29_2_signature_base64` → `lineage_proof_required` (422). Wrong proof → `lineage_proof_signature_invalid` (422). ARWC assessment not `calibration-review`, or reference not `reference-compatible`, or version mismatch → 422.
