Step 1: Compute the K29.2 lineage proof signature.

Decrypt the signer from the deleted commit using password = dossier.rollover_record.passphrase_half + history.passphrase_half.
Then sign canonical_bytes({"key_id":"fk-release-2026-old","lineage":"fieldkest-release-2026"}).

```python
import base64, hashlib, json
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

wrapped = json.loads(open('/tmp/release-signer.enc.json').read())
password = (rollover_passphrase_half + history_passphrase_half).encode()
kdf = wrapped["kdf"]
key = hashlib.scrypt(password, salt=base64.b64decode(kdf["salt_base64"]), n=kdf["n"], r=kdf["r"], p=kdf["p"], dklen=32)
c = wrapped["cipher"]
seed = AESGCM(key).decrypt(base64.b64decode(c["nonce_base64"]), base64.b64decode(c["ciphertext_base64"]) + base64.b64decode(c["tag_base64"]), c["aad"].encode())
proof_message = json.dumps({"key_id":"fk-release-2026-old","lineage":"fieldkest-release-2026"}, sort_keys=True, separators=(",",":")).encode()
sig = Ed25519PrivateKey.from_private_bytes(seed).sign(proof_message)
print(base64.b64encode(sig).decode())
```
