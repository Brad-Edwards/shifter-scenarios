## Read the diagnostic program

The diagnostic program endpoint returns the flag and a base64 ELF artifact. The
artifact embeds the migration record as a plain ASCII run in its `.rodata`.

```bash
PROCESS=$(cat receipts/process-session)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  https://process-view.arwc.test/api/diagnostic-programs/current -o /tmp/diag.json
python3 - <<'PY'
import json, base64, re, hashlib
d = json.load(open("/tmp/diag.json"))
print("flag:", d["flag"])
print("record_id:", d["record"]["record_id"])
print("project_family:", d["record"]["project_family"])
art = base64.b64decode(d["artifact_b64"], validate=True)
assert art.startswith(b"\x7fELF"), "not an ELF image"
assert hashlib.sha256(art).hexdigest() == d["record"]["sha256"], "artifact digest mismatch"
mig = next(s.decode() for s in re.findall(rb"[ -~]{6,}", art) if s.decode().startswith("MIG-"))
print("migration_record:", mig)
PY
```

Expected: `flag: FLAG{a701d55117606501}`, `project_family: CRR-CTRL-R19`,
`migration_record: MIG-OG2-R19-R21`.

## Recover the binary's hash (used in W19.2 and W19.3)

Read the binary's disassembly to recover its two hashes. Do not run the ELF.

- Rolling 32-bit hash: start at `0x6D2B79F5`. For each input byte, rotate
  `state XOR byte` left by 5 bits in 32 bits, then add `0x9E3779B9` in 32 bits.
- Verifier 64-bit hash: `rotl64(0x243F6A8885A308D3 XOR (rolling * 0x100000001B3), 9) XOR rolling`.

```bash
python3 - <<'PY'
def rotl(x, r, bits):
    mask = (1 << bits) - 1
    x &= mask
    return ((x << r) | (x >> (bits - r))) & mask
def rolling(rec):
    mask = (1 << 32) - 1
    v = 0x6D2B79F5
    for b in rec.encode():
        v = (rotl((v ^ b) & mask, 5, 32) + 0x9E3779B9) & mask
    return v
def verifier(rec):
    mask = (1 << 64) - 1
    v = rolling(rec)
    return rotl(0x243F6A8885A308D3 ^ ((v * 0x100000001B3) & mask), 9, 64) ^ v
mig = "MIG-OG2-R19-R21"
print(f"rolling32  = {rolling(mig):08x}")
print(f"verifier64 = {verifier(mig):016x}")
PY
```

Expected: `rolling32 = d0b09731`, `verifier64 = 50b1d433b771b618`. This matches
the 8-byte little-endian value the binary prints for `MIG-OG2-R19-R21`. The flag
is in the top-level `flag` field of the diagnostic-program response.
