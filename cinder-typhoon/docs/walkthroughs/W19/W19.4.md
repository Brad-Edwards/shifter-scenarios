## Build the mapping and its comparison digest

The service binds the mapping by the SHA-256 of its canonical JSON (sorted keys,
no spaces). The mapping relates the legacy project to the current project, the
legacy outlet identifiers, and the two outlet instruments.

```bash
PROCESS=$(cat receipts/process-session)
BODY=$(python3 - <<'PY'
import json, hashlib
mapping = {
    "legacy_project": "CRR-CTRL-R19",
    "current_project": "CRR-CTRL-R21",
    "legacy_identifiers": {"OUTLET_A": "OG-CRR-02/GT-CRR-02A", "OUTLET_B": "OG-CRR-02/GT-CRR-02B"},
    "instruments": {"OUTLET_A": "FIT-CRR-204A", "OUTLET_B": "FIT-CRR-204B"},
}
digest = hashlib.sha256(json.dumps(mapping, sort_keys=True, separators=(",", ":")).encode()).hexdigest()
print(json.dumps({"migration_record": "MIG-OG2-R19-R21", "comparison_digest": digest, "observation": "EVT-COMM-OG2-114"}))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST \
  https://process-view.arwc.test/api/diagnostic-programs/legacy
```

The computed `comparison_digest` is
`63992721c574fc22a8c7e721045ca0b5d8d265235e7493ccc089541fe2e99f8d`.
