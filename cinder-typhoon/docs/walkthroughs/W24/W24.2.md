## Predict the next padding class for each case

For each prediction case, run the recovered selector over `(request_id,
epoch_bucket)`, take the low two bits as a rotation, and rotate the observed
padding class forward by that amount. A wrong prediction is rejected with 409.

```bash
PROCESS=$(cat receipts/process-session)
PV=https://process-view.arwc.test
BODY=$(python3 - <<'PY'
import json
d = json.load(open("/tmp/w24.json")); m = json.load(open("/tmp/w24model.json"))
mask = (1 << 64) - 1
def selector(rid, eb):
    x = (rid ^ m["request_constant"]) & mask; y = (eb ^ m["epoch_constant"]) & mask
    x = (x ^ ((x << m["left_shift"]) & mask)) & mask
    return ((x ^ y ^ (x >> m["request_shift"]) ^ (y >> m["epoch_shift"])) + y) & mask
contract = d["record"]
preds = []
for c in contract["prediction_cases"]:
    rot = selector(int(c["request_id"], 16), c["epoch_bucket"]) & 3
    observed = "ABCD"[("ABCD".index(c["padding_class"]) + rot) & 3]
    preds.append({"request_id": c["request_id"], "epoch_bucket": c["epoch_bucket"], "observed_class": observed})
print(json.dumps({"record_id": contract["engineering_record"], "prediction_set": "SELECTOR-CRR-R4", "predictions": preds}))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST \
  "$PV/api/signature-oracles/current"
```
