After W24.2. Recover archive-unlock value via Bleichenbacher RSA PKCS#1 v1.5 padding oracle attack.

Oracle endpoint: POST /api/estimator-tasks/current with operation="oracle".
- ciphertext: 512-hex string (RSA ciphertext to test)
- request_id: 16-hex random string (determines rotation via xorshift128+)
- epoch_bucket: must equal EPOCH_BUCKET from W24.1 response
- Returns observed_class A-D (rotated by selector(request_id, epoch_bucket) & 3)
- Limit: 4096 unique queries
- Class D = structurally valid PKCS#1 v1.5 padding with ENG1 tag

Bleichenbacher attack recovers plaintext m = 0x0002<padding>00ENG1<unlock>.
archive_unlock = last 36 bytes of m (after 0x00 separator).
