After W15.3, use the review_capability token with the inspection from W13.1.

```python
import json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
contractor = pathlib.Path("receipts/contractor-session").read_text().strip()
review_cap = pathlib.Path("receipts/review-capability").read_text().strip()
h = {"Authorization": "Bearer " + contractor, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

body = json.dumps({
    "review_capability": review_cap,
    "approval_id": "APR-CRR-4417-R6",
    "inspection": "INSP-CRR-2026-09-18",
}).encode()
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://maintenance-review.arwc.test/api/approval-tokens/current",
                            data=body, headers=h, method="POST"),
    context=ctx).read())
rec = d["record"]
print("status:", rec["status"])   # signed
print("flag:", d["flag"])         # FLAG{f0c8905464c8ef69}
```

Flag: `FLAG{f0c8905464c8ef69}` in the top-level `flag` field.
