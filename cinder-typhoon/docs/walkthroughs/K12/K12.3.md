# K12.3 Walkthrough: The privileged render runs

## Prerequisite

K12.2 complete. PRV-771 is in state=prepared with queue=privileged-review.

## Vulnerability

The autonomous `_privileged_review_worker` polls for reviews in state=prepared and queue=privileged-review. It fetches the content from the internal review-content server and renders it via Gotenberg. It does not re-validate provenance before rendering — it trusts the prepared state. A participant who poisoned the review via K12.1 (BOLA) and K12.2 (nonce intercept) makes the real worker render participant-controlled content.

## Steps

The participant waits. The worker runs every 5 seconds and processes PRV-771 automatically. No participant action is required.

Poll the review state until `state` changes to `rendered`:

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Authorization: Bearer $TOKEN" \
  https://preview.keplerops.test/api/preview/reviews/PRV-771
```

Expected output when rendered:

```json
{"compatibility_summary":"fieldlink.connector/v3 compatible","flag":"FLAG{7b89fd70e897ed74}","queue":"privileged-review","render_digest":"...","renderer_identity":"svc-preview-reviewer","review_id":"PRV-771","schema":"fieldkest.preview-review/v1","source_id":"doc-9bc054d6f95dfa6a","state":"rendered","support_receipt":"PRV-RCPT-...","worker_scope":"/review/"}
```

The flag appears only when `state=rendered`. K12.3 is complete.
