After W26.3. Same shell session — $CONTRACTOR_TOKEN, $APPROVAL, and $RENDERER_ATTEST are set.

## Issue a scoped control client via the control broker (W26.4 acceptance check)

The contractor session is the issuer credential for the control broker. The
renderer_attestation proves the renderer ran successfully.

```bash
curl -s --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $CONTRACTOR_TOKEN" \
  -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" \
  -d "{\"approval\":$APPROVAL,\"outlet_group\":\"OG-CRR-02\",\"project\":\"CRR-CTRL-R21\",\"actions\":[\"plan-execute\",\"readback\"],\"renderer_attestation\":\"$RENDERER_ATTEST\"}" \
  -X POST https://control-broker.arwc.test/api/approval-clients/current
```

```json
{"audit_id":"<uuid>","record":{"record_id":"CTRL-CLIENT-CRR-26","revision":1,"approval":"APR-CRR-4417-R6","inspection":"INSP-CRR-2026-09-18","outlet_group":"OG-CRR-02","project":"CRR-CTRL-R21","actions":["plan-execute","readback"],"issued_at":"...","expires_at":"..."},"control_client":"<client_token>","flag":"FLAG{dcad7d22a6c5fb80}"}
```

Save the control_client token for W27+:

```bash
CONTROL_CLIENT="<control_client value from response>"
```

Gate: 403 "valid renderer attestation required" means the renderer_attestation does not match
the renderer evidence — re-run W26.3 on the same range (do not reuse from another attempt).
Gate: 403 "issuer evidence required" means the contractor token is stale — re-run W13.4.
Gate: 409 means the approval, outlet_group, project, or actions binding does not match.
