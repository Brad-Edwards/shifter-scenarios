## Execute renderer to fetch the maintenance control handover (W26.3 acceptance check)

```bash
curl -s --cacert /tmp/arwc-ca.crt \
  -H "Authorization: Bearer $CONTRACTOR_TOKEN" \
  -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" \
  -d '{"work_package":"WP-CRR-CINDER-R1","approval":"APR-CRR-4417-R6","action":"fetch_handover","argument":"HND-MAINT-CTRL-09"}' \
  -X POST https://maintenance-renderer.arwc.test/api/preview-executions
```
