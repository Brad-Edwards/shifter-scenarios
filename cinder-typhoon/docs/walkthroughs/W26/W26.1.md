Requires contractor session from W13.4 and signed approval from maintenance-review.arwc.test.

## Step 0 — open the participant shell

```bash
gcloud compute ssh <range-vm> --project prod-mgau4w --zone us-central1-a --tunnel-through-iap
sudo docker exec --user fieldlink --workdir /var/lib/fieldlink-connector cinder-arwc-connector bash -l
```

## Step 1 — load the contractor session token

The contractor check-in (W13.4) writes the bearer token to `receipts/contractor-session`.
If you get a 403 below, the token is stale (re-run W13.4 to get a fresh one).

```bash
CONTRACTOR_TOKEN=$(cat receipts/contractor-session)
```

## Step 2 — read the renderer profile (W26.1 acceptance check)

```bash
curl -s --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $CONTRACTOR_TOKEN" \
  -H "X-ARWC-Tenant: arwc" https://maintenance-renderer.arwc.test/api/renderers/current
```

```json
{"flag":"FLAG{660639096fab0268}","record":{"record_id":"RENDER-MAINT-CRR-R9","approval":"APR-CRR-4417-R6","inspection":"INSP-CRR-2026-09-18",...}}
```

Gate: 403 "maintenance renderer session required" means the contractor token is missing or stale — re-run W13.4.
