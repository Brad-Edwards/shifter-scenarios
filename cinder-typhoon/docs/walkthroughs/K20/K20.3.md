## Prerequisites: K20.2 (release_admin_token)

## Get administration session to find version and approval_request fields

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Authorization: Bearer <release_admin_token>" \
  https://delivery.keplerops.test:8443/api/release-administration/session
```

Output: `{"principal":"svc-release-admin","approval_scope":"fieldlink-connector-rehearsal","approval_request":{"version":"7.4.3-cinder.rset1","interfaces":["fieldkest.connector/v2","fieldkest.connector/v3"],"lineage":"fieldkest-release-2026","key_id":"fk-release-2026-old"},"consumer":"support-rehearsal-v3","rehearsal_input":{...}}`

Values used next: `version=7.4.3-cinder.rset1`, `release_id=REL-FLK-7.4.3-cinder.rset1`

## Approve release (K20.3 acceptance check)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Authorization: Bearer <release_admin_token>" \
  -H "Content-Type: application/json" \
  --data-binary '{"version":"7.4.3-cinder.rset1","interfaces":["fieldkest.connector/v2","fieldkest.connector/v3"],"lineage":"fieldkest-release-2026","key_id":"fk-release-2026-old"}' \
  https://delivery.keplerops.test:8443/api/releases/REL-FLK-7.4.3-cinder.rset1/approval
```

Output: `{"flag":"FLAG{cc5504772d80de3d}","release_id":"REL-FLK-7.4.3-cinder.rset1","version":"7.4.3-cinder.rset1","approved":true,"acting_principal":"svc-release-admin",...}`
