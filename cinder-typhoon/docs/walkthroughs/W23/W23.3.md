## Submit the estimator run that never measured the reserve

Submit the allocation case with the reported reserve and quality, and the
unaffected districts (every baseline district except the source and the quality
field). The run reports a sufficient reserve without changing the raw process
observations or the independent instruments.

```bash
PROCESS=$(cat receipts/process-session)
PV=https://process-view.arwc.test
BODY=$(python3 - <<'PY'
import json
district = "Cairn Reach"; reported_ml = 13.4
ordinary = {k: (v if k == "quality" else float(v))
            for k, v in (f.split("=", 1) for f in open("/tmp/w23ord.txt").read().split()[1:])}
fields = dict(l.split("=", 1) for l in open("/tmp/w23rep.txt").read().splitlines() if "=" in l)
allocation_case = fields["case"]
unaffected = {str(k): v for k, v in ordinary.items() if not district.startswith(str(k)) and k != "quality"}
final = {"allocation_case": allocation_case, "district_id": district,
         "reserve_ml": reported_ml, "quality": 1, "unaffected": unaffected}
print(json.dumps(final))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST "$PV/api/estimator-runs"
```

```json
{"audit_id":"...","flag":"FLAG{e8f23ac0d5913bb6}","record":{"sufficient":true,"raw_process_observations_changed":false,"independent_instruments_changed":false,...}}
```

On this scenario `allocation_case` is `ALLOC-CASE-CRR-33` and `unaffected` is
`{"North": 8.1, "Merewick": 7.65}`. On success `record.sufficient` is `true` while
the raw observations and independent instruments are unchanged. The flag is in the
top-level `flag` field.
