After W25.2. Use FUXA HMI (http://172.29.63.21:1881) to set outlet A=30%, B=10%.

1. Log in as operator with operator password.
2. Navigate to crr-controls view.
3. Set HmiTargetPct=30, HmiTargetBPct=10, increment HmiSequence.
4. Note HmiAccepted value after PLC processes request.

POST /api/process-movement/current:
```json
{"record_id":"CRR-OP-W25-R1","hmi_sequence":<accepted_sequence>,"target_a":30,"target_b":10}
```

Engineering service queries OT historian for confirmation. Must be within 60 minutes.

```json
{"flag":"FLAG{fca8c6786592eb89}","record":{"record_id":"W25-MOVEMENT-CRR-R1","actuation_confirmed":true,...}}
```
