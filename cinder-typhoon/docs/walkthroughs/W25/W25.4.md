# W25.4 Walkthrough — Accepted is not actuated (restoration)

Requires W25.3 to pass. Keep the movement sequence from W25.3.

## Step 1 — Issue the restoration HMI command via FUXA browser (participant path)

**Primary path (human participants):**

1. In the FUXA `crr-controls` browser view (still logged in as `operator`).
2. Set **A target** = 20 %, **B target** = 20 %, **mode** = Manual, **flow** = 0.20 m³/s.
3. Click **Apply**. Record the new sequence number.
4. Watch **HmiAccepted**: wait until it matches the new sequence.
5. Watch **PositionPct** and **PositionBPct**: wait until both settle near 20 %.
6. Record `restore_accepted_at` and the final observed timestamp.

**QA scripted equivalent (admin REST only — not the participant path):**

```
# Reuse admin token from W25.3 (or re-authenticate)
SEQ2=$(curl -s "http://172.29.63.21:1881/api/getTagValue?ids=%5B%22HmiAccepted%22%5D" \
  -H "x-access-token: $TOK" \
  | python3 -I -c "import json,sys; print((json.load(sys.stdin)[0]['value'] % 65535) + 1)")

curl -s -X POST http://172.29.63.21:1881/api/setTagValue \
  -H "Content-Type: application/json" -H "x-access-token: $TOK" \
  -d "{\"tags\":[{\"id\":\"HmiTargetPct\",\"value\":20.0},{\"id\":\"HmiTargetBPct\",\"value\":20.0},{\"id\":\"HmiSequence\",\"value\":$SEQ2}]}"

# Poll for acceptance and settled positions
curl -s "http://172.29.63.21:1881/api/getTagValue?ids=%5B%22HmiAccepted%22%2C%22PositionPct%22%2C%22PositionBPct%22%2C%22TotalFlowM3s%22%5D" \
  -H "x-access-token: $TOK"
```

## Step 2 — Collect the historian trace summary

The historian records positions and flows during the interval between movement and restoration.
Read from the OT historian (PostgreSQL) or from the FUXA historian view.

Required summary fields (from the interval `start` to `end`):

- `position_a_min_pct`, `position_a_max_pct`
- `position_b_min_pct`, `position_b_max_pct`
- `total_flow_min_m3s`, `total_flow_max_m3s`
- `sample_count` (number of time-aligned samples)
