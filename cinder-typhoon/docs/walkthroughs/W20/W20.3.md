
After W20.2. Build a new NOR flash record with sequence+1 and status=ACCEPTED, apply programming operations, submit the modified image.

```bash
PROCESS=$(cat receipts/process-session)
# Build new record (see test_w20_nor_flash_image for computation):
# - New target: F204 magic, sequence=119, status_bits=1, instrument=FIT-CRR-204B, CRC32C
# - Operations: program offsets 128, 184, 191
# Wrong operation order gate:
# -> 409

# Correct order:
curl -s --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $PROCESS" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" \
  -d '{"operations":[{"kind":"program","offset":128,"data_b64":"..."},{"kind":"program","offset":184,"data_b64":"..."},{"kind":"program","offset":191,"data_b64":"AA=="}],"image_b64":"..."}' \
  -X POST https://process-view.arwc.test/api/maintenance-records/current
```
