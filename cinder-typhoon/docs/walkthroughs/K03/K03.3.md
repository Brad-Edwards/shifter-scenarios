## Fetch the native object with the developer credentials (K03.3 acceptance check)

The developer identity `rowan.ito` has read access to `fieldlink-collections` through the seeded `~/.aws/credentials`. Fetch the object the manifest names.

```
aws --endpoint-url https://objects.keplerops.test s3api get-object \
  --bucket fieldlink-collections --key callbacks/CB-17/FKCOL-2841.json \
  /tmp/FKCOL-2841.json
python3 -c "import json; d = json.load(open('/tmp/FKCOL-2841.json')); print('flag:', d['flag']); print('ticket:', d['source']['ticket_reference']); print('asset:', d['source']['asset_id'])"
```

```

ticket: SUP-2841
asset: CRR-OG2
```

## Confirm the integrity binding (optional)

The fetched object matches the manifest digest, and the staging `callback-integrity` equals `sha256(PowerShell stage bytes || object bytes)`.

```
python3 -c "import hashlib; print(hashlib.sha256(open('/tmp/FKCOL-2841.json','rb').read()).hexdigest())"
```

This digest equals `object_sha256` from the K03.2 manifest.
