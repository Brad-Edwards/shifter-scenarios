## Recover the staging bundle and decode its instructions (K03.1 acceptance check)

The retained ODT is a ZIP. Extract the staging bundle attachment and decode its base64 `instructions` field.

```
python3 - <<'PY'
import zipfile, base64, json
with zipfile.ZipFile("/home/rowan/work/analysis/field-notes-2026-08.odt") as z:
    stage = z.read("Attachments/staging-FKCOL-2841.bin").decode()
instr_b64 = [l.split("=", 1)[1] for l in stage.splitlines() if l.startswith("instructions=")][0]
instructions = json.loads(base64.b64decode(instr_b64))
print(json.dumps(instructions, indent=2))
PY
```
