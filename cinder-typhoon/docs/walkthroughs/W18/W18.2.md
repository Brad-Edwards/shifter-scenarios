Requires W18.1. Access from the OT engineering desktop or via the connector container.

The register CRR-IO-R364 is in /opt/arwc-ot/challenges/W18/participant/tag-register.csv on the ot-engineering workstation.

FIT-CRR-204B row from tag-register.csv:
- controlled_equipment: GT-CRR-02B
- modbus_table: input_register (singular)
- function_code: 4, pdu_offset: 5, iec_address: %IW5
- raw_variable: FlowBRaw, raw_type: UINT, counts_per_unit: 10000
- engineering_unit: m3/s, plc_value: FlowBM3s
- opcua_node_id: nsu=urn:arwc:crr:tags;s=CRR.FlowBM3s
- historian_series: flow_b_m3s

```python
import csv, json, ssl, urllib.request, pathlib

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

with open("/opt/arwc-ot/challenges/W18/participant/tag-register.csv") as f:
    for row in csv.DictReader(f):
        if row["instrument"] == "FIT-CRR-204B" and row["plc_value"] == "FlowBM3s":
            focus = row
            break

body = json.dumps({
    "card": "W18.2",
    "instrument": focus["instrument"],
    "controlled_equipment": focus["controlled_equipment"],
    "modbus_table": focus["modbus_table"],
    "function_code": int(focus["function_code"]),
    "pdu_offset": int(focus["pdu_offset"]),
    "iec_address": focus["iec_address"],
    "raw_variable": focus["raw_variable"],
    "raw_type": focus["raw_type"],
    "counts_per_unit": int(focus["counts_per_unit"]),
    "engineering_unit": focus["engineering_unit"],
    "plc_value": focus["plc_value"],
    "opcua_node_id": focus["opcua_node_id"],
    "historian_series": focus["historian_series"],
}).encode()

d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/live-observations/current",
                           data=body, headers=h, method="POST"),
    context=ctx).read())
print("satisfied:", d["satisfied"])
print("flag:", d["flag"])   # FLAG{5b9b0ae9726e230f}
```

Key: modbus_table is "input_register" (singular), controlled_equipment is "GT-CRR-02B".

Flag: `FLAG{5b9b0ae9726e230f}` in the top-level `flag` field.
