Requires W18.1. The register is on the engineering workstation at
`/home/fieldlink/CairnReach/Briefs/W18/tag-register.csv` (user fieldlink on
a-engineering). Read the `FIT-CRR-204B` row and reconcile its seven layers:
Modbus FC4, PDU offset 5, IEC `%IW5`, raw `FlowBRaw` (UINT, 10000 counts/m3/s),
engineering value `FlowBM3s`, OPC UA node `CRR.FlowBM3s`, historian series
`flow_b_m3s`; controlled equipment `GT-CRR-02B`. Confirm the point identity in
`ot_history.tag_catalog`. The key distinction: PDU offset 5 is not the IEC
address `%IW5`, and the raw counts are not the engineering value (10000
counts/m3/s).

The endpoint is engineering-role, so it uses the corporate session. Submit the
complete binding from the connector, which holds that session:

```bash
sudo docker exec -i --user fieldlink cinder-arwc-connector sh -c '
sess=$(cat /var/lib/fieldlink-connector/handover/corporate-session)
curl -s --cacert /tmp/arwc-ca.crt -H "Authorization: Bearer $sess" -H "X-ARWC-Tenant: arwc" \
  -H "Content-Type: application/json" -X POST \
  https://process-view.arwc.test/api/live-observations/current \
  -d "{\"card\":\"W18.2\",\"instrument\":\"FIT-CRR-204B\",\"controlled_equipment\":\"GT-CRR-02B\",\"modbus_table\":\"input_register\",\"function_code\":4,\"pdu_offset\":5,\"iec_address\":\"%IW5\",\"raw_variable\":\"FlowBRaw\",\"raw_type\":\"UINT\",\"counts_per_unit\":10000,\"engineering_unit\":\"m3/s\",\"plc_value\":\"FlowBM3s\",\"opcua_node_id\":\"nsu=urn:arwc:crr:tags;s=CRR.FlowBM3s\",\"historian_series\":\"flow_b_m3s\"}"
'
```

```json
{"card":"W18.2","satisfied":true,"flag":"FLAG{5b9b0ae9726e230f}"}
```

The submission must match the register focus point exactly. Flag in the
top-level `flag` field.
