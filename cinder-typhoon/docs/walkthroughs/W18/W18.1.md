`/home/fieldlink/CairnReach/Briefs/W18/tag-register.csv` (user fieldlink on
a-engineering). Read it to get register_id `CRR-IO-R364`, project_revision `364`,

- `ot_history.tag_catalog.register_sha256` equals `df09d72a355340266896c59a204248e02aa277769f881e7a2f6ce6d15b6f7a3b` for the variables;

Submit the register id, revision, native digest, and the five non-heartbeat
process variables. The endpoint is engineering-role, so it uses the corporate
session. Run from the connector, which holds that session and trusts the range CA:

```bash

sess=$(cat /var/lib/fieldlink-connector/handover/corporate-session)

  -H "Content-Type: application/json" -X POST \
  https://process-view.arwc.test/api/live-observations/current \
  -d "{\"card\":\"W18.1\",\"asset\":\"AST-CRR-017\",\"register_id\":\"CRR-IO-R364\",\"project_revision\":364,\"register_sha256\":\"df09d72a355340266896c59a204248e02aa277769f881e7a2f6ce6d15b6f7a3b\",\"variables\":[\"FlowBM3s\",\"FlowM3s\",\"LevelM\",\"PositionBPct\",\"PositionPct\"]}"
'
```
