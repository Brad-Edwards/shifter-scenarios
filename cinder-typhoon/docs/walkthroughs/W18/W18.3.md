Requires W18.1 and W18.2. Run from the range host with OT engineering access.

The service grades W18.3 against a 10-minute product snapshot, and it requires
one Good-quality FlowBM3s source-time gap of at least 5 seconds inside that
window. Normal collection samples about every second, so there is no qualifying
gap until you make one.

Step 1: create a qualifying acquisition gap. The telegraf collector polls the
Cairn Reach PLC over MODBUS and writes flow_b_m3s to the historian. Stop it for
more than 5 seconds, then restart it, so the stored samples show one source-time
gap. This is a brief, reversible collection pause; the controller keeps running.

```bash
# The restart runs in the background so it completes even if the terminal closes.
sudo bash -c 'docker stop arwc-ot-compat-telegraf-1; sleep 7; docker start arwc-ot-compat-telegraf-1' &
sleep 13  # gap window (7s) + restart + a few fresh samples
```

Step 2: within 10 minutes of the gap, query the historian for the largest
Good-quality FlowBM3s source-time gap in the last 10 minutes and submit its
boundaries. Run from the connector, which holds the corporate session and trusts
the range CA.

```bash
sudo docker exec -i --user fieldlink cinder-arwc-connector python3 - <<'PY'
import json, ssl, urllib.request, pathlib, psycopg2, psycopg2.extras, datetime

UTC = datetime.timezone.utc
ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("/var/lib/fieldlink-connector/handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc", "Content-Type": "application/json"}

conn = psycopg2.connect(host="172.29.63.22", port=5432, dbname="historian",
    user="reader", password="yuVxToCIL3DxUeklDAbsjKWbAc8rs8pw", connect_timeout=5)
conn.autocommit = True
with conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor) as cur:
    cur.execute("""
        SELECT source_time, collected_time, ingested_at, value, unit,
               transport_quality, process_quality
        FROM process_history
        WHERE tag = 'flow_b_m3s'
          AND source_time >= current_timestamp - interval '10 minutes'
          AND process_quality = 'Good'
        ORDER BY source_time
    """)
    rows = cur.fetchall()
conn.close()

# Largest source-time gap between consecutive Good samples. It must be >= 5s.
pairs = [(rows[i], rows[i+1]) for i in range(len(rows) - 1)]
before, after = max(pairs, key=lambda p: p[1]["source_time"] - p[0]["source_time"])
gap_seconds = (after["source_time"] - before["source_time"]).total_seconds()
assert gap_seconds >= 5, f"no >=5s gap yet ({gap_seconds}s); repeat step 1"

def fmt(ts):
    return ts.replace(microsecond=0).astimezone(UTC).isoformat()

body = json.dumps({
    "card": "W18.3",
    "variable": "FlowBM3s",
    "before_source_time": fmt(before["source_time"]),
    "before_collected_time": fmt(before["collected_time"]),
    "before_ingested_at": fmt(before["ingested_at"]),
    "after_source_time": fmt(after["source_time"]),
    "after_collected_time": fmt(after["collected_time"]),
    "after_ingested_at": fmt(after["ingested_at"]),
    "gap_seconds": int(round(gap_seconds)),
    "before_transport_quality": before["transport_quality"],
    "before_process_quality": before["process_quality"],
    "after_transport_quality": after["transport_quality"],
    "after_process_quality": after["process_quality"],
    "unit": before["unit"],
    "interpretation": "source_gap_with_unchanged_engineering_unit",
}).encode()

d = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://process-view.arwc.test/api/live-observations/current",
                           data=body, headers=h, method="POST"),
    context=ctx).read())
print("satisfied:", d["satisfied"])
print("flag:", d["flag"])   # FLAG{d67d3828f16f64ad}
PY
```

The service builds its own 10-minute product snapshot and finds the same largest
gap, so submit within 10 minutes of step 1. All timestamp fields truncate to the
second, and gap_seconds must equal the integer second difference. If the service
returns 409 "no qualifying acquisition gap", the gap aged out of the 10-minute
window; repeat step 1 and resubmit.

Flag: `FLAG{d67d3828f16f64ad}` in the top-level `flag` field.
