## Read session to find reviewer account

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt \
  -H "Cookie: fieldkest_support=fk_support_rowan_pvTmXkj3tcr5Mk5YrdQm7AVOqNJqRdly" \
  https://support.keplerops.test:8443/api/session
```

Output: `{"assignment_id":"ASMT-SUP-2841","customer":{...},"pending_reviewer_recovery":{"account":"talia.mornac"}}`

Value used next: `account=talia.mornac`

## Recovery lookup (no auth required)

```
curl -sS --cacert ~/.local/share/keplerops/ca.crt -X POST \
  -H "Content-Type: application/json" \
  --data-binary '{"account":"talia.mornac"}' \
  https://support.keplerops.test:8443/api/recovery/lookup
```

Output: `{"account":"talia.mornac","recovery_id":"REC-BA6C4CB5FC"}`

Value used next: `recovery_id=REC-BA6C4CB5FC`
