## Log in to the osTicket staff panel as maya.ranscombe

The handover note is a private internal note, visible only inside the support
desk. Get a session cookie and the login CSRF token, then sign in.

```
CA=~/.local/share/keplerops/ca.crt
BASE=https://support.keplerops.test
csrf=$(curl -sS --cacert $CA -c /tmp/ost.jar "$BASE/scp/login.php" \
  | grep -oP 'name="__CSRFToken__"[^>]*value="\K[^"]+' | head -1)
curl -sS --cacert $CA -b /tmp/ost.jar -c /tmp/ost.jar -X POST \
  --data-urlencode "__CSRFToken__=$csrf" \
  --data-urlencode "userid=maya.ranscombe" \
  --data-urlencode "passwd=<maya_scp_password>" \
  --data-urlencode "submit=Log In" \
  "$BASE/scp/login.php"
```

A successful login returns `302` with `Location: index.php`.

## Read the private handover note on case SUP-2841 (K17.1 acceptance check)

Find the ticket id for case SUP-2841 in the staff queue, then open the ticket.

```
for id in $(curl -sS --cacert $CA -b /tmp/ost.jar "$BASE/scp/tickets.php" \
    | grep -oiE "tickets\.php\?id=[0-9]+" | grep -oE "[0-9]+" | sort -un); do
  curl -sS --cacert $CA -b /tmp/ost.jar "$BASE/scp/tickets.php?id=$id" \
    | grep -q "K17 Private Handover" && echo "SUP-2841 = ticket id $id" && break
done
curl -sS --cacert $CA -b /tmp/ost.jar "$BASE/scp/tickets.php?id=$id"
```

the case, customer (ARWC), asset CRR-OG2, connector FLK-7.4.2, the EXP-2841 and
SCHED-2841 references, and the flag:

