## Step 1 — Enable remote selection via FUXA

In the FUXA HMI at `http://fuxa:1881`, use Site controls to enable remote selection. This sets `HmiRemoteEnabled = True` in the PLC.

Alternatively via FUXA socket.io API (programmatic):
```python
import urllib.request, json, urllib.parse

FUXA = "http://172.29.63.21:1881"
# Login
r = urllib.request.urlopen(urllib.request.Request(FUXA + "/api/signin",
    data=json.dumps({"username": "operator", "password": "pYow06S3u4odS5EhD6eYG7-miRqTKb8v"}).encode(),
    headers={"Content-Type": "application/json"}, method="POST"), timeout=5)
token = json.loads(r.read()).get("data", {}).get("token", "")

# Connect socket.io with token in query
url_base = FUXA + "/socket.io/?EIO=4&transport=polling&token=" + urllib.parse.quote(token)
r2 = urllib.request.urlopen(url_base, timeout=5)
sid = json.loads(r2.read().decode()[1:])["sid"]
url = url_base + "&sid=" + sid
urllib.request.urlopen(urllib.request.Request(url, data=b"40", headers={"Content-Type": "text/plain"}, method="POST"), timeout=5)
urllib.request.urlopen(url, timeout=5)

# Enable remote
event = {"cmd": "set", "var": {"source": "crr-plc", "id": "HmiRemoteEnabled", "value": True}}
emsg = ('42["device-values",' + json.dumps(event, separators=(',', ':')) + ']').encode()
urllib.request.urlopen(urllib.request.Request(url, data=emsg, headers={"Content-Type": "text/plain"}, method="POST"), timeout=5)
```

## Step 4 — Publish the remote request

```
REQ_ID=$(python3 -c "import uuid; print(uuid.uuid4())")
EXPIRY=$(python3 -c "import time; print(int(time.time())+90)")

mosquitto_pub -h mosquitto -p 8883 \
  --cafile ~/CairnReach/Connections/mqtt-ca.pem \
  -u operator -P "Y7kjNV-evM0quA-cRFaPd01HBMf9gbLP" \
  -t arwc/crr/commands/operator -q 1 \
  -m "{\"id\":\"$REQ_ID\",\"asset\":\"AST-CRR-017\",\"mode\":\"automatic\",\"position_a_pct\":20.0,\"position_b_pct\":20.0,\"total_flow_m3s\":0.3,\"expires_at\":$EXPIRY}"
```

## Step 5 — Wait for completed outcome

Check `/tmp/outcomes.txt` for the `completed` status with `sequence` and flow values (~0.15 m³/s each).

Record:
- `received_at`: time from `dispatch_history` where `status=received`
- `completed_at`: time from `dispatch_history` where `status=completed`
- `remote_sequence`: the `sequence` number from outcomes

## Step 6 — Restore via FUXA

In FUXA, use Site controls to send manual A20/B20 request (HmiSequence++). Note the `restore_accepted_at` from `command_history` where `channel=HMI`.

## Step 7 — Collect timestamps from historian

```
psql -h postgres -U reader -d historian -c "
SELECT status, sequence, time
FROM public.dispatch_history
WHERE id = '$REQ_ID'
ORDER BY time"

psql -h postgres -U reader -d historian -c "
SELECT channel, decision, sequence, source_time
FROM public.command_history
WHERE asset = 'AST-CRR-017'
  AND source_time >= '$INTERVAL_START'
ORDER BY source_time"
```
