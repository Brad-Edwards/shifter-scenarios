## Challenge description — player-facing

Recover the retained maintenance record set through the supplied device interface and bind it to the inspection image.

## Story purpose

Establishes a usable artifact beyond a raw image filename.

## Prerequisites and starting position

**Required access or evidence:** [OT_READ](../../capability-routes.json).

**Starting material:** A retained maintenance image, simulated device-access material, and ordinary maintenance record examples.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual record-bearing data and image binding. No physical kit is required.

## Difficulty and inspiration

A bounded interface and artifact-recovery task.

**Inspiration:** [Flash-ing Logs (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c12). Retains Flash-ing Logs' constrained record and storage problem using a simulated interface.
