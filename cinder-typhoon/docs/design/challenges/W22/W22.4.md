## Challenge description — player-facing

The opened project includes a commissioning review helper whose recorded archive access does not match its apparent behavior or the listed reviewers. Recover the concealed review identity and use its access in the retained review context to obtain the withheld commissioning comparison.

## Story purpose

Gives Cinder a usable route into the retained review archive and the comparison that the official handover omitted. The project decision is already earned in W22.3; this challenge exposes who could read beyond that handover.

## Technical design


### Surface and normal behavior

`a-engineering` owns this card. The participant analyzes the ReviewHelper.dll from W22.3 to discover the concealed reviewer identity, finds the archive session in Nextcloud share history, and submits both to the service.

**Two-step mechanic:**

**Step 1 — DLL analysis (ReadyToRun native-body mismatch):**
The ReviewHelper.dll is a .NET 8 ReadyToRun x86_64 binary. The managed metadata lists `mara.stone-review` as the reviewer, but the native ReadyToRun code body has been replaced post-compilation and derives `elias.vorn-review` instead.
- Run with ReadyToRun: `dotnet ReviewHelper.dll` → `REVIEWHELP-R4:elias.vorn-review:CMP-CRR-R21-R7`
- Run without ReadyToRun: `COMPlus_ReadyToRun=0 dotnet ReviewHelper.dll` → `REVIEWHELP-R4:mara.stone-review:CMP-CRR-R21-R7`
- The discrepancy reveals `elias.vorn-review` as the concealed reviewer

**Step 2 — Nextcloud share history:**
`elias.vorn-review@arwc.test` is a Nextcloud user (Staff group). They share a "Commissioning Access" folder with the Staff group. The share note contains the archive session ID. A Staff member (CORPORATE user) listing their received shares sees the note: `Commissioning archive session: ARCHIVE-REVIEW-R7-ELIAS`.

**Service route**: `POST https://process-view.arwc.test/api/unlisted-reviewers/current`
- Requires CORPORATE Bearer token
- Gates on `sealed_project_opened=True` (W22.3 done)
- Body: `{"helper_sha256": "<sha256_of_dll>", "reviewer": "elias.vorn-review", "session": "ARCHIVE-REVIEW-R7-ELIAS", "comparison": "CMP-CRR-R21-R7", "project": "CRR-CTRL-R21"}`
- Validates all five fields; wrong reviewer (mara.stone-review) returns 409
- Sets `concealed_reviewer_used=True`
- Returns 201 with: `record_id=CMP-CRR-R21-R7`, comparison text, `historical=True`, `current_identity=False`, `maintenance_approval=False`, `control_authority=False`

**Participant Nextcloud access**: List received shares at `GET /ocs/v2.php/apps/files_sharing/api/v1/shares?format=json&shared_with_me=true` using CORPORATE credentials. The response includes one entry from "Elias Vorn" with note containing `ARCHIVE-REVIEW-R7-ELIAS`.

Native bindings:
- `a-engineering.a-engineering/process-view:process-view.arwc.test/api/unlisted-reviewers/current`
- `corporate.nextcloud:elias.vorn-review@arwc.test/Commissioning Access` (Staff group share)

The private service-loader contract is `content.arwc-a-engineering.w22-4-the-reviewer-who-was-never-listed`. It freezes accepted and denied requests, state transition, persistence, and evidence; it does not seed a successful result.
