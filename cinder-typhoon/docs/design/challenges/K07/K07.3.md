## Challenge description — player-facing

Use the framing capability to perform the inspector's protected package action and recover its restricted assessment.

## Story purpose

Gives the request exploit a useful package-intelligence conclusion.

## Prerequisites and starting position

**Required access or evidence:** [K07.2](K07.2.md).

**Starting material:** The registry inspector's normal account, request samples, component descriptions, and a constrained rehearsal interface.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Complete the protected assessment under the inspector's downstream authority. Repeating the framing demonstration without crossing the action boundary earns no further credit.

## Difficulty and inspiration

Requires composing the primitive with the protected action's binding and authorization constraints.

**Inspiration:** [Percetron (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c05). Retains Percetron's request-framing problem; W04 and W11 use different portions of the source.

## Technical design

### Surface and normal behavior
The assessment component has a protected package-inspection action tied to a restricted assessment record and accepts only its internal framed request form.

### Vulnerability and intended solution
K07.2's framing primitive can select that action while retaining the external inspector's permitted request context. The intended solution applies the documented discrepancy to retrieve one protected assessment.

### Evidence and completion
The component emits a protected-assessment read with request correlation and returns its immutable finding as player evidence.

### Boundaries and reset
The primitive is limited to one action and read-only assessment data; it cannot publish packages, alter policy, or access customer records. Reset clears events.

### Author checks
Verify direct protected access denial, required K07.2 evidence, intended read, unrelated action denial, correct audit correlation, and reset.
