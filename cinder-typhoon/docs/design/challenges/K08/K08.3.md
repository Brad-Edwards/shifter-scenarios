## Challenge description — player-facing

Create an alternative entitlement the legacy checker accepts while preserving the required customer and feature binding.

## Story purpose

Completes the legacy-license branch with an unauthorized accepted entitlement.

## Prerequisites and starting position

**Required access or evidence:** [K08.2](K08.2.md).

**Starting material:** The obsolete entitlement checker, representative license records, compatibility notes, and its bounded exercise interface.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Obtain acceptance for a distinct, correctly scoped entitlement. It does not confer customer execution or modern release-signing authority.

## Difficulty and inspiration

Requires constructing an accepted alternative under the retained legacy cryptographic constraints.

**Inspiration:** [Tsayaki (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c06). Retains Tsayaki's legacy cryptographic entitlement problem; this concerns an obsolete component.

## Technical design

### Surface and normal behavior
The legacy entitlement checker validates a customer, feature, expiry, and compatibility integrity field before enabling a test entitlement in the isolated service.

### Vulnerability and intended solution
The legacy derivation omits a field required by the current policy. The intended solution uses K08.2's legitimate reconstructed context to craft an alternate but correctly customer/feature-bound entitlement accepted by the legacy checker.

### Evidence and completion
The service records legacy acceptance, customer/feature binding, and test entitlement state; a text artifact alone does not score.

### Boundaries and reset
Acceptance affects only a player-local compatibility feature and creates no session, package, or ARWC authority. Reset clears entitlement state.

### Author checks
Test current checker rejection, intended legacy acceptance, wrong customer/feature rejection, expiry handling, no cross-service effect, and reset.
