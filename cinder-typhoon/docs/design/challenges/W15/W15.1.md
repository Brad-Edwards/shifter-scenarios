## Challenge description—player-facing

Recover the restricted cache association for the maintenance drawing and identify the version the review workflow will serve.

## Story purpose

Grounds the cache investigation in an actual maintenance record.

## Prerequisites and starting position

**Required access or evidence:** W13.SESSION (contractor session from W13.4).

**Starting material:** The maintenance-review client document, discoverable from the client reference graph.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover CACHE-DRW-OG2-R8 binding drawing DRW-OG2-R8 at revision R8 to reviewer queue REV-CRR-4417 at drawings.arwc.test. This is the cache association the review workflow will serve.

## Difficulty and inspiration

A bounded cache and document-binding investigation.

**Inspiration:** [OmniWatch (HTB Business CTF 2024; directory Medium / writeup Hard)](../../reference-catalog.md#c24).

## Technical design

### Surface and normal behavior

**Nextcloud source:** CACHE-DRW-OG2-R8.json is seeded to Nextcloud in `records-admin/contractor-workspace/` by seed-portal. The maintenance-review service fetches it at startup using admin WebDAV credentials from `/run/arwc-approval-config/nc-reader.json` and stores it in service state. The `maintenance.drawing-cache` route returns the state-held cache association. The ASSOCIATION constant in the service code is NOT the live source.

The cache association fields:
- `record_id`: CACHE-DRW-OG2-R8
- `revision`: 8
- `drawing`: DRW-OG2-R8
- `drawing_revision`: R8
- `reviewer_queue`: REV-CRR-4417
- `upstream_host`: drawings.arwc.test
- `cache_key_path`: /viewer/drawings/DRW-OG2-R8

**Gate:** The `maintenance.drawing-cache` route requires W13.SESSION (contractor session bearer token). Without a valid contractor session, the route returns HTTP 403.

**Route:** `maintenance.drawing-cache` → GET `maintenance-review.arwc.test/api/drawing-cache/current`.

Native bindings:

- Route: `maintenance.drawing-cache` → GET `maintenance-review.arwc.test/api/drawing-cache/current`
- Nextcloud document: `records-admin/contractor-workspace/CACHE-DRW-OG2-R8.json`
- Service: `a-approval` container at `maintenance-review.arwc.test`

### Vulnerability and intended solution

This card is an exact discovery and read task. The participant traverses the client reference graph to find the maintenance-review service, calls the drawing-cache route with their W13.SESSION contractor session, and receives the live cache association.

### Evidence and completion

The archive service writes an immutable audit (`drawing-cache-read`). Evidence sources are `features.a-maintenance.a-approval`.

### Boundaries and persistence

`association_observed` state flag persists across restarts. The cache association is refreshed from Nextcloud on every restart.

### Author checks

Verify the drawing-cache route returns the correct association fields with a valid contractor session. Test wrong session (403). Confirm association is sourced from Nextcloud (not canned constant). Verify the association identifies DRW-OG2-R8, R8, REV-CRR-4417.
