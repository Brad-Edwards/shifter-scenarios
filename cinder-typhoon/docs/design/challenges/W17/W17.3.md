## Challenge description — player-facing

Find the instrument described in the controls engineer's note and recover its correct observation identifier.

## Story purpose

Connects engineering prose to a usable observation.

## Prerequisites and starting position

**Required access or evidence:** [OT_READ](../../capability-routes.json).

**Starting material:** Current process observations, a separate mode record, engineering descriptions, and a documented benign reference test.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the identifier and the matching instrument description. This identifies the named instrument, not the complete outlet mapping of W18.

## Difficulty and inspiration

A bounded lookup across a short engineering description and tag reference.

**Inspiration:** Original challenge for this campaign.
