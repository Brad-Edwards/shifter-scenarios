## Challenge description — player-facing

Deliver a crafted support document that crosses the viewer's intended isolation boundary and recovers the protected preview content.

## Story purpose

Completes an application-exploitation branch with actual restricted information.

## Prerequisites and starting position

**Required access or evidence:** [K10.2](K10.2.md).

**Starting material:** The document-preview source, an ordinary preview account, representative attachments, and the preview boundary's observable behavior.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the protected content through a fresh preview interaction. A binding collision without access to the other document is insufficient.

## Difficulty and inspiration

A substantive isolation and delivery problem directly inspired by Postviewer v3.

**Inspiration:** [Postviewer v3 (Google CTF 2024; 19 solves, no formal tier)](../../reference-catalog.md#c09). Uses Postviewer v3's isolated-document binding problem; its original solve count is not a tier label.

## Technical design


### Surface and normal behavior
The support gateway accepts a player-uploaded preview document and returns the rendered content belonging to the derived document identity under the preview worker's constrained service context.

### Vulnerability and intended solution
K10.2's identity collision lets a crafted attachment select the protected document's derived identity. The intended solution crosses that precise isolation boundary and recovers the other document's content.

### Evidence and completion
The preview queue emits a source-to-derived collision event and a protected-content read with the target document version; both are required for objective evaluation.

### Boundaries and persistence

Preview-only disclosure Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Test normal own preview, collision prerequisite, intended protected output, no access to a third document, no external navigation, and upload/worker state persistence.
