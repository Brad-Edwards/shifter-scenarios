## Challenge description — player-facing

A release review is missing from the checkout. Find its staff work-board record and recover the attached review and unresolved comments.

## Story purpose

Makes the workstation feel like a working environment with unfinished decisions.

## Prerequisites and starting position

**Required access or evidence:** the supplied KeplerOps developer foothold.

**Starting material:** The developer's working directory, browser profile, saved client settings, and local FieldKest tools.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the native review attachment, unresolved comments, and release reference. Reading the support ticket does not reveal this content.

## Difficulty and inspiration

One normal work-board search and one attachment read keep this easy while requiring a separate application and record correlation. Kanboard supports task search, task comments, and task attachments as native task state.

**Inspiration:** Original challenge for this campaign.

**Product references:** [Kanboard search syntax](https://docs.kanboard.org/v1/user/search/), [Kanboard task files](https://docs.kanboard.org/v1/api/task_file_procedures/).

## Technical design


### Surface and normal behavior
The native Kanboard FieldLink project contains several release tasks. The target task uses release reference `REL-FLK-7.4.2-09` and owns the review attachment and its unresolved comments.

### Vulnerability and intended solution
The developer's ordinary project membership still exposes the unfinished release task. The intended solution is native task search followed by attachment and comment review under Rowan's normal Kanboard session.

### Evidence and completion
The native Kanboard task identity, attachment bytes, unresolved comments, and release reference establish the result. No local duplicate or custom record lookup is accepted.

### Boundaries and persistence

Rowan and release-platform background reused Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Check the checkout and home archive lack the review export, the native task owns the attachment and three unresolved comments, Rowan can read but not administer the project, K01.2 is insufficient, and neighboring tasks do not satisfy the result.
