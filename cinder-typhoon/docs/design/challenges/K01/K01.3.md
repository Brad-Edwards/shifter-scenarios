## Challenge description — player-facing

A release review refers to a work file missing from the checkout. Find the developer's exposed copy and recover the unresolved review comments.

## Story purpose

Makes the workstation feel like a working environment with unfinished decisions.

## Prerequisites and starting position

**Required access or evidence:** the supplied KeplerOps developer foothold.

**Starting material:** The developer's working directory, browser profile, saved client settings, and local FieldKest tools.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the separate review document and its release reference. Reading the browser conversation does not reveal this content.

## Difficulty and inspiration

A direct document-recovery lead on a separate surface.

**Inspiration:** Original challenge for this campaign.

## Technical design


### Surface and normal behavior
Rowan's review workspace includes a release-review reference and a separate ordinary local export outside the checked-out repository.

### Vulnerability and intended solution
The developer left a stale copy in a user-accessible project artifact area. The intended solution is contextual local-artifact discovery, then validation against the release reference.

### Evidence and completion
Completion records the document digest, unresolved comments, and related release ID; the document is distinct from the browser conversation.

### Boundaries and persistence

Rowan and release-platform background reused Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Check the checkout lacks the file, the review references it, the external copy has one matching release, K01.2 is insufficient, and unrelated artifacts do not accepted result.
