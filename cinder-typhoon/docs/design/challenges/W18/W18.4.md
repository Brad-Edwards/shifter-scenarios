## Challenge description — player-facing

**Required access or evidence:** ([W18.3](W18.3.md) AND [W17.OBS](../../capability-routes.json)).

**Starting material:** The current tag-export references, a separately retained scale table, and process observations from the read context.

**Campaign references:** `W18.MAP`.

## Completion and downstream use

Establish the tag/scale-to-outlet mapping supported by observed behavior. This supplies W18.MAP and MAPPING, not allocation or current project-revision evidence.

The conclusion associates the previously ambiguous identifiers with the physical outlet group and its recorded reference-event trace. The operator can now point to the part of the reservoir those values describe. It presents the mapping they established, not a new live command or a rehearsal that secretly moves the plant.
