## Challenge description — player-facing

Construct a valid practice sequence that respects the operating envelope and produces the specified bounded movement.

## Story purpose

Completes the knowledge needed to distinguish a valid command plan from an unsafe guess.

## Prerequisites and starting position

**Required access or evidence:** ([W25.3](W25.3.md) AND [W17.OBS](../../capability-routes.json)).

**Starting material:** The documented outlet operating envelope, separate permissive records, and a private practice model with visible observations.

**Campaign references:** `W25.MODE`.

## Completion and downstream use

Demonstrate the intended practice effect under the correct conditions. This supplies W25.MODE and MODE; it does not grant live write authority.

In the clearly identified practice model, the valid sequence produces visible outlet movement and a matching measured response, contrasting with the acknowledged but ineffective requests investigated earlier. The player has turned process understanding into controlled movement in rehearsal. The conclusion uses the existing bounded practice result; it requires no current outlet mapping or live client and does not change the real campaign's reserve.

## Difficulty and inspiration

A small documented state-sequence problem tied to independent observation evidence.

**Inspiration:** Original challenge for this campaign.
