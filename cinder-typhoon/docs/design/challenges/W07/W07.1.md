## Technical design


### Surface and normal behavior

The `planning-data.arwc.test` service (`a-data`) serves QRY-RESERVE-R7 at `GET /api/saved-queries/current`. Authentication requires both the FieldLink corporate session Bearer token and the W06.3 Metabase session via `X-ARWC-Planner-Session`. The returned definition names PostgreSQL 16.4 view `reserve_report_current`, double-quote identifier quoting, SELECT-only policy, and ordinary request/result pairs. The QRY-RESERVE-R7 Metabase question queries `reserve_report_current` and is accessible to nadia.corvane in the native reporting system.

Native bindings:

- Route: `planning.saved-query` in the planning_data service client document → `GET https://planning-data.arwc.test/api/saved-queries/current`
- Authentication: FieldLink corporate session (Bearer) + W06.3 Metabase session (X-ARWC-Planner-Session)
- Native Metabase question: QRY-RESERVE-R7 on the `reserve_report_current` PostgreSQL view
- PostgreSQL: `planning` DB, `planning_reader` role, SELECT-only on `public.reserve_report_current`

The participant reads the definition and observes actual query results to determine what operations are permitted versus what the "SELECT only" label claims.
