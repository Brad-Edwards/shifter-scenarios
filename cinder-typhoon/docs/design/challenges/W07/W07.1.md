## Challenge description — player-facing

Recover the private reserve-report definition and determine which report operations the planner's query interface actually permits. Resolve the disagreement between its 'read-only' label and the supplied ordinary request results.

## Story purpose

Introduces the backend's actual data scope.

## Prerequisites and starting position

**Required access or evidence:** [W06.3](../W06/W06.3.md).

**Starting material:** The earned planner session, its restricted query interface, and normal report/query examples.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the report definition and a correct account of the permitted operation classes supported by the supplied request/result evidence. Merely opening the planner session or downloading a profile does not count; protected backend reads remain W07.2.

## Difficulty and inspiration

A bounded behavioral investigation comparing the report contract with observed ordinary requests, before attempting the harder backend boundary.

**Inspiration:** [Aurors Archive (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c19). Retains Aurors Archive's restricted-database boundary after the browser chain.
