## Challenge description — player-facing

Recover the missing delivery fixture named in the training package's review note and identify the behavior it covered.

## Story purpose

Introduces development history as useful evidence.

## Prerequisites and starting position

**Required access or evidence:** the supplied training workspace.

**Starting material:** The training repository, retained build diagnostics, a sample package, and the rehearsal publication/consumer interfaces.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual fixture and expected delivery outcome. A revision identifier alone does not count.

## Difficulty and inspiration

A small repository investigation with an explicit missing artifact.

**Inspiration:** Original challenge for this campaign.

## Technical design

### Surface and normal behavior

A Gitea training repository contains the formatter package, review discussion,
and a real commit history. A review note names a removed delivery fixture; the
fixture existed in a prior ordinary commit and describes an expected consumer
outcome.

### Vulnerability and intended solution

This is a source-provenance exercise, not a hidden-path puzzle. The intended
solution is to use normal Forge and Git history to recover the deleted fixture
and correlate its assertion with the consumer record.

### Evidence and completion

The fixture's content hash, historical commit, and expected delivery outcome
are submitted as one evidence record. Scoring verifies the object is an actual
ancestor artifact and makes its expectation available to T03.4.

### Boundaries and reset

The repository is read-only for this card and contains only training source.
History is immutable; reset only removes the player's completion evidence.

### Author checks

Confirm the head checkout lacks the fixture, the review note gives a fair lead,
the parent history contains one matching artifact, an unrelated commit fails,
and the expected outcome agrees with the consumer fixture.
