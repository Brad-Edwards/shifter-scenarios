## Challenge description — player-facing

Convert the browser capability into usable planner authority over the protected application record.

## Story purpose

Gives the browser chain a durable application result.

## Prerequisites and starting position

**Required access or evidence:** [W06.2](W06.2.md).

**Starting material:** The corporate login and drawing-preview workflows, ordinary application material, and a controlled planner-review interaction.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover and demonstrate the planner session against the protected record. This supplies W07's application context; an exposed browser value without authority does not count.

## Difficulty and inspiration

Requires crossing the session's independent binding constraints after browser access.

**Inspiration:** [Aurors Archive (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c19). Adapts Aurors Archive's browser and session portion; W07 carries the separate database problem.
