## Challenge description — player-facing

Make the planner's privileged browser attach Cinder's controlled preview to the inspection's private drawing review.

## Story purpose

Creates a useful browser capability across the intended login boundary.

## Prerequisites and starting position

**Required access or evidence:** [W06.1](W06.1.md).

**Starting material:** The corporate login and drawing-preview workflows, ordinary application material, and a controlled planner-review interaction.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Demonstrate the attachment change inside the planner's review context. A preview in your own account does not count. This is a browser-mediated action; independently usable planner session authority remains W06.3.

## Difficulty and inspiration

Cross-application login and rendering composition inspired by Aurors Archive.

**Inspiration:** [Aurors Archive (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c19). Adapts Aurors Archive's browser and session portion; W07 carries the separate database problem.
