## Challenge description—player-facing

Make the planner's privileged browser attach Cinder's controlled preview to the inspection's private drawing review.

## Story purpose

Creates a useful browser capability across the intended login boundary.

**Campaign references:** No separately named capability output.

## Technical design


### Surface and normal behavior

The archive service owns the drawing-context POST endpoint. The OAuth state is stored in a native Nextcloud planning document (OAUTH-PLN-882.json), shared read-only with the planning reader account. The initial state: the planning OAuth context binds drawing DRW-OG2-R8, review REV-CRR-4417, and pending_origin `https://drawing-preview.arwc.test`. The participant replaces the pending_origin with the controlled endpoint `https://preview-cinder.arwc.test`.

Native bindings:

- Nextcloud: `Corporate Records/Planning/OAUTH-PLN-882.json` (admin-owned, shared with `arwc-planner-reader`)
- Route: `identity.drawing-context` in the retained-archive service client document → `POST https://retained-archive.arwc.test/api/drawing-contexts`
- Credentials: planning_access from HND-PLANNER-06 (W04.3) for Nextcloud; planner_handover token (W04.3) for the POST endpoint
- Browser: archive service runs chrome-headless-shell to render the drawing review page under the planner's review context; the page loads an iframe from `http://preview-cinder.arwc.test/preview/{drawing}`
- Evidence: preview-cinder serves a postMessage script; chrome's DOM output records `preview_callback_received:origin:preview-cinder.arwc.test` proving the controlled endpoint's JavaScript executed in the planner's browser session; render_hash is SHA-256 of the DOM output

preview-cinder.arwc.test DNS resolves to `10.77.60.11` (edge nginx). The edge serves a simple HTTP response on port 80 with a postMessage script identifying the controlled origin.

Unauthenticated or wrong-token requests return HTTP 403. Wrong oauth_state returns HTTP 409. Wrong drawing/review returns HTTP 409. Wrong preview_origin returns HTTP 409. Absent postMessage in DOM (render failed) returns None render_hash.

### Vulnerability and intended solution

The authored condition is **OAuth state and mutable preview-origin confusion**. Preview callback validates OAuth state before replacing the pending preview origin; a controlled preview at preview-cinder.arwc.test can be attached to DRW-OG2-R8 in the isolated planner browser. The hand build must preserve every named version, encoding, bound, validation order, identity, and unaffected field; substituting a generic vulnerable service would change the task.

The required result is: Demonstrate the attachment change inside the planner's review context. A preview in your own account does not establish the result. This is a browser-mediated action; independently usable planner session authority remains W06.3.

### Evidence and completion

The owning service writes an immutable audit for the accepted request and result. Caller-supplied output, a local copy, or knowledge of an identifier is not sufficient. Completion is evaluated from fresh service-owned evidence after the action. It cannot issue the identity, create the mutation, move a simulated actuator, or fabricate a downstream acceptance needed to prove itself.

Evidence sources are `features.a-corporate.a-identity`. A wrong identifier, stale revision, replayed one-time value, different checkpoint, or cross-tenant artifact is rejected.

### Boundaries and persistence

The result remains local evidence unless a downstream workflow explicitly names it. Tenant-scoped mutations, sessions that have not expired, generated artifacts, and audits persist across ordinary retries and later sessions. Initial immutable records remain unchanged unless the named route explicitly permits a field-level revision. Infrastructure recovery and submission adjudication are external to the SDL.

The behavior is limited to the named fictional objects and bounded service operation. It provides no general shell, arbitrary network target, unrelated district access, real process interface, or authority not expressly declared by the card.
