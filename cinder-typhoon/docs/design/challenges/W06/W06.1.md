## Challenge description — player-facing

Recover the protected login/rendering record for the planning application and bind it to the drawing under review.

## Story purpose

Establishes the actual application relationship behind the next browser task.

## Prerequisites and starting position

**Required access or evidence:** [W05.3](../W05/W05.3.md) OR [W04.3](../W04/W04.3.md).

**Starting material:** The corporate login and drawing-preview workflows, ordinary application material, and a controlled planner-review interaction.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the specific transaction and drawing association. A public login page or generic browser trace is insufficient.

## Difficulty and inspiration

A bounded identity/rendering investigation from either earned foothold.

**Inspiration:** [Aurors Archive (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c19). Adapts Aurors Archive's browser and session portion; W07 carries the separate database problem.
