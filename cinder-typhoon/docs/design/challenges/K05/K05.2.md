## Challenge description — player-facing

The visible package listing skips an older release mentioned in the support ticket. Recover the retained version record and its maintenance note.

## Story purpose

Adds product history with its own information payoff.

## Prerequisites and starting position

**Required access or evidence:** [G01 — K01.1](../K01/K01.1.md).

**Starting material:** The readable FieldKest package workspace, interface examples, release records, and an ordinary consumer-check facility.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the missing version record and note. It informs the package dispute but is not a hidden prerequisite for ordinary entry.

## Difficulty and inspiration

A short version-history lead on a separately exposed artifact.

**Inspiration:** Original challenge for this campaign.

## Technical design


### Surface and normal behavior
The Forge release history and support case expose a visible gap in the current registry listing for an older FieldKest release.

### Vulnerability and intended solution
Registry search suppresses yanked maintenance versions while its versioned release manifest remains normally recoverable through the named historical reference. The intended solution is revision-led recovery.

### Evidence and completion
Completion binds the retained version metadata and maintenance note to `FLK-6.9.8`; it grants context only.

### Boundaries and persistence

Optional history; active 7.4.2 stays visibly distinct Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Verify current listing omits the version, ticket/release history gives a lead, one record resolves, active and obsolete revisions differ visibly, and no authority results.
