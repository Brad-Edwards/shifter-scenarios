## Challenge description — player-facing

The report build failed, but it retained a review note separate from the console log. Recover that note and establish the input contract for submitting a corrected report provider.

## Story purpose

Connects a real build record to the separately archived input contract used by its report workflow.

## Prerequisites and starting position

**Required access or evidence:** the supplied KeplerOps developer foothold.

**Starting material:** The failing report job, a sample output, the fixture reference, and the developer's normal test interface.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover REVNOTE-1842 from the native Jenkins build artifacts and bind its provider contract to the failing build and source revision. This read does not grant source write or job configuration authority.

## Difficulty and inspiration

One bounded native artifact-discovery step, with the build number and source revision providing explicit leads. Jenkins exposes build artifacts separately from console output; understanding this distinction supports the Easy tier.

**Inspiration:** Original challenge for this campaign. Native behavior is documented in [Jenkins Remote Access API](https://www.jenkins.io/doc/book/using/remote-access-api/).

## Technical design


### Surface and normal behavior
Native Jenkins job fieldlink-report build 1842 retains the actual failed test console, source revision, workspace and archived reports/REVNOTE-1842.json. The separate fieldlink-report-review job exposes a native provider.zip file parameter.

### Vulnerability and intended solution
The console log does not reproduce the separately archived provider contract. Follow the native artifact link or artifact API, read the review note, and correlate its exact fixture path and revision with the actual failed build. Use native artifact requests under the developer's existing read permission.

### Evidence and completion
The native build record, archived REVNOTE-1842 bytes and source revision establish the input contract. Record the artifact digest and the native file-parameter job that consumes the provider package; source write and job configuration remain denied.

### Boundaries and persistence

Input for K02.3 Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Verify native artifact download and exact note digest, matching build/source revision, absent artifact 404, anonymous denial and unchanged source-write/job-configuration permissions.
