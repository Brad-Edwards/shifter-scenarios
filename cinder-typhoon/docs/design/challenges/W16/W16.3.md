## Challenge description—player-facing

## Technical design


### Surface and normal behavior

`a-archive` and its `retained-archive` application own this card. The `/api/signal-experiments` route handles two operations:

**measure**: accepts a program of TEST (opcode 5) instructions and returns `observations` list. Each TEST(slot, probe) entry returns `{"slot": slot, "probe": probe, "cycles": 1200 + 64*popcount(SAMPLE_SLOTS[slot] XOR probe) + jitter}`. Jitter is drawn deterministically from `JITTER = (0, 1, -1, 2, -2, -1, 1, 0)` indexed by `(sequencer_experiment_count + observation_index) % 8`. TEST has no authorization check; it reaches any slot.

**verify**: validates the participant's recovered interpretation. Accepts `reference_values={"4": 0, "5": 1, "6": 255}`, `target_slot=159`, `recovered_byte=165` (0xA5), `repetitions=8`, `bit_order="lsb0"`. On success sets `sequencer_signal_discriminated=True` and returns `SEQ-DISCRIM-CRR-4`.

Reference test points (from SAMPLE_SLOTS): slot 4=0x00 (zero), slot 5=0x01 (single-bit), slot 6=0xFF (saturation). Target: slot 159=0xA5 (10100101, 4 set bits). Jitter ≤ ±2; signal per bit ±64. Single measurement per probe suffices.

Native bindings:

- Route: `POST retained-archive.arwc.test/api/signal-experiments`
- `execute_test_program` and `sequencer_signal` in `retained_archive.py`

The private service-loader contract is `content.arwc-a-archive.w16-3-an-experiment-with-a-signal`.

### Vulnerability and intended solution

The authored condition is **bounded deterministic side-channel experiment**. TEST probes any slot including unauthorized ones. The cycle formula `1200 + 64*popcount(sample XOR probe) + jitter` encodes each bit via the sign of the cycle difference between a single-bit probe and the probe=0 baseline.

Intended experiment:
1. POST `measure` with TEST(159, 0) baseline + TEST(159, 1), TEST(159, 2), TEST(159, 4) ... TEST(159, 128) for each bit position.
2. For each bit i: if `cycles(probe=2^i) < cycles(probe=0)`, bit i is set in the sample.
3. POST `verify` with reference_values per the descriptor, target_slot=159, recovered_byte=165, repetitions=8, bit_order=lsb0.

The reference cases (slots 4, 5, 6) confirm the formula: slot 4 (0x00) cycles ~1200, slot 5 (0x01) cycles ~1264, slot 6 (0xFF) cycles ~1712—a 64-cycle-per-bit gradient.

The required result is: Demonstrate correct discrimination of the designated independent conditions. Raw timing differences or repeated ordinary sequences are insufficient.

## Hints

### Hint 1

Use `POST /api/signal-experiments` with `operation=measure` and a program of TEST (opcode 5) instructions. Each TEST(slot, probe) entry returns cycles = 1200 + 64×popcount(sample[slot] XOR probe) + jitter. Submit TEST on slot 159 with probe=0 to get the baseline, and also test the reference slots (4, 5, 6) to validate the formula.

### Hint 2

For each bit i (0–7), submit TEST(159, 2^i). If `cycles(probe=2^i) < cycles(probe=0)`, bit i is set in the sample. The signal difference per bit is ±64 cycles; jitter is at most ±2 and does not obscure it. Work through all eight bit positions to reconstruct the full byte.

### Hint 3

After recovering the byte (165 = 0xA5), submit `operation=verify` with `reference_values={"4": 0, "5": 1, "6": 255}`, `target_slot=159`, `recovered_byte=165`, `repetitions=8`, `bit_order="lsb0"`. A successful verify returns `SEQ-DISCRIM-CRR-4` and sets the signal-discrimination flag needed for W16.4.
