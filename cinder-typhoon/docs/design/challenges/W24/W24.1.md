## Technical design


### Surface and normal behavior

`a-diagnostics` (via engineering proxy) owns this card. The participant uses CORPORATE Bearer on `process-view.arwc.test`; engineering forwards to diagnostics with `X-ARWC-Internal: historian-r21`.

**Step 1**—Read the oracle contract:
`GET https://process-view.arwc.test/api/signature-requests` with CORPORATE Bearer.
- Sets `oracle_contract_observed=True`
- Returns: `record_id=RECOVERY-ORACLE-R4`, `algorithm=RSA-2048/PKCS1-v1_5`, `query_limit=4096`
- Returns 4 labeled examples (class + ciphertext for A, B, C, D)
- Returns 4 prediction cases (request_id + epoch_bucket, no class—must be predicted)
- Returns the `selector_artifact` (selector24 binary SHA256) and `selector_validation_cases`

**Oracle class definitions** (RSA-2048 PKCS#1 v1.5 structure after decryption):
- **A**: missing `\x00\x02` prefix
- **B**: fewer than 8 nonzero padding bytes
- **C**: missing separator byte or wrong `ENG1` payload tag
- **D**: structurally valid padding (all constraints satisfied)

**Selector function** (xorshift128+ variant):
The oracle applies a rotation: `observed_class = shift(padding_class, selector(request_id, epoch_bucket) & 3)`.
The `selector_validation_cases` supply known (request_id, epoch_bucket) → rotation pairs to verify the selector implementation.

**Step 2**—Submit prediction classifications:
`POST https://process-view.arwc.test/api/signature-oracles/current` with CORPORATE Bearer.
- Body: `{"record_id": "ENG-REC-24", "prediction_set": "SELECTOR-CRR-R4", "predictions": [{"request_id": ..., "epoch_bucket": ..., "observed_class": ...}, ...]}`
- Validates all 4 predictions against `PREDICTION_CASES` (real RSA + real selector math)
- Sets `selector_predicted=True` for W24.2+
- Returns 201 with `record_id=SELECTOR-CRR-R4`

Native bindings:
- `a-engineering.a-diagnostics/process-view:process-view.arwc.test/api/signature-requests` (GET)
- `a-engineering.a-diagnostics/process-view:process-view.arwc.test/api/signature-oracles/current` (POST)

The private service-loader contract is `content.arwc-a-diagnostics.w24-1-two-kinds-of-answer`. It freezes accepted and denied requests, state transition, persistence, and evidence; it does not seed a successful result.

This card is an exact discovery, interpretation, or reconciliation task rather than an additional privilege flaw. Recovery contract RECOVERY-ORACLE-R4 uses RSA-2048 PKCS#1 v1.5 and four classes: A for missing 00 02 prefix, B for fewer than eight nonzero padding bytes, C for missing separator or wrong ENG1 payload tag, and D for structurally valid padding; it enforces 4096 total queries and supplies labeled examples for engineering record ENG-REC-24. The result must come from the declared source and bindings, not from a duplicate clue or pre-completed record.

The required result is: Recover the actual contract and correctly classify the supplied responses. A service banner or guessed algorithm name is insufficient.
