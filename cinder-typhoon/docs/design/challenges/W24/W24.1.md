## Challenge description — player-facing

Recover the legacy recovery contract and distinguish the response classes produced for the supplied engineering record.

## Story purpose

Establishes what the recovery interface actually reveals.

## Prerequisites and starting position

**Required access or evidence:** [W21.REVISION](../../capability-routes.json).

**Starting material:** The legacy engineering recovery interface, its ordinary examples, the sealed diagnostic evidence bundle, the current project binding, and a bounded query allowance. The bundle's contents are not yet readable.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual contract and correctly classify the supplied responses. A service banner or guessed algorithm name is insufficient.

## Difficulty and inspiration

A bounded interface and response-meaning investigation.

**Inspiration:** [Twin Oracles (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c23). Retains Twin Oracles' constrained oracle reasoning. W24.1–W24.3 earn evidence recovery; W24.4 has its own signature-analysis precedent.
