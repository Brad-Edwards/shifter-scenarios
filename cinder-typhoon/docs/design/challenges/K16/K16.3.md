## Challenge description — player-facing

Establish the separate execution context needed for the scheduled task to act after your current support session ends.

## Story purpose

Adds an execution identity independent of the current interactive session.

## Prerequisites and starting position

**Required access or evidence:** [K16.2](K16.2.md).

**Starting material:** The earned delegated context, scheduled-workflow records, startup settings, and an on-demand shift rehearsal.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Demonstrate the protected task action under the separate context. Merely running the modified job again under the current session does not count.

## Difficulty and inspiration

Requires distinguishing and composing interactive and scheduled authority.

**Inspiration:** Original challenge for this campaign.
