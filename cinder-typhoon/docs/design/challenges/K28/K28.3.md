## Technical design


### Surface and normal behavior
The retained binary and its signed diagnostic configuration remain unchanged. The loader emits an archived internal path and engineering-note object ID. The private native Gitea repository `fieldkest/connector-archive` retains the note as a Markdown file under that exact namespace; its README explains that archived internal paths are repository paths rather than live service endpoints. Gitea owns the authenticated file, Git history, revision and ordinary access errors.

### Vulnerability and intended solution
Reconstruct the concealed loader's path and object identifier, then use that binding to retrieve the corresponding native repository note. Correlate the note's customer and retained diagnostic-package references with the fresh loader result. The note supplies an optional ARWC Engineering discovery lead; it grants no customer or OT authority.

### Evidence and completion
Require the fresh diagnostic result's route, note ID, output digest and protected tool audit, together with the actual Gitea repository path, commit revision and engineering-note content digest. An unrelated local file, guessed HTTP route or ordinary connector response does not establish that binding. The note identifies retained package `DIAG-CRR-MIXED-19` and project family `R19`; its content does not supply the reservoir diagnostic's later interpretation or outlet mapping.

### Boundaries and persistence

Lead to W19 only Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Verify the original binary, build ID, tag and diagnostic transformations remain unchanged. Recover the exact route and note ID from a fresh diagnostic result; retrieve the matching native Gitea file and bind its revision and digest. Check authenticated retrieval, anonymous denial and an unrelated path denial. Confirm the note names the retained ARWC package without disclosing its analysis or granting OT access.
