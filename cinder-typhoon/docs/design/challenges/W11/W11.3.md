## Challenge description — player-facing

Use the earned exchange capability to recover the current asset lineage behind the backend's separate relation boundary.

## Story purpose

Provides authoritative history useful to the maintenance investigation.

## Prerequisites and starting position

**Required access or evidence:** [W11.2](W11.2.md).

**Starting material:** The relation-service references exposed by asset or allocation evidence, normal transaction examples, and a restricted lineage backend.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the protected lineage and its current asset binding. It can introduce W12's archive trail; the initial protocol response does not contain this result.

## Difficulty and inspiration

Requires composing the protocol capability with the protected relation's additional constraints.

**Inspiration:** [Percetron (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c05). Retains Percetron's backend-protocol construction segment, separate from K07 and W04.
