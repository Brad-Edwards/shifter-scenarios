## Challenge description — player-facing

Your publication identity still cannot read the private support package. Cross the package-view boundary and recover its protected contents.

## Story purpose

Adds a separate registry data compromise after publication access.

## Prerequisites and starting position

**Required access or evidence:** [K06.1](K06.1.md).

**Starting material:** The package import workflow, its documented input form, a rehearsal consumer, and the registry interfaces exposed by the workflow.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the protected package through the distinct package-view authorization weakness. Merely reusing A01 for an already permitted read does not satisfy this result.

## Difficulty and inspiration

Requires distinguishing publication rights from the package view's separate access rules.

**Inspiration:** [Prison Pipeline (HTB Business CTF 2024; organizer Medium / writeup Easy)](../../reference-catalog.md#c01). Adapts the importer-to-registry portion of Prison Pipeline; production ARWC delivery remains K26.

## Technical design


### Surface and normal behavior
Verdaccio presents public release-channel packages and a protected support package using the same scoped package namespace but different view policies.

### Vulnerability and intended solution
A view-resolution endpoint evaluates the requested package before applying the caller's restricted view. The intended solution is to demonstrate the specific cross-view authorization error with `A01`, then recover the protected package contents.

### Evidence and completion
The registry logs an authorized-by-flaw read of the protected package version and returns its immutable manifest/content digest.

### Boundaries and persistence

Input to K06.3 Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Test normal view separation, intended package read, unrelated private package denial, no write escalation, audit attribution.
