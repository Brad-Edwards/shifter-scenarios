## Challenge description — player-facing

Publish a compatible connector package under the authority you recovered, then make the isolated rehearsal consumer run its actual code and return your changed result.

## Story purpose

Completes a local supplier-side execution episode before customer delivery.

## Prerequisites and starting position

**Required access or evidence:** [K06.2](K06.2.md).

**Starting material:** The package import workflow, its documented input form, a rehearsal consumer, and the registry interfaces exposed by the workflow.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Cause actual changed behavior in the separate test consumer and recover its result. This grants no ARWC execution and does not replace K26.

## Difficulty and inspiration

Native mechanics: [npm publication](https://docs.npmjs.com/cli/v11/commands/npm-publish/) and [package contents](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/). Medium work combines compatible implementation, immutable publication and actual isolated module execution.

## Technical design


### Surface and normal behavior
Verdaccio owns ordinary npm publication and immutable package versions. The existing FieldLink rehearsal application retrieves the requested real package and the isolated worker installs it offline and loads its actual Node module and local files.

### Vulnerability and intended solution
Use the private support package interface and scoped publisher identity to implement and publish a new compatible connector version. Invoke the normal rehearsal with that native version, preserving the request and output interface while changing the assessment.

### Evidence and completion
The native publication, immutable version, exact tarball digest and fresh isolated rehearsal result bind the executed package to its actual changed output and preserved tenant/asset/interface fields.

### Boundaries and persistence

Supplier-only result; no ARWC route Participant-created service state persists for the life of the participant world and ordinary retries do not erase it. The action is limited to the exact records, identities, routes, and destination effects declared here; unrelated tenants and services remain denied. Infrastructure recovery and submission adjudication are outside this in-world contract.

### Author checks
Verify native publish and duplicate-version rejection, changed compatible module execution, required-local-file or interface failure, preserved tenant and asset fields, and no release-administration authority.
