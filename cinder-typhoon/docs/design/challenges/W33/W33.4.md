## Technical design


### Surface and normal behavior

`a-reservoir` and its `reservoir-controller` application own this part of **When the forecast moves**. Normal behavior applies the declared identity, tenant, object, revision, and process bindings and returns or changes only the caller-scoped object. The exact initial state is: Policy evaluator accepts one ARWC-POL1 document containing twelve base release values and bounded buffer and demand gains, then runs all 27 Cartesian combinations of demand offset -0.05, 0.00, +0.05 m3/s, outlet gain 0.98, 1.00, 1.02, and observation delay 20, 40, 60 seconds; each action must derive from the buffer and demand observations available at that step, and per-case schedules are rejected.

Native bindings:

- `a-control.a-reservoir/reservoir-controller/when-the-forecast-moves`
- `a-control.a-distribution/distribution-rehearsal/when-the-forecast-moves`
- `a-control.a-instruments/independent-instruments/when-the-forecast-moves`

The private service-loader contract is `content.arwc-a-reservoir.w33-4-when-the-forecast-moves`. It freezes accepted and denied requests, state transition, persistence, and evidence; it does not seed a successful result.
