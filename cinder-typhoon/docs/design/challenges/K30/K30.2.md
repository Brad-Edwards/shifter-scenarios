## Challenge description — player-facing

Recover the protected historical records using the authority you have over their backup, without gaining direct access to the source database.

## Story purpose

Completes a substantive cloud-data compromise through a different trust boundary.

## Prerequisites and starting position

**Required access or evidence:** [K30.1](K30.1.md).

**Starting material:** The discovered backup catalog, protected build metadata, and the customer's retained migration history.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual protected record set. All necessary recovery and access work earns one score; creating a data copy without reading it is insufficient.

## Difficulty and inspiration

Cloud backup/data-access reasoning directly inspired by codebuild_secrets.

**Inspiration:** [codebuild_secrets (CloudGoat; Hard challenge lab)](../../reference-catalog.md#c28). Adapts CloudGoat codebuild_secrets' protected-data recovery problem; the source is a Hard lab, not a timed CTF.
