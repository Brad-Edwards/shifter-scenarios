## Technical design

### Surface and normal behavior

**Nextcloud source:** FIELD-BAG-CRR-4417-R3.json is seeded to Nextcloud in the `records-admin/contractor-workspace/` folder by seed-portal. The contractor portal fetches it from Nextcloud at startup using admin WebDAV credentials from `/run/arwc-contractors-config/nc-reader.json` and stores it in service state. The field-kit route returns the state-held field bag. If the Nextcloud fetch fails at startup, the route returns HTTP 503.

The field bag fields:
- `record_id`: FIELD-BAG-CRR-4417-R3
- `revision`: 3
- `inspection`: INSP-CRR-2026-09-18
- `asset`: AST-CRR-017
- `expected_outlets`: [OG-CRR-02]
- `retained_client`: fieldbag/v1 protocol with encoding and request fields
- `service_manifest`: legacy (field-read-legacy.arwc.test) and current (process-read.arwc.test) endpoints

**Gate:** The `contractors.field-kit` route requires a valid contractor session (W13.SESSION). A wrong or absent contractor session returns HTTP 403.

**Route:** `contractors.field-kit` → GET `contractor-portal.arwc.test/api/field-kits/current`.

Native bindings:

- Route: `contractors.field-kit` → GET `contractor-portal.arwc.test/api/field-kits/current`
- Nextcloud document: `records-admin/contractor-workspace/FIELD-BAG-CRR-4417-R3.json`
- Service: `a-contractors` container

### Vulnerability and intended solution

This card is an exact discovery and read task. The participant uses their W13.SESSION contractor session to call the `contractors.field-kit` route. The portal fetches the field bag from Nextcloud and returns it. The service writes an audit entry.

The required result is: FIELD-BAG-CRR-4417-R3, inspection=INSP-CRR-2026-09-18, asset=AST-CRR-017, with the service manifest naming the legacy and current endpoints.

### Evidence and completion

The archive service writes an immutable audit (`field-kit-read`). Evidence sources are `features.a-maintenance.a-contractors`.

### Boundaries and persistence

`field_bag_observed` state flag persists across restarts. The field bag is sourced from Nextcloud at every startup; a failed fetch returns 503.

### Author checks

Verify the field-kit route returns the correct field bag fields with a valid contractor session. Test wrong/absent session (403). Confirm field bag is sourced from Nextcloud (not canned constant). Verify audit is written.

## Hints

### Hint 1

The contractor portal client document exposes `contractors.field-kit`. Use the contractor session earned in W13.4 as the bearer token for this call. A corporate session alone is not sufficient—the contractor session is required.

### Hint 2

The route returns FIELD-BAG-CRR-4417-R3 with inspection=INSP-CRR-2026-09-18 and asset=AST-CRR-017. The field bag contains the expected outlets (OG-CRR-02) and a service manifest with both a legacy and a current endpoint.

### Hint 3

The service manifest distinguishes the retired legacy endpoint (field-read-legacy.arwc.test) from the current endpoint (process-read.arwc.test). Record both—W14.2 and W14.3 require the manifest to identify which endpoint carries current data.
