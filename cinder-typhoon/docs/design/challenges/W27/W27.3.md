## Challenge description — player-facing

Create a valid-looking diagnostic program that makes the planning consumer report sufficient reserve for Cinder's allocation case while preserving its required diagnostics and unaffected district outputs.

## Story purpose

Completes the elite integrity branch with a useful planning-view capability.

## Prerequisites and starting position

**Required access or evidence:** [W27.2](W27.2.md).

**Starting material:** The legacy engineering-program verifier, approved diagnostic examples, and the isolated planning consumer it protects.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Demonstrate acceptance of the altered program and its false reserve result at the genuine planning consumer. The useful collision and accepted program earn one score. This supplies the same scoped W34 planning-view capability as W23.3, without altering raw process observations.

## Difficulty and inspiration

Accepted, meaningful program construction inspired by the Insane-rated ROT128 challenge.

**Inspiration:** [ROT128 (HTB Cyber Apocalypse 2024; Insane)](../../reference-catalog.md#c15). Retains ROT128's custom-integrity analysis and meaningful altered-program objective.
