## Challenge description — player-facing

Use the exposed context and conversation evidence to recover the other fictional customer's restricted support document.

## Story purpose

Completes a cross-customer data compromise within the supplier.

## Prerequisites and starting position

**Required access or evidence:** ([K23.1](K23.1.md) AND [K23.2](K23.2.md)).

**Starting material:** The support assistant's context views, retained navigation artifacts, and ordinary retrieval interface.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual foreign-tenant document while retaining the original support identity. A generated summary or current-customer record is insufficient.

## Difficulty and inspiration

A bounded tenant, conversation, and retrieval join.

**Inspiration:** [ATLAS application-trust inspiration](../../threat-inspiration.md#atlas). ATLAS informs the data-isolation theme. All three objectives are deterministic application tasks.
