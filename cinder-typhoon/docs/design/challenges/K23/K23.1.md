## Challenge description — player-facing

Recover the assistant's exposed context inventory and the unpublished support-source entry it includes.

## Story purpose

Introduces a data surface separate from the assistant's generated answers.

## Prerequisites and starting position

**Required access or evidence:** [B01 — K17.1](../K17/K17.1.md).

**Starting material:** The support assistant's context views, retained navigation artifacts, and ordinary retrieval interface.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual context inventory entry. This provides retrieval context, not another tenant's protected document.

## Difficulty and inspiration

A bounded endpoint/data discovery.

**Inspiration:** [ATLAS application-trust inspiration](../../threat-inspiration.md#atlas). ATLAS informs the data-isolation theme. All three objectives are deterministic application tasks.
