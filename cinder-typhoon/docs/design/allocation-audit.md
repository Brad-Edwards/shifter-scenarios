# Allocation audit: draft 2 to draft 3

The audit applies the distinct-work rule to the briefs themselves. It removes
twenty allocations and funds twenty new achievements in six operations.
The total remains **240 slots**, now across **70 operations**. This is an
architecture allocation, not an assertion that every surviving slot has passed
implementation and fresh-player testing.

The [draft-2 ledger](portfolio-v2.csv) preserves the baseline. The
[current ledger](portfolio.csv) supplies the revised counts. Tiers describe
remaining work after prerequisites with the provided agent. Source ratings
do not automatically transfer to each partial achievement.

Easy/medium work remains 154 slots, or 64.2%. Both organizations retain all
five tiers. Hard-or-higher work grows from 83 to 86 slots. Fewer elite partial
flags reflect the audit of marginal work, not a decision to lower the technical
ceiling: the difficult native, browser, identity, timing, estimator, and program
integrity mechanisms remain.

Supply, cloud, and process now contain eleven hard-or-higher allocations,
compared with zero in their draft-2 principal-category rows. Category changes
come from new work; existing binary exercises were not renamed cloud or process
to improve the table. The cloud chapter now has six operations, customer delivery
five, water-on-paper five, and release/consequences six. Chapter sizes follow
their work rather than a four-operation template.

## Remaining audit obligations

This pass covers the clearest duplication and the accepted distribution gaps.
It is not a completed 240-card inventory. Surviving introductory disclosures
still need genuinely separate surfaces; native partial credit still needs
independent remaining work; new capstone tiers still need source-aware testing.

Preserve the content requirement when a proposed card fails. Record actual
accepted counts and remaining authoring capacity openly. Do not count abandoned
allocations, unscored story receipts, alternative methods for one effect, or
capability-graph joins as additional challenges.
