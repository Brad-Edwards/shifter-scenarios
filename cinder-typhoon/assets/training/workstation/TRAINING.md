# Cinder rehearsal systems

This workstation is attached only to the rehearsal network. Four independent
desks are available:

- Workbench: `http://workbench.training:8080/`
- Accounts: `http://accounts.training:8080/`
- Developer artifacts: `http://developer.training:8080/`
- Outlet desk: `http://state.training:8080/`

Each desk links its own ordinary records and interfaces. Material recovered at
the Accounts desk is reused only by that desk. Release access recovered at the
Developer artifacts desk is reused only by its registry. The later workplace
systems are separate and are not reachable from this network.

The supplied tools may be used from this workstation. Read-only records remain
unchanged when inspected. Service activity that changes application state is
retained by that service.
