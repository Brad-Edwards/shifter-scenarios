## Challenge description — player-facing

Turn the bounded release plan into a correctly bound live command plan using the client and authority you earned.

## Story purpose

Joins the campaign's separately earned knowledge and control capabilities.

## Prerequisites and starting position

**Required access or evidence:** ([PROCESS_INTERPRETATION](../../capability-routes.json) AND [CONTROL](../../capability-routes.json) AND [MODE](../../capability-routes.json) AND [CONSEQUENCE_PLAN](../../capability-routes.json)).

**Starting material:** The earned scoped control client, validated current process evidence, and the bounded release/consequence plan.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Produce a command plan whose target, current revision, units, mode, and authority match the intended bounded release. A copied practice sequence is insufficient.

## Difficulty and inspiration

A medium integration task after the control exploit and evidence work are complete.

**Inspiration:** Original challenge for this campaign.
