## Challenge description — player-facing

The local FieldLink helper has an unfinished support-report job. Make it produce a fresh inspection summary from the developer's supplied sample, with that sample's asset and revision correctly represented.

## Story purpose

Gives a newcomer a visible application result before a larger compromise.

## Prerequisites and starting position

**Required access or evidence:** the supplied KeplerOps developer foothold.

**Starting material:** The developer's working directory, browser profile, saved client settings, and local FieldLink tools.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Produce the sample's inspection summary through the local helper, preserving its asset and revision binding. This is an introductory interface task with a visible result, not a claimed privilege escalation.

## Difficulty and inspiration

A documented, limited application action with immediate feedback.

**Inspiration:** Original challenge for this campaign.
