## Challenge description — player-facing

A release review refers to a work file missing from the checkout. Find the developer's exposed copy and recover the unresolved review comments.

## Story purpose

Makes the workstation feel like a working environment with unfinished decisions.

## Prerequisites and starting position

**Required access or evidence:** the supplied KeplerOps developer foothold.

**Starting material:** The developer's working directory, browser profile, saved client settings, and local FieldLink tools.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the separate review document and its release reference. Reading the browser conversation does not reveal this content.

## Difficulty and inspiration

A direct document-recovery lead on a separate surface.

**Inspiration:** Original challenge for this campaign.
