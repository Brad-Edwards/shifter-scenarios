## Challenge description — player-facing

The visible package listing skips an older release mentioned in the support ticket. Recover the retained version record and its maintenance note.

## Story purpose

Adds product history with its own information payoff.

## Prerequisites and starting position

**Required access or evidence:** [G01 — K01.1](../K01/K01.1.md).

**Starting material:** The readable FieldLink package workspace, interface examples, release records, and an ordinary consumer-check facility.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the missing version record and note. It informs the package dispute but is not a hidden prerequisite for ordinary entry.

## Difficulty and inspiration

A short version-history lead on a separately exposed artifact.

**Inspiration:** Original challenge for this campaign.
