## Challenge description — player-facing

Make the isolated test consumer run your compatible package behavior and return its protected rehearsal result.

## Story purpose

Completes a local supplier-side execution episode before customer delivery.

## Prerequisites and starting position

**Required access or evidence:** [K06.2](../K06/K06.2.md).

**Starting material:** The package import workflow, its documented input form, a rehearsal consumer, and the registry interfaces exposed by the workflow.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Cause actual changed behavior in the separate test consumer and recover its result. This grants no ARWC execution and does not replace K26.

## Difficulty and inspiration

Package adaptation and test-consumer binding, using the private interface evidence already recovered.

**Inspiration:** [Prison Pipeline (HTB Business CTF 2024; organizer Medium / writeup Easy)](../../reference-catalog.md#c01). Adapts the importer-to-registry portion of Prison Pipeline; production ARWC delivery remains K26.

## Technical design

### Surface and normal behavior
The private package describes a player-local rehearsal consumer that resolves compatible FieldLink versions, runs its documented diagnostic behavior, and returns a protected receipt.

### Vulnerability and intended solution
The intended solution uses the distinct package-view result and the normal release-channel publication scope to supply compatible changed behavior to the isolated consumer.

### Evidence and completion
Completion requires publication, resolution, execution, and a receipt showing the protected rehearsal result and exact consumed package revision.

### Boundaries and reset
The rehearsal consumer has synthetic input and no ARWC delivery route; every player receives separate registry versions and receipt state. Reset removes them.

### Author checks
Test baseline resolution, intended compatible behavior, failed incompatible package, fresh consumer receipt, no cross-player result, and registry/consumer reset.
