## Challenge description — player-facing

Recover the cryptographic context needed to reproduce the legacy entitlement check for the supplied record.

## Story purpose

Builds a substantive cryptographic capability before entitlement abuse.

## Prerequisites and starting position

**Required access or evidence:** [K08.1](../K08/K08.1.md).

**Starting material:** The obsolete entitlement checker, representative license records, compatibility notes, and its bounded exercise interface.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover context that reproduces the checker result for the designated entitlement. Merely naming an algorithm or extracting an unused constant is insufficient.

## Difficulty and inspiration

Cryptographic reconstruction directly inspired by Tsayaki, with instance-specific context.

**Inspiration:** [Tsayaki (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c06). Retains Tsayaki's legacy cryptographic entitlement problem; this concerns an obsolete component.

## Technical design

### Surface and normal behavior
The compatibility record refers to a key identifier, derivation version, and archived encryption-context metadata stored in the FieldLink release archive.

### Vulnerability and intended solution
Archive metadata separates encrypted payload from its protected context weakly enough that the named record's context can be reconstructed. The intended solution is cryptographic-context recovery and validation, not key guessing.

### Evidence and completion
The checker accepts the recovered context only when it decrypts/verifies the supplied record and binds it to the expected legacy revision.

### Boundaries and reset
Only synthetic, card-specific key material and one record are available; no general secret-store read or current entitlement key is exposed. Reset renews player material.

### Author checks
Verify incomplete context fails, expected context validates one record, wrong revision/key ID fails, no other archive object opens, and reset.
