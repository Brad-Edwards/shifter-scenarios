## Challenge description — player-facing

Recover the restricted district-allocation adjustment ledger through the planner's query interface, despite the rules that exclude it from ordinary reserve reports.

## Story purpose

Establishes a useful data primitive beyond normal planning queries.

## Prerequisites and starting position

**Required access or evidence:** [W07.1](../W07/W07.1.md).

**Starting material:** The earned planner session, its restricted query interface, and normal report/query examples.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the actual adjustment ledger with its district and reporting-period binding. Running an already permitted report or merely describing the interface restriction is insufficient.

## Difficulty and inspiration

Substantive query interpretation under the source challenge's retained constraints.

**Inspiration:** [Aurors Archive (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c19). Retains Aurors Archive's restricted-database boundary after the browser chain.
