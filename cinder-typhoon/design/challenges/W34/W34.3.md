## Challenge description — player-facing

Couple the false planning view to the bounded release through the disclosed reporting handover. Preserve the convincing report while establishing the actual reserve loss.

## Story purpose

Creates an optional deeper ending that pays off the controls engineer's warning.

## Prerequisites and starting position

**Required access or evidence:** ([W34.2](../W34/W34.2.md) AND [CONTROL](../../capability-routes.json) AND [MODE](../../capability-routes.json) AND [CONSEQUENCE_PLAN](../../capability-routes.json)).

**Starting material:** The earned planning-view capability, the planner's input and refresh records, independent process observations, and a private rehearsal from earned state.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Demonstrate the changed decision, bounded volume loss, and continued reporting consistency across the handover, using evidence, authority, and the release calculation for the same earned checkpoint. Live control is required here; independent process truth and prior campaign results remain intact.
