## Challenge description — player-facing

Recover the diagnostic's hidden validation logic well enough to reproduce its decisions on the specified engineering records.

## Story purpose

Builds a substantive model of the diagnostic's actual checks.

## Prerequisites and starting position

**Required access or evidence:** [W19.2](../W19/W19.2.md).

**Starting material:** The retained engineering diagnostic, ordinary examples, and the current read-only observation context. K28's note is an optional discovery lead.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Demonstrate the correct decisions and record bindings. Replaying one known accepted input does not count.

## Difficulty and inspiration

Requires reconstructing the hidden program logic beyond the alternate-path observation.

**Inspiration:** [Gateway (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c21). Adapts Gateway's mixed-execution-mode analysis; it is a different problem from K28's loader investigation.
