## Challenge description — player-facing

Change the retained image so the outlet's last inspection is recorded as completed, preserving its asset identity, every unrelated record, and the image's required consistency.

## Story purpose

Completes a precise data-tampering episode.

## Prerequisites and starting position

**Required access or evidence:** [W20.2](../W20/W20.2.md).

**Starting material:** A retained maintenance image, simulated device-access material, and ordinary maintenance record examples.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Produce an accepted altered image with only the intended inspection completion changed. This is a historical maintenance-record manipulation, not control of live telemetry or a controller.

## Difficulty and inspiration

A constrained modification problem beyond record decoding; preserving surrounding data is part of the objective.

**Inspiration:** [Flash-ing Logs (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c12). Retains Flash-ing Logs' constrained record and storage problem using a simulated interface.
