## Challenge description — player-facing

The recovered staging material conceals another stage. Reconstruct the usable script and recover the instructions needed to understand what the earlier operator collected.

## Story purpose

Rewards sustained analysis with a specific operational lead.

## Prerequisites and starting position

**Required access or evidence:** [K03.1](../K03/K03.1.md).

**Starting material:** A retained staging bundle from an earlier Cinder attempt, its carrier document, and a short collection note.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the complete next-stage script and its actual collection instructions. Merely locating embedded text does not establish the reconstructed behavior.

## Difficulty and inspiration

Layered document and script analysis inspired directly by Game Invitation.

**Inspiration:** [Game Invitation (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c04). The inspiration is document and script reconstruction; the objective remains collection for Cinder.

## Technical design

### Surface and normal behavior
The staging artifact is a layered encoded script bundle with a documented runtime wrapper, integrity marker, and a separate collection-instruction payload.

### Vulnerability and intended solution
This is a staged reverse-engineering exercise. The intended solution reconstructs the complete executable representation and interprets its declared collection instructions; locating a string fragment is insufficient.

### Evidence and completion
The reconstruction service accepts the recovered script digest and instruction set only when they reproduce the fixture's deterministic behavior, then unlocks K03.3's callback configuration.

### Boundaries and reset
The script is analyzed in a card-local interpreter with synthetic inputs and no network or process execution. Reset clears reconstructed artifacts.

### Author checks
Test partial decode failure, correct reconstruction, integrity mismatch rejection, instruction/collection consistency, no host execution, and reset.
