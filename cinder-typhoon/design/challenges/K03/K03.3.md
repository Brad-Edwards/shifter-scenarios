## Challenge description — player-facing

Reconstruct the earlier operation's callback configuration and recover its lost collection. Find out what it learned about the unresolved ARWC maintenance ticket.

## Story purpose

Pays off the old Cinder thread without making it a compulsory customer-entry gate.

## Prerequisites and starting position

**Required access or evidence:** [K03.2](../K03/K03.2.md).

**Starting material:** A retained staging bundle from an earlier Cinder attempt, its carrier document, and a short collection note.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the correctly bound collection and its ticket evidence. The result explains the handler's interest; it supplies no required access credential.

## Difficulty and inspiration

Requires resolving configuration and collection context across the recovered stages.

**Inspiration:** [Game Invitation (HTB Cyber Apocalypse 2024; Hard)](../../reference-catalog.md#c04). The inspiration is document and script reconstruction; the objective remains collection for Cinder.

## Technical design

### Surface and normal behavior
A local callback emulator holds the predecessor operation's lost collection behind configuration fields for endpoint, collection ID, and integrity value.

### Vulnerability and intended solution
The emulator intentionally requires a correctly reconstructed configuration rather than exposing a listable archive. The intended solution applies K03.2's recovered instructions to the supplied staging binding.

### Evidence and completion
The emulator emits a collection-retrieved event only when all bound fields match and returns the `SUP-2841` ticket evidence with provenance.

### Boundaries and reset
It serves one synthetic collection, has no external endpoint, grants no continuing access, and resets its player callback state after completion.

### Author checks
Verify each incorrect configuration fails distinctly, correct reconstruction returns one collection, ticket provenance matches the staging record, direct archive reads fail, and reset works.
