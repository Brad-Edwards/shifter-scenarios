## Challenge description — player-facing

Recover the restricted preview association for the supplied support attachment. Establish which document identity the viewer believes it is presenting.

## Story purpose

Gives the preview investigation a concrete identity question.

## Prerequisites and starting position

**Required access or evidence:** [G01 — K01.1](../K01/K01.1.md).

**Starting material:** The document-preview source, an ordinary preview account, representative attachments, and the preview boundary's observable behavior.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the protected association and bind it to the supplied attachment. Public viewer documentation is only starting material.

## Difficulty and inspiration

A bounded investigation of document identity and preview behavior.

**Inspiration:** [Postviewer v3 (Google CTF 2024; 19 solves, no formal tier)](../../reference-catalog.md#c09). Uses Postviewer v3's isolated-document binding problem; its original solve count is not a tier label.

## Technical design

### Surface and normal behavior
The FieldLink preview queue renders support attachments in an isolated Playwright worker and records source attachment, derived document identity, viewer request, and owner case.

### Vulnerability and intended solution
The association lookup exposes the restricted derived identity for the supplied attachment without confirming that the requester owns its case. The intended solution recovers and validates that association.

### Evidence and completion
The queue returns the viewer's document identity, source attachment version, and restricted case binding as player evidence for K10.2.

### Boundaries and reset
This card is metadata-only: no preview content, worker action, or cross-case document read results. Reset clears player events.

### Author checks
Test normal own-case association, one supplied restricted association, denied unrelated attachment metadata, correct source/derived binding, and reset.
