## Challenge description — player-facing

Recover the archive-unlock value within the recovery interface's query allowance and open the diagnostic evidence bundle bound to the current engineering project.

## Story purpose

Turns the observation capability into protected engineering evidence and reveals the separate diagnostic-signing component behind the legacy service.

## Prerequisites and starting position

**Required access or evidence:** [W24.2](../W24/W24.2.md).

**Starting material:** The legacy recovery interface and its response-selection capability earned in W24.2, the sealed diagnostic evidence bundle, a bounded query allowance, and the current project binding from W21.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Recover the correct archive-unlock value and open the matching bundle within the allowance. These are one achievement. The bundle contains the retained diagnostic signer executable and signed records with their original metadata, providing W24.4's analysis material. Its unlock value is separate from diagnostic signing authority; no signing key or fresh authorization is awarded here.

## Difficulty and inspiration

Requires combining response meanings and selection behavior under the stated query allowance. Opening the recovered bundle completes that recovery; the independent signing problem remains in W24.4.

**Inspiration:** [Twin Oracles (HTB Cyber Apocalypse 2025; Hard)](../../reference-catalog.md#c23). Retains its constrained oracle recovery. The recovered value opens the diagnostic evidence bundle as the campaign payoff.
