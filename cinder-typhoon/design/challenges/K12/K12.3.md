## Challenge description — player-facing

Take control of the preview worker's contribution to the support review while preserving the expected review interface.

## Story purpose

Adds control of an active processing component.

## Prerequisites and starting position

**Required access or evidence:** [K12.2](../K12/K12.2.md).

**Starting material:** An ordinary release-preview account, preview application material, and a private support-review rehearsal.

**Campaign references:** No separately named capability output.

## Completion and downstream use

Demonstrate the worker producing Cinder's chosen compatible preview behavior. Replaying the preceding privileged action does not suffice.

## Difficulty and inspiration

Demanding worker control within the inherited browser constraints.

**Inspiration:** [apexsurvive (HTB Cyber Apocalypse 2024; Insane)](../../reference-catalog.md#c08). Retains apexsurvive's demanding browser-to-renderer composition in the supplier preview workflow.
