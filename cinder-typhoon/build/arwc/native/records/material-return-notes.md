# Service material returns

Owner: Procurement  
Applies to: Veybridge field-service orders

Return unused seals and actuator mounting kits to the maintenance store with
the supplier order number. Keep removed components in separate bags labelled
with the asset register reference and removal date. Instrument Services owns
calibration certificates; the Veybridge handback should reference the
certificate rather than amend it.

The stores team reconciles quantities every Friday. Damaged packaging should
be noted before the courier accepts the return. Supplier credits are processed
against the original purchase order.
