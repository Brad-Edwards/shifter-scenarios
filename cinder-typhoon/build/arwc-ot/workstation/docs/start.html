Cairn Reach Reservoir

This desk provides normal operation and engineering for ARWC's two-outlet reservoir site.

Operator views

Open FUXA for site controls and equipment feedback. Numeric proposed fields commit with Enter; Apply submits the complete request. Compare proposed settings, accepted settings, and measured values. Operator stop disarms valve motion. Clearing stop does not resume an old request.

Open process history for reservoir measurements, both outlets, quality gaps, alarms, and observed command decisions.

Engineering tools

Use OpenPLC Editor to open ~/CairnReach/controller. The graphical program shows measurements, permissives, request arbitration, and the outlet control blocks. Open the individual blocks to inspect their IEC logic. The PLC engineering endpoint is https://plc:8443.

In the project Configuration view, check the Runtime v4 IP address and use Connect. Sign in with the engineering role from the private connection notes. Use Debugger for live project variables. The disabled start/stop control requires an existing connection; the lower “No file selected” area is documentation.

Use the native OPC UA browser with opc.tcp://plc:4840/arwc, Basic256Sha256, and SignAndEncrypt. The published namespace is urn:arwc:crr:tags. Browse the real tag types and values.

PostgreSQL tools connect to postgres, database historian, with the historical reader role. Query process_history, alarm_history, command_history, dispatch_history, and historian_tag_catalog when their components are installed.

The authenticated MQTT broker is mosquitto:8883. Use the supplied CA and the published remote-request contract. MQTT receipt, PLC acceptance, and measured completion are distinct.

Site reference

The published tag register and I/O list are in /usr/share/arwc-ot/. The network diagram shows supervisory and field roles. Role-specific credentials and the current public certificate are delivered privately in ~/CairnReach/Connections/.

The read-only W17 field sheet and instrument reference are in ~/CairnReach/Briefs/W17/. They contain no fixed process values; record the live product state and UTC interval you actually observe.

The W18 native I/O register and history-provenance note are in ~/CairnReach/Briefs/W18/. Use them to reconcile Modbus channels, OPC UA identities, historian series, quality, and time.

The W21 project handover and commissioning note are in ~/CairnReach/Briefs/W21/. Reconcile the supplied project with OpenPLC's program-identity check, Runtime Status, and live ProjectRevision. Do not upload, start, stop, or force anything.

The W25 operating envelope and bounded-movement instruction are in ~/CairnReach/Briefs/W25/. Use only the two named local FUXA requests, prove the result in native history, and restore A20/B20 before finishing.

The W29 allocation export and reconciliation method are in ~/CairnReach/Briefs/W29/. Join the dated corporate records to a fresh good-quality usable_volume_ml sample; preserve both source times and do not treat the paper report as current process truth.

The W30 release plan and operator brief are in ~/CairnReach/Briefs/W30/. Bind the fixed plan to the published remote-request contract, execute one fresh dispatcher request, prove the result across native records, and restore manual A20/B20 through local FUXA priority.

The W33 operating window, schedule template, commissioning brief, and bounded client are in ~/CairnReach/Briefs/W33/. Calibrate from the completed W30 product history, plan the peak hour, commission every reviewed setpoint through the existing dispatcher, restore manual A20/B20 in FUXA, and keep measured trial evidence separate from the one-hour projection.

The PLC restarts disarmed. Accepted manual settings and automatic flow settings are retained. The physical model represents a small reservoir and two valve actuators. This VM soft PLC does not provide hard real-time or safety-instrumented guarantees.
