# Planned participant briefing

current authoritative briefing remains in `briefing-deck/`; content must not
be duplicated across both roots.

It contains mission context, objectives, rules of engagement, and the supported
A14 access instructions. It must not contain solution order, credentials,
answers, hidden state, proof predicates, or operator-only access methods.
