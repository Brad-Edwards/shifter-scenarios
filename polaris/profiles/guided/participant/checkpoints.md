# Guided self-checks

Pause periodically and ask:

- Can I explain the Boreas target picture using only in-world observations?
- Do I control useful access inside the enterprise rather than merely viewing
  a public surface?
- Have I recovered material that explains the protected program?
- Did my own range activity cause the intended industrial effect?
- Can I demonstrate control of the protected autonomous system from the
  participant surface?

A self-check is a reflection prompt, not a completion verdict. Continue only
from evidence you discovered through play.
