# Purple-team observation prompts

For each authored evidence requirement:

- identify the source system that would own the observation;
- verify the event belongs to the active range, participant, and attempt;
- distinguish participant activity from health checks and management actions;
- note missing observation coverage as a gap rather than treating silence as a
  successful detection;
- avoid exposing private predicates or raw event bodies to participants.

Polaris has planned observability contracts, not a claimed live telemetry
product. Any query examples must come from a future proved runtime, not from
this content bundle.
