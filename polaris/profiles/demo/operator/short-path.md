# Polaris demonstration beats

This presenter-only outline selects high-signal moments from the canonical
campaign:

- establish the Boreas target picture;
- show participant-controlled front-office access;
- contrast the lab and industrial branches;
- demonstrate the blackout-to-splice relationship;
- finish with control of the autonomous platform.

These are presentation beats, not an alternate path. On `local_degraded`, show
only components that genuinely exist and label the run degraded. Only the
planned `aws_event` binding can eventually support the complete scenario, and
neither runtime currently carries a golden claim.
