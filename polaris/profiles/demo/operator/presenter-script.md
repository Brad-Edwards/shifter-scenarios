# Polaris presenter script

Open by stating that Polaris is one offensive enterprise-to-industrial
scenario and that the current pack remains draft.

For each selected beat:

- show the participant surface before the action;
- explain the operational question without revealing later actions;
- perform or replay only behavior the selected runtime genuinely supports;
- distinguish participant activity from operator observation;
- state plainly when `local_degraded` cannot represent a required component.

Close by returning to the five campaign objectives and the single reference
contract. Do not describe the demo as a golden rehearsal or as a separate
scenario path.
